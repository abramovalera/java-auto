## Цели модуля и вопросы

Формат: вопрос → **суть правильного ответа** → типичные заблуждения.

### О1. Зачем массив, создание, значения по умолчанию
- «Зачем массив, если можно завести 100 переменных?» → **цикл не может перебирать переменные с разными именами; массив — одно имя и номер ячейки, его можно крутить в цикле; размер можно взять из ввода.**
- «Три способа создать массив?» → **`new int[5]`, `{1, 2, 3}` при объявлении, `new int[]{1, 2, 3}` где угодно.**
- «Что лежит в `new double[3]`, `new boolean[2]`, `new String[4]`?» → **0.0; false; null.**
- «Можно ли увеличить массив?» → **нет, размер фиксирован; создают новый побольше (`Arrays.copyOf(a, новаяДлина)`).**
- Заблуждение: «в новом массиве мусор/пусто, будет ошибка при чтении». Нет — значения по умолчанию есть всегда (в отличие от локальных переменных).
- Заблуждение: `a = {1, 2};` после объявления. Не компилируется.

### О2. Индексы и length
- «Почему индекс первого элемента 0?» → **индекс — смещение от начала: до первой ячейки 0 шагов.**
- «Последний элемент массива любой длины?» → **`a[a.length - 1]`.**
- «`a.length` или `a.length()`? А у строки?» → **у массива свойство без скобок, у строки метод `length()`.**

### О3. Обход, ввод, for-each
- «Напиши по памяти цикл обхода» → **`for (int i = 0; i < a.length; i++)`**; объяснить `<`, а не `<=`.
- «Как прочитать N, потом N чисел?» → **`n = nextInt()` → `new int[n]` → цикл `a[i] = nextInt()`.**
- «Когда for-each, когда for по индексам?» → **for-each — только чтение всех значений по порядку; индексы — запись в ячейки, позиция, соседи, обратный порядок, часть массива.**
- «Почему `for (int x : a) x = 0;` не обнуляет массив?» → **x — копия значения элемента.**
- Заблуждение: «for-each быстрее/лучше всегда». Нет, он просто удобнее, когда индекс не нужен.

### О4. Массив в памяти: ссылки (главная цель модуля)
- «Нарисуй память для `int[] a = {1,2,3}; int[] b = a; b[0] = 9;`» → **в стеке a и b с одним адресом, в куче один массив; `a[0]` стал 9.**
- «Чем `int y = x` отличается от `int[] b = a`?» → **`=` копирует содержимое переменной: у примитива это значение, у массива — ссылка.**
- «Как сделать настоящую копию? Три способа.» → **`Arrays.copyOf(a, a.length)`, `a.clone()`, новый массив + цикл.**
- «Что будет со старым массивом после `a = new int[5]`?» → **если на него больше никто не ссылается — его уберёт сборщик мусора; если ссылается b — живёт.**
- «Что такое `null` у массива? Чем отличается от `new int[0]`?» → **null — ссылки нет, `a.length` даст NPE; `new int[0]` — настоящий пустой массив, length = 0.**
- Проверка в тесте: «тест сохранил `expected = actual;`, программа поменяла actual — что проверит тест?» → **сравнит массив сам с собой, всегда зелёный.**

### О5. Сравнение массивов
- «`a == b` для двух массивов `{1, 2}` — что вернёт и почему?» → **false, разные объекты/адреса.**
- «Как сравнить содержимое?» → **`Arrays.equals(a, b)`.**
- «А `a.equals(b)`?» → **у массивов работает как `==`.** Частая ловушка на собеседовании.

### О6. Класс Arrays
- «Почему `println(a)` печатает `[I@1b6d3586`? Как расшифровать?» → **паспорт объекта: `[` — массив, `I` — int, после @ — хеш.**
- «Какие методы Arrays меняют массив, а какие возвращают новое?» → **`sort`, `fill` меняют и ничего не возвращают (void); `toString`, `copyOf`, `copyOfRange`, `equals` — возвращают результат.**
- «Почему `int[] s = Arrays.sort(a);` не компилируется?» → **sort возвращает void.**
- «Границы `copyOfRange(a, 1, 4)`?» → **с 1 включительно до 4 не включая, длина 3.**
- «Как получить отсортированную копию, не испортив оригинал?»

### О7. Базовые алгоритмы (Мастерская)
- «С какого значения начинать поиск максимума и почему не с 0?» → **с `a[0]`: при всех отрицательных 0 окажется ложным максимумом.**
- «`>` или `>=` — какой индекс максимума найдём при повторах?» → **`>` — первый, `>=` — последний.**
- «Почему `else { "Не найдено" }` внутри цикла поиска — ошибка?» → **«нет» можно сказать только после проверки всех элементов; внутри цикла известно лишь, что текущий не подходит.**
- «Что значит `index = -1`?» → **договорённость «не нашли», такого индекса не бывает (как у `indexOf`).**
- «Среднее: почему `(double) sum / n`, а не `sum / n`?» → **целочисленное деление.**
- «Почему сдвиг вправо делают с конца?» → **слева направо каждое копирование затирает ещё не перенесённое значение.**

### О8. Двумерные массивы
- «Что такое `m.length`, `m[0]`, `m[0].length` для `new int[3][5]`?» → **3 строки; строка 0 (int[]); 5 столбцов.**
- «Как это лежит в памяти?» → **внешний массив ссылок на строки-массивы.**
- «Где обнулять сумму строки?» → **внутри цикла по строкам, перед циклом по столбцам.**
- «Чем печатать двумерный массив целиком?» → **`Arrays.deepToString`.**
- «Почему во внутреннем цикле `m[r].length`, а не `m.length`?» → **для неквадратных таблиц и «рваных» массивов.**

### О9. char[], String, String[] args
- «Что такое `String[] args` в main?» → **массив строк — аргументы запуска; без аргументов длина 0, не null.**
- «Как передать аргументы в IDEA?» → **Run → Edit Configurations → Program arguments.**
- «`args[0]` при запуске `Петя 25` — какого типа "25"?» → **String; число — `Integer.parseInt` (на опережение).**
- «Как поменять букву в строке?» → **toCharArray → правка → `new String(chars)`; строка неизменяемая.**
- «Что напечатает `println(chars)` и `println("" + chars)`?» → **текст; паспорт `[C@…`.**

## Банк головоломок

Давай по одной. Сначала ответ и «почему», потом разбор. Задачи про ссылки — проси **нарисовать стек и кучу**. ★★★ — на опережение, предупреждай честно.

### Что выведется?
1. `int[] a = new int[3]; System.out.println(a[1] + a.length);` → `3`
2. `int[] a = {1, 2, 3}; int[] b = a; b[0] = 10; System.out.println(a[0] + b[0]);` → `20`
3. `int[] a = {1, 2, 3}; int[] b = {1, 2, 3}; System.out.println(a == b); System.out.println(Arrays.equals(a, b));` → `false`, `true`
4. `int[] a = {1}; int[] b = {1}; System.out.println(a.equals(b));` → `false` (equals у массивов = ==)
5. `int[] a = {1, 2, 3}; for (int x : a) { x *= 2; } System.out.println(Arrays.toString(a));` → `[1, 2, 3]`
6. `String[] s = new String[2]; System.out.println(s[0] + "!");` → `null!`
7. `int[] a = {3, 1, 2}; int[] b = a; a = new int[]{9, 9}; System.out.println(b[0] + " " + a.length);` → `3 2`
8. `int[] a = {1, 2, 3}; int[] b = a.clone(); b[0] = 100; System.out.println(a[0]);` → `1`
9. `char[] c = {'h', 'i'}; System.out.println(c); System.out.println("" + c);` → `hi`, затем `[C@…`
10. `int[] a = {3, 1, 2}; int[] b = a; Arrays.sort(b); System.out.println(a[0]);` → `1` (sort через вторую ссылку)
11. `int[] a = {7, 8}; int[] c = Arrays.copyOf(a, 4); System.out.println(Arrays.toString(c));` → `[7, 8, 0, 0]`
12. `int[][] m = {{1, 2, 3}, {4, 5}}; System.out.println(m.length + " " + m[1].length);` → `2 2`
13. `int[] a = {1, 2, 3}; for (int i = 1; i < a.length; i++) a[i] = a[i - 1]; System.out.println(Arrays.toString(a));` → `[1, 1, 1]` («протекание» при сдвиге слева направо)
14. Разворот «до конца»: `for (int i = 0; i < a.length; i++) { обмен a[i] и a[a.length-1-i] }` для `{1, 2, 3, 4}` → `[1, 2, 3, 4]` (развернули дважды)
15. ★★★ `int[][] m = new int[2][]; System.out.println(m[0]);` → `null` (строки не созданы); `m[0][0]` → NullPointerException

### Скомпилируется ли?
16. `int[] a = new int[];` → **нет**: нужен размер или значения (array dimension missing).
17. `int[] a = new int[3]{1, 2, 3};` → **нет**: либо размер, либо значения.
18. `int[] a; a = {1, 2, 3};` → **нет**: короткая форма только при объявлении; `a = new int[]{1, 2, 3};` — да.
19. `int a[] = new int[5];` → **да** (стиль C, в Java не принят).
20. `int n = 0; int[] a = new int[n]; System.out.println(a.length);` → **да**, `0`.
21. `int[] sorted = Arrays.sort(a);` → **нет**: sort возвращает void.
22. `double[] d = new int[3];` → **нет**: `int[]` не превращается в `double[]` (хотя `int` в `double` — да).
23. `String s = "кот"; s.charAt(0) = 'р';` → **нет**: charAt возвращает значение, присвоить ему нельзя; строка неизменяема.

### Скомпилируется, но что будет при запуске?
24. `int[] a = {5}; System.out.println(a[a.length]);` → `ArrayIndexOutOfBoundsException: Index 1 out of bounds for length 1`
25. `int[] a = null; System.out.println(a.length);` → `NullPointerException`
26. ★★★ `int[] a = new int[-1];` → `NegativeArraySizeException`
27. Запуск без аргументов: `System.out.println(args[0]);` → `ArrayIndexOutOfBoundsException: Index 0 out of bounds for length 0`

### Найди ошибку
28. Сумма: `for (int i = 1; i <= a.length; i++) sum += a[i];` → две ошибки: старт с 1 (пропуск a[0]) и `<=` (вылет).
29. Максимум: `int max = 0; for (int x : a) if (x > max) max = x;` → неверно для всех отрицательных; `int max = a[0];`.
30. Соседи: `for (int i = 0; i < a.length; i++) if (a[i] == a[i + 1]) …` → вылет на последнем витке; условие `i < a.length - 1`.
31. Поиск: `else { System.out.println("Не найдено"); }` внутри цикла → печатает много раз; решение после цикла по флагу/индексу.
32. Сумма строк: `int rowSum = 0;` до внешнего цикла → нарастающий итог вместо суммы строки.
33. Обнуление: `for (int x : a) x = 0;` → массив не меняется; нужен for по индексам.

### Почему здесь ошибка?
Покажи код и сообщение, попроси объяснить причину своими словами:
34. `Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5 at Oops.main(Oops.java:5)` → что, какой индекс, какая длина, где; чаще всего `<=` в условии цикла.
35. Вывод `[I@6d06d69c` вместо чисел → печать массива через println, нужен `Arrays.toString`.
36. Тест «проверяет, что сортировка работает», но всегда зелёный: `int[] expected = actual; Arrays.sort(actual); assert Arrays.equals(expected, actual)` → expected и actual — один массив.

## Задачи «Мастерской» (решать вслух по шаблону)

Ученик проговаривает: примеры (включая граничные) → руками → роли → псевдокод → код → трассировка. Наставник **не даёт код**, только вопросы по шаблону («какие роли?», «а если один элемент?», «что будет на шаге 2?»).

1. **Разворот на месте** (на сайте `m06-t06`): ключевые вопросы — сколько обменов, почему `left < right`, что будет при `i < a.length`.
2. **Второй по величине** (`m06-t10`): два рекордсмена + флаг; что происходит со старым максимумом; повторы максимума; второй раньше максимума.
3. **Палиндром-массив**: `{1, 2, 3, 2, 1}` → да. Два указателя навстречу, флаг, `break` при первом несовпадении.
4. **Сдвиг влево по кругу** (зеркально к `m06-t08`): в какую сторону идти, что спасать в tmp.
5. **Количество «ступенек»**: сколько раз `a[i] > a[i - 1]` — граница цикла с 1.
6. **Сумма по столбцам** таблицы (зеркально к `m06-t09`): какой цикл внешний.
