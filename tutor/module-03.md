## Цели модуля и вопросы

Формат: вопрос → **суть правильного ответа** → типичные заблуждения.

### О1. Арифметика и целочисленное деление
- «Почему `7 / 2` — это 3?» → **оба операнда int → результат int, дробная часть отрезается (не округляется).**
- «Три способа получить 3.5 из 7 и 2?» → **`7 / 2.0`, `7.0 / 2`, `(double) 7 / 2`.** А `(double) (7 / 2)` — 3.0, и почему.
- «`int a = 5, b = 2; double r = a / b;` — что в r?» → **2.0: правая часть считается раньше, тип переменной слева не влияет.**
- «`-7 / 2`?» → **-3: отрезание дроби идёт к нулю.**
- «Чем унарный минус отличается от бинарного? Что напечатает `int t = 5; System.out.println(10 - -t);`?» → **унарный — один операнд, меняет знак значения (t не меняется); 15.** `+t` ничего не меняет.
- «Почему `50 / 100 * 2` — 0, а `50 * 2 / 100` — 1?» → **целочисленное деление съело 50 / 100 до умножения; с целыми сначала умножай.**
- Заблуждение: «целочисленное деление округляет». Нет, отбрасывает.

### О2. Остаток %
- «Как достать последнюю цифру числа? Как её отрезать?» → **`n % 10`, `n / 10`.**
- «Как проверить чётность и почему `n % 2 == 1` — плохая проверка нечётности?» → **`n % 2 == 0`; у отрицательных нечётных остаток −1.**
- «Какой знак у остатка?» → **как у делимого (левого числа): `-7 % 2 == -1`, `7 % -2 == 1`.**
- «Сейчас 22 часа, который час будет через 5 часов?» → **`(22 + 5) % 24` = 3.**
- Проверочное тождество: `(a / b) * b + a % b == a`.
- «Работает ли `%` с double? `7.5 % 2`?» → **да, 1.5; знак — как у делимого.**

### О3. Деление на ноль, типы результата, переполнение
- «Что будет при `10 / 0` и при `10.0 / 0`?» → **ArithmeticException: / by zero (при запуске, компилятор не ловит) и Infinity. `0.0 / 0` — NaN.**
- «Что опаснее: исключение или Infinity/NaN?» → **NaN/Infinity: тихо портят дальнейшие вычисления.**
- «int + double — какой тип?» → **double: меньший тип расширяется до большего.**
- (для любопытных, не обязательно) «`long big = 1_000_000 * 1_000_000;` — что в big и почему?» → **переполнение int до присваивания, −727379968; лечится `1_000_000L`.**

### О4. ++, -- и составные присваивания
- «Чем `i++` отличается от `++i`?» → **постфикс отдаёт старое значение, потом увеличивает; префикс — сначала увеличивает, потом отдаёт новое. На отдельной строке разницы нет.**
- «Что выведет `int i = 5; i = i++; System.out.println(i);` и почему?» → **5: i++ отдал 5, присваивание затёрло шестёрку.**
- «`x += y` — это что?» → **`x = x + (y)`, правая часть целиком: `k *= 2 + 1` — умножение на 3.**
- «Скомпилируется ли `int x = 10; x += 2.7;`, а `x = x + 2.7;`?» → **первое да (скрытое приведение, x = 12), второе нет.** (★ — для сильного ответа)
- Заблуждение: «`5++` даст 6». Нет: ++ только для переменных.

### О5. Сравнения и boolean
- «Что такое результат `age >= 18`?» → **значение типа boolean, его можно напечатать и положить в переменную.**
- «`=` и `==`?» → **присвоить / сравнить. `boolean b = x = 5;` — ошибка компиляции: int в boolean не положить.**
- «Почему `1 < x < 10` не компилируется?» → **`1 < x` — boolean, его нельзя сравнить с 10. Нужно `x > 1 && x < 10`.**
- «Почему `0.1 + 0.2 == 0.3` — false? Как сравнивать double?» → **двоичная погрешность (0.1 — бесконечная двоичная дробь); `Math.abs(a - b) < eps`, где eps — допуск.** JUnit здесь не упоминать (он в модуле 17).
- «Как сравнить строки?» → **`.equals()`; `==` сравнивает ссылки (подробно в модуле 8).** Здесь достаточно правила, глубину не требовать.
- «`'a' < 'B'`?» → **false: сравниваются коды (97 и 66).**

### О6. Логические операторы и короткое замыкание
- «Таблица истинности для && и ||» → **&& — true только если оба true; || — false только если оба false.**
- «Что такое короткое замыкание? Пример, где оно спасает» → **`false && …` и `true || …` не вычисляют правую часть; `count != 0 && total / count > 10`.**
- «Что будет, если поменять части местами?» → **ArithmeticException при count == 0.**
- «Чем `&` отличается от `&&` для boolean?» → **`&` всегда вычисляет обе части.** (★)
- Попроси записать правило из жизни: «скидка, если студент или старше 65, но только при наличии карты» → `(isStudent || age > 65) && hasCard`. Проверь скобки.

### О7. Приоритет и порядок вычисления
- «Порядок: унарные → * / % → + - → сравнения → == != → && → || → присваивание.» Пересказ своими словами, не дословно.
- «Почему `"2 + 2 = " + 2 + 2` даёт 22, а `"Итог: " + 3 * 2` — 6?» → **+ одного уровня, слева направо, со строкой — склейка; * главнее +.**
- «`100 / 10 / 5`?» → **2 — один уровень, слева направо.**
- «Где ошибка: `double avg = a + b + c / 3.0;`?» → **делится только c; нужны скобки.**
- Попроси расписать по шагам: `20 - 3 * 4 / 2 + 10 % 3` → 12, 6, 14, 1, 15 (так в трассировке урока 3.5: приоритет расставляет скобки `(20 - (3*4/2)) + (10 % 3)`, дальше слева направо; `10 % 3` считается после `20 - 6`). Школьный порядок 12, 6, 1, 14, 15 тоже даёт 15 — засчитывай, но спроси, в каком порядке на самом деле идёт Java.
- «Когда решается, что `+` — склейка?» → **при компиляции, по типам двух операндов этого плюса: хотя бы один String → склейка.** Не «во время выполнения».

### О8. Класс Math
- «Какой тип возвращают pow, sqrt, round, floor, ceil?» → **double, double, long (для double), double, double.**
- «Почему не компилируется `int p = Math.pow(2, 10);`?» → **double в int без приведения нельзя.**
- «Как округлить до сотых и почему делим на `100.0`?» → **`Math.round(x * 100) / 100.0`; со `100` будет целочисленное деление.**
- «Разница floor и (int) для −2.7?» → **−3.0 и −2: floor — вниз по прямой, (int) — к нулю.**
- «Формула кубика? Почему `(int) Math.random() * 6 + 1` всегда 1?» → **`(int) (Math.random() * 6) + 1`; приведение главнее умножения.**
- «Случайное целое от min до max включительно?» → **`(int) (Math.random() * (max - min + 1)) + min`; без `+ 1` max никогда не выпадет.** Попроси проверить на min = 10, max = 20.
- «Что вернёт `Math.ceil(7 / 2)`?» → **3.0: целочисленное деление случилось раньше.**

## Банк головоломок

Давай по одной. Сначала ответ и «почему», потом разбор. ★★★ — честно предупреждай, что это сложнее/на опережение.

### Что выведется?
1. `System.out.println(7 / 2 * 2);` → `6`
2. `System.out.println(7 / 2.0 * 2);` → `7.0`
3. `System.out.println(5 % -3 + " " + -5 % 3);` → `2 -2` (знак — как у делимого)
4. `int i = 5; i = i++ + ++i; System.out.println(i);` → `12`
5. `int i = 5; i = i++; System.out.println(i);` → `5`
6. `int a = 5; int b = a++; int c = ++a; int d = a-- - --a; System.out.println(a + " " + b + " " + c + " " + d);` → `5 5 7 2`
7. `int q = 5; System.out.println(q++ + q++); System.out.println(q);` → `11`, `7`
8. `int w = 5; System.out.println(--w - w--); System.out.println(w);` → `0`, `3`
9. `char c = 'A'; System.out.println(c + 1); c++; System.out.println(c);` → `66`, `B`
10. `System.out.println('1' + 2);` → `51` (код '1' — 49)
11. `System.out.println("" + 'a' + 1);` → `a1`; а `System.out.println('a' + 1 + "");` → `98`
12. `System.out.println(1 + 2 + "3" + 4 * 5);` → `3320`
13. `System.out.println("Итог: " + 3 * 2 + 1);` → `Итог: 61`
14. `System.out.println(true || false && false);` → `true`; `System.out.println((true || false) && false);` → `false`
15. `int x = 0; boolean r = x == 0 || x++ > 0; System.out.println(x + " " + r);` → `0 true`
16. `int x = 0; boolean a = false && ++x > 0; boolean b = true || ++x > 0; boolean c = true && ++x > 0; System.out.println(x);` → `1`
17. `System.out.println((0.1 + 0.2 == 0.3) + " " + (0.5 + 0.25 == 0.75));` → `false true` (половинки и четвертинки в двоичном виде точны)
18. `System.out.println(Math.round(2.5) + " " + Math.round(-2.5));` → `3 -2`
19. `System.out.println(Math.ceil(7 / 2));` → `3.0`
20. `int k = 3; k *= 2 + 1; System.out.println(k);` → `9`
21. `String s = "Ура"; s += 1 + 2; System.out.println(s);` → `Ура3` (правая часть `+=` считается целиком: 1 + 2 = 3, потом склейка)
22. ★★★ `int i = 2; int r = i + i++ * i; System.out.println(r + " " + i);` → `8 3` (операнды слева направо: 2 + 2 × 3)

### Скомпилируется ли?
23. `int x = 5; boolean ok = 1 < x < 10;` → **нет**: boolean нельзя сравнить с int.
24. `int x = 7; boolean five = x = 5;` → **нет**: int cannot be converted to boolean.
25. `int p = Math.pow(2, 3);` → **нет**: double → int без приведения.
26. `int r = Math.round(2.7);` → **нет**: round(double) возвращает long.
27. `5++;` → **нет**: ++ только для переменной.
28. `System.out.println("Разница: " + 10 - 5);` → **нет**: строка минус число.
29. ★★★ `int x = 10; x += 2.7;` → **да**, x = 12. А `x = x + 2.7;` → **нет**.
30. `boolean b = true > false;` → **нет**: у boolean нет «больше/меньше».

### Скомпилируется, но что будет при запуске?
31. `int people = 0; System.out.println(10 / people);` → ArithmeticException: / by zero.
32. `System.out.println(10.0 / 0 + " " + 0.0 / 0);` → `Infinity NaN`, без падения.
33. `int dice = (int) Math.random() * 6 + 1;` → всегда 1.
34. `int count = 0; boolean ok = 100 / count > 5 && count != 0;` → падение: деление стоит первым. Как починить?
35. ★★★ `long big = 1_000_000 * 1_000_000; System.out.println(big);` → `-727379968`.
36. ★★★ `System.out.println(Math.abs(Integer.MIN_VALUE));` → `-2147483648` (переполнение: +2147483648 не помещается в int).

### Найди ошибку
37. ```java
    int points = 17;   // 17 баллов за 5 контрольных
    int tests = 5;
    double average = points / tests;
    boolean whole = points % tests = 0;
    ```
    → строка 4: `=` вместо `==` (компиляция); строка 3: целочисленное деление, средний балл 3.0 вместо 3.4 (логика). Сюжет специально «делимый» (средний балл), а не конфеты/печенье: штучное не делят на дроби.
38. ```java
    int a = 4;
    int b = 5;
    int c = 3;
    double avg = a + b + c / 3;
    ```
    → приоритет (делится только c) **и** целочисленное деление: нужно `(a + b + c) / 3.0`.
39. `boolean isOdd = n % 2 == 1;` → сломается на отрицательных; `n % 2 != 0`.
40. `double rounded = Math.round(price * 100) / 100;` → целочисленное деление long на int: копейки теряются.

### Почему здесь ошибка?
Покажи код и сообщение, попроси объяснить своими словами:
41. `error: incompatible types: possible lossy conversion from double to int` на строке `int p = Math.pow(2, 10);` → pow возвращает double. Попутно спроси, что значит число в `Traps.java:3:` — **номер строки в файле, как на полях IDEA**.
42. `error: bad operand types for binary operator '<'` на `1 < x < 10` → первое сравнение дало boolean.
43. `Exception in thread "main" java.lang.ArithmeticException: / by zero` → целое деление на ноль, найти строку по номеру в последней строке трассировки.

### Ещё: унарный минус, % с дробными, случайный диапазон
44. `int x = 4; System.out.println(-x * -2);` → `8` (унарные минусы раньше умножения).
45. `System.out.println(7.5 % 2 + " " + -7.5 % 2);` → `1.5 -1.5`.
46. `int n = (int) (Math.random() * (20 - 10)) + 10;` — какие числа выпадут? → **10…19, двадцатка никогда: забыли `+ 1`.**
47. `System.out.println(50 / 100 * 2 + " " + 50 * 2 / 100);` → `0 1`.

## Дополнительные задачи (если ученик быстрый)

Код ученик пишет сам, ты проверяешь глазами или просишь вставить вывод. Только пройденное: без `if` и циклов.
- «Обратное число»: ввести трёхзначное число, напечатать его задом наперёд (472 → 274) — арифметикой, без строк.
- «Часы назад»: сейчас H часов, сколько будет через N часов, если N может быть отрицательным? (подсказка: `Math.floorMod` или `((H + N) % 24 + 24) % 24`).
- «Кратно 3 или 5»: ввести число, напечатать `true`, если оно делится на 3 или на 5, но не на оба сразу (знакомство с `^`, или через `&&`/`||`/`!`).
- «Треугольник существует?»: три стороны → `true/false` одним выражением (каждая сторона меньше суммы двух других).
- «Площадь круга»: радиус → площадь до сотых через `Math.PI` и `Math.round`.
- «Обмен без третьей переменной»: `a = a + b; b = a - b; a = a - b;` — объяснить, почему работает (★: что будет при переполнении).
- «Попадание в прямоугольник»: точка (x, y) и прямоугольник от (x1, y1) до (x2, y2) → `true/false`. Мост к игре «Джавик-курьер» в модуле 4: там условия тоже собираются из нескольких датчиков через `&&`, `||` и `!`.
