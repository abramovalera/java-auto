## Цели модуля и вопросы

Формат: вопрос → **суть правильного ответа** → типичные заблуждения.

### О1. Переменная, объявление, присваивание
- «Что такое переменная? Аналогия?» → **именованное место в памяти с типом и одним значением; коробка с ярлыком.**
- «Как читается `x = x + 1`? Почему это не противоречит математике?» → **= — присваивание, не равенство: вычисли правую часть со старым x, положи результат в x.**
- «Чем `int a;` отличается от `int a = 5;`?» → **объявление без значения / объявление с инициализацией; читать неинициализированную переменную нельзя.**
- «`int b = a * 10; a = 5;` — изменится ли b?» → **нет, в b лежит готовое число, а не формула.**
- Заблуждения: «= значит равно», «переменная запоминает формулу», «можно объявить второй раз с новым значением».

### О2. Примитивные типы и литералы
- «Назови пять главных примитивных типов и что в них хранится» → **int, long, double, boolean, char.** Плюс byte, short, float — знать, что есть.
- «Какой тип для: возраста, населения Земли, цены, "включён ли свет", буквы оценки?» → **int, long, double, boolean, char.**
- «Почему `long x = 3000000000;` не компилируется?» → **литерал без L — int, а для int он слишком велик.**
- «Почему `float f = 1.5;` не компилируется?» → **1.5 — литерал double, double → float — сужение.**
- «Чем `'A'` отличается от `"A"`?» → **char (один символ, внутри код) и String (объект-строка).**
- «Почему 0.1 + 0.2 не равно ровно 0.3?» → **дробные хранятся в двоичном виде с погрешностью; деньги не в double.**

### О3. Переполнение
- «Что выведет `Integer.MAX_VALUE + 1` и почему?» → **−2147483648, int идёт по кругу (счётчик пробега).**
- «Java предупредит о переполнении?» → **нет, молча.**
- «Почему `long s = years * 365 * 24 * 60 * 60;` всё равно переполняется?» → **правая часть считается в int до записи в long; нужен long хотя бы в первом множителе: `365L` или `long years`.**

### О4. String, var, final, имена
- «Почему String с большой буквы?» → **это класс, строки — объекты; примитивы — с маленькой.**
- «Что вернёт `"Java".charAt(4)`?» → **упадёт с StringIndexOutOfBoundsException: номера 0..3.**
- «Что делает `var`? Можно ли `var x;`?» → **компилятор выводит тип из значения справа один раз; без значения нельзя, тип потом не меняется.**
- «Зачем `final`? Как называют константы?» → **значение кладётся один раз; UPPER_SNAKE_CASE; нет «магических чисел», одно место для правки.**
- «Назови стили имён в Java» → **camelCase — переменные/методы, PascalCase — классы, UPPER_SNAKE_CASE — константы.**

### О5. Память: стек и куча (тема особенно важна автору курса)
- «Где хранятся примитивы и объекты?» → **переменные методов — во фрейме на стеке; у примитива значение прямо в переменной, у объектной переменной — ссылка, объект в куче.** Бонус: поле-примитив объекта живёт в куче внутри объекта (модуль 9).
- «Что происходит при `String s2 = s1;`?» → **копируется ссылка, обе переменные смотрят на один объект.**
- «`s2 = "Боб"` после этого — изменится ли s1?» → **нет, s2 перевесили на новый объект.**
- «Чем `""` отличается от `null`?» → **пустая строка — объект с 0 символов; null — объекта нет.**
- «Что будет при `s.length()`, если s == null?» → **NullPointerException при запуске (компилируется).**
- «Может ли int быть null?» → **нет.**
- «Кто и когда убирает стек и кучу?» → **фрейм снимается целиком, когда метод завершился; объекты без ссылок убирает сборщик мусора, когда JVM решит.**
- Попроси нарисовать: `int a = 5; int b = a; String s1 = "Аня"; String s2 = s1; s1 = null;` — где мусор? (**мусора нет: на «Аню» смотрит s2**).
- Заблуждения: «String хранится в переменной целиком», «s2 = s1 копирует строку», «после s1 = null объект удаляется сразу».
- Тонкость: строки-литералы (`"Аня"`) на деле держит пул строк, и сборщик их не уберёт. В уроке 2.4 это в блоке «для любопытных»; на вопросы «где мусор» засчитывай ответ «на объект не ведёт ни одна ссылка» — правило то же, что для обычных объектов.

### О6. Scanner
- «Зачем `import java.util.Scanner`, а для String import не нужен?» → **import указывает пакет класса; java.lang подключён всегда.**
- «Чем отличаются nextLine, next, nextInt?» → **строка до Enter / слово до пробела / целое число.**
- «Объясни ловушку nextInt + nextLine» → **nextInt оставляет Enter на ленте, nextLine читает до него пустую строку; лечится лишним nextLine() или чтением через nextLine + parseInt.**
- «Почему nextDouble падает на "3.5" в русской Windows?» → **Scanner читает по правилам языка системы: дробь через запятую.**
- «Что будет, если на nextInt ввести "abc"?» → **InputMismatchException.**

### О7. Расширение и сужение
- «Какие преобразования Java делает сама?» → **расширение: byte → short → int → long → float → double, char → int.**
- «Чему равно `(int) 3.99`? `(int) -3.99`?» → **3 и −3: отбрасывание, не округление.**
- «Что выведет `double d = 7 / 2;`?» → **3.0: сначала int / int.**
- «Почему `int x = 3.5;` — ошибка, а `double y = 3;` — нет?» → **сужение только явно (possible lossy conversion), расширение — автоматически.**
- «`int sum = 10, count = 4;` Чем `(double) sum / count` отличается от `(double) (sum / count)`?» → **2.5 и 2.0: приведение действует на то, что сразу справа; во втором случае сначала целое деление.**
- «Почему `37 * (9.0 / 5) + 32` печатает 98.60000000000001 и как вывести 98.6?» → **дробные хранятся приблизительно; `Math.round(x * 10) / 10.0` — делить именно на 10.0, иначе целое деление.**

### О8. char ↔ int
- «Что выведет `'A' + 1`? А `(char) ('A' + 1)`?» → **66 и B.**
- «Почему `'A' + 'B'` — 131, а `"" + 'A' + 'B'` — AB?» → **char + char — сложение кодов; со строки начинается склейка.**
- «Чему равен код '0'? Как из символа '7' получить число 7?» → **48; `'7' - '0'`.**

### О9. Строки ↔ числа
- «Как превратить "42" в число? А 42 в строку?» → **Integer.parseInt / Double.parseDouble / Long.parseLong; String.valueOf(42) или "" + 42.**
- «Что будет с `Integer.parseInt("3.5")`? `parseInt(" 42")`?» → **NumberFormatException в обоих случаях.**
- «Что такое `Integer` и `Double`? Почему `Integer.parseInt` пишется через имя класса, а не через переменную?» → **классы-обёртки для int и double, «ящики с инструментами»; parseInt — метод самого класса, объект не нужен (подробно — модули 7, 9, 13).**
- «Зачем это в реальных программах?» → **из поля ввода, файла или интернета всё приходит текстом; чтобы сравнивать/складывать числа — parse.**

## Банк головоломок

Давай по одной. Сначала ответ и «почему», потом разбор. ★★★ — честно предупреждай, что это на опережение.

### Что выведется?
1. `int a = 5; int b = a; a = 10; System.out.println(b);` → `5` (копия значения)
2. `int x = 4; x = x * 2; x = x + x; System.out.println(x);` → `16`
3. `System.out.println('A' + 'B' + "C");` → `131C`
4. `System.out.println("C" + 'A' + 'B');` → `CAB`
5. `System.out.println("" + 'A' + 'B' + 1);` → `AB1`
6. `double d = 10 / 4; System.out.println(d);` → `2.0`
7. `System.out.println(10 / 4.0);` → `2.5`
8. `long big = Integer.MAX_VALUE + 1; System.out.println(big);` → `-2147483648` (переполнение до расширения)
9. `int a = 2_000_000_000; System.out.println(a + a);` → `-294967296`
10. `char c = 'a'; System.out.println(c + 1); System.out.println((char) (c + 1));` → `98`, `b`
11. `String s1 = "Кот"; String s2 = s1; s1 = s1 + "ик"; System.out.println(s2);` → `Кот` (строки неизменяемы, перевесили стрелку)
12. `System.out.println((int) 9.99 + (int) 0.99);` → `9`
13. `System.out.println("Java".length() + "Java".charAt(0));` → `78` (!) — `4 + 'J'` = 4 + 74 = 78: int + char = int. ★★
14. `System.out.println(Integer.parseInt("12") + "3");` → `123`
15. `System.out.println(0.1 + 0.2);` → `0.30000000000000004`
16. `char c = 65; System.out.println(c);` → `A` (литерал-константа, помещается в char — компилятор разрешает)
17. ★★★ `System.out.println(1 / 0.0);` → `Infinity` (а `1 / 0` → ArithmeticException; модуль 3)
18. ★★★ `System.out.println((byte) 200);` → `-56`
18а. `int a = 7, b = 2; System.out.println((double) a / b); System.out.println((double) (a / b));` → `3.5`, `3.0`
18б. `System.out.println(Math.round(2.5 * 10) / 10);` → `2`: round вернул целое 25, а 25 / 10 — целое деление; с `/ 10.0` → `2.5`

### Скомпилируется ли?
19. `long stars = 3000000000;` → **нет**: integer number too large, нужно L.
20. `float price = 9.99;` → **нет**: 9.99 — double, нужно 9.99f.
21. `int n = 5L;` → **нет**: long → int — сужение.
22. `var data = null;` → **нет**: cannot infer type.
23. `var x; x = 5;` → **нет**: var без инициализатора.
24. `final int LIMIT; LIMIT = 10; LIMIT = 20;` → **нет**, ошибка на третьем: variable LIMIT might already have been assigned. (Первое присваивание законно!)
25. `int count = null;` → **нет**: примитив не бывает null.
26. `String s = 'Привет';` → **нет**: строки — в двойных кавычках.
27. `char c = 'AB';` → **нет**: unclosed character literal.
28. `int 2players = 2;` → **нет**: имя не может начинаться с цифры.
29. `int Class = 3;` → **да!** `Class` — не ключевое слово (ключевое — `class`). Но так называть нельзя по стилю.
30. `double d = 5; int i = d;` → **нет**: possible lossy conversion; `double d = 5;` сам по себе законен.

### Скомпилируется, но что будет при запуске?
31. `String t = null; System.out.println(t.length());` → **NullPointerException**.
32. `System.out.println("Кот".charAt(3));` → **StringIndexOutOfBoundsException**.
33. `Integer.parseInt("3.5")` / `Integer.parseInt("")` / `Integer.parseInt(" 7")` → **NumberFormatException**.
34. Ввод `20⏎Анна⏎`, код `int age = sc.nextInt(); String name = sc.nextLine(); System.out.println(name + ": " + age);` → печатает `: 20` (пустое имя), «Анна» не прочитана.
35. На `nextInt()` пользователь ввёл `двадцать` → **InputMismatchException**.
36. В русской Windows на `nextDouble()` ввели `3.5` → **InputMismatchException** (нужно `3,5`).

### Найди ошибку
37. ```java
    int age = "25";
    String name = 'Аня';
    boolean ok = True;
    double price = 9.99;
    ```
    → три ошибки: строка в int, одинарные кавычки у строки, `True` вместо `true`.
38. ```java
    int total;
    int bonus = 5;
    total = total + bonus;
    ```
    → total читается до инициализации: variable total might not have been initialized.
39. ```java
    Scanner sc = new Scanner(System.in);
    String city = sc.next();       // пользователь вводит «Нижний Новгород»
    ```
    → логическая ошибка: next() прочитает только «Нижний».

### Почему здесь ошибка?
Покажи код и сообщение javac, попроси объяснить своими словами:
40. `error: incompatible types: possible lossy conversion from double to int` на `int sum = total * price;` (price — double) → результат double, в int без приведения нельзя; либо `double sum`, либо `(int)` с осознанной потерей.
41. `error: cannot assign a value to final variable MAX` → константу поменять нельзя.
42. `error: variable a is already defined in method main(String[])` → тип при повторном присваивании не пишут.
43. `error: cannot find symbol … class Scanner` → забыли `import java.util.Scanner;`.
