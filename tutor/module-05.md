## Цели модуля и вопросы

Формат: вопрос → **суть правильного ответа** → типичные заблуждения.

### О1. Зачем циклы и как работает while
- «Чем `while` отличается от `if`?» → **`if` проверяет условие один раз, `while` — перед каждым кругом, пока оно верно.**
- «Назови три части цикла» → **подготовка (до цикла), условие, шаг (меняет переменную условия).**
- «Может ли тело while не выполниться ни разу?» → **да, если условие ложно с самого начала.**
- «Что такое итерация?» → **один проход по телу.**
- Заблуждение: «после цикла i равно последнему напечатанному». Нет: после `while (i <= 3)` i = 4.

### О2. Бесконечный цикл
- «Почему программа зависла? Как остановить?» → **условие никогда не становится ложным; красный квадрат Stop / Ctrl+F2.**
- «Назови 3 причины вечного цикла» → **нет шага; шаг в другую сторону; `continue` перед шагом в while; `;` после `while (…)`; `!=` вместо `<` при шаге через одно.**
- «Бывают ли бесконечные циклы нарочно?» → **да: игры, серверы; `while (true)` + `break`.**

### О3. for
- «Порядок выполнения частей for?» → **подготовка один раз; затем условие → тело → шаг → условие…**
- «Когда выполняется шаг?» → **после тела**, хотя записан в заголовке. Частое заблуждение — «перед телом».
- «Сколько раз выполнится `for (int i = 0; i <= n; i++)`?» → **n + 1.** А `i = 0; i < n` и `i = 1; i <= n` — по n.
- «Где видна переменная i из заголовка for?» → **только внутри цикла.**
- «Напиши заголовок для 10 8 6 4 2 / для 1 2 4 8 … 1024.»

### О4. do-while, break, continue, выбор цикла
- «Чем do-while отличается от while?» → **проверка после тела, тело хотя бы один раз; `;` в конце обязательна.**
- «Пример, где нужен do-while» → **переспрашивать ввод, пока он неверный; меню «сыграть ещё?».**
- «break vs continue?» → **break — выйти из цикла; continue — пропустить остаток круга.**
- «Почему continue в while опасен?» → **может перепрыгнуть шаг → вечный цикл. В for continue ведёт на шаг.**
- «Как выбрать цикл?» → **число кругов известно — for; «пока не случится» — while; «хотя бы раз» — do-while.**

### О5. Вложенные циклы
- «В каком порядке обходятся клетки прямоугольника 3×5?» → **строка за строкой; на каждом круге внешнего внутренний проходит целиком, с начала.**
- «Где стоит `println()` и почему?» → **после внутреннего цикла, внутри внешнего — один перевод строки на строку картинки.**
- «Сколько раз выполнится тело внутреннего?» → **A × B; для треугольника `j <= i` — 1 + 2 + … + N.**
- «break во внутреннем цикле — что остановится?» → **только внутренний.**
- «Как подойти к рисованию фигуры?» → **табличка «строка → пробелы → символы» для маленького N, формула через номер строки, псевдокод.** Ёлочка: пробелов `N − row`, звёзд `2·row − 1`.

### О6. Роли переменных (Мастерская)
- «Назови роли и начальные значения» → **шагающая; счётчик = 0; накопитель суммы = 0, произведения = 1; рекордсмен = первое значение; флаг = false; последнее значение/временная.**
- «Почему max нельзя начинать с 0?» → **все числа могут быть отрицательными — получится 0, которого не было.**
- «Почему у флага не должно быть `else found = false`?» → **флаг «забудет», что уже находил.**
- «Зачем временная переменная в Фибоначчи?» → **чтобы не потерять старое значение при сдвиге пары.**
- Дай любой короткий код с циклом и спроси: «Какая роль у каждой переменной?»

### О7. Цифры числа
- «Что дают `n % 10` и `n / 10`?» → **последнюю цифру и число без неё.**
- «Скелет обработки цифр» → **`while (n > 0) { digit = n % 10; …; n = n / 10; }`, кругов столько, сколько цифр.**
- «Как приписать цифру справа к числу?» → **`result * 10 + digit` (×10 сдвигает влево и освобождает место).**
- «Что делает этот скелет с 0 и с отрицательным числом?» → **цикл не выполнится ни разу.** Для количества цифр 0 нужно обработать (do-while или особый случай); для отрицательных — `n != 0` (в Java `-123 % 10 == -3`).

### О8. Типичные ошибки
- «Что такое off-by-one? Как защищаться?» → **лишний/недостающий круг; проверять первое и последнее значение, формула b − a + 1.**
- «Что не так с `while (i < 5); { i++; }`?» → **`;` = пустое тело, вечный цикл.**
- «Почему `int sum = 0;` внутри цикла — ошибка?» → **обнуляется каждый круг и не видна после цикла (область видимости до `}`).**
- «Когда объявлять внутри — правильно?» → **когда значение нужно только на один круг (сумма каждой строки).**

### О9. Шаблон «Мастерской» и отладчик
- «Перечисли 6 шагов шаблона» → **вход/выход с примерами → руками → роли → псевдокод → код → трассировка.**
- «С чего начнёшь задачу “разверни строку”?» → **с примеров и решения руками, а не с кода.** Ученик должен сам пересказать план: шагающая i с конца, накопитель result, приписываю букву справа.
- «Как в IDEA посмотреть значения переменных на каждом круге?» → **точка останова, Debug, F8 / F9, окно Variables.**

## Банк головоломок

Давай по одной. Сначала ответ и «почему», потом разбор. ★★★ — предупреждай, что со звёздочкой.

### Сколько раз выполнится? Что выведется?
1. `for (int i = 0; i < 5; i++)` / `i <= 5` / `i = 1; i < 5` → **5 / 6 / 4.**
2. `int i = 0; while (i++ < 3) System.out.print(i);` → **`123`** (i++ отдаёт старое значение для сравнения; после цикла i = 4).
3. `int i = 0; while (++i < 3) System.out.print(i);` → **`12`** (++i сначала увеличивает).
4. ```java
   for (int i = 0; i < 3; i++)
       for (int j = 0; j < 2; j++)
           System.out.print(i * j);
   ```
   → **`000102`**
5. ```java
   for (int i = 1; i <= 3; i++) {
       for (int j = 1; j <= 3; j++) {
           if (j == i) break;
           System.out.print(j);
       }
   }
   ```
   → **`112`** (break только из внутреннего).
6. То же, но `continue` вместо `break` → **`23` `13` `12` → `231312`.**
7. `int x = 10; do { x -= 3; } while (x > 0); System.out.println(x);` → **`-2`** (выход, когда граница уже перешагнута).
8. `for (int i = 1; i <= 5; i++) { if (i == 3) continue; if (i == 5) break; System.out.print(i); }` → **`124`**
9. `int n = 1000, c = 0; while (n > 1) { n /= 10; c++; }` → **c = 3** (с `n > 0` было бы 4).
10. `for (int i = 1; i < 100; i *= 3) System.out.print(i + " ");` → **`1 3 9 27 81`**
11. `int k = 5; do { System.out.print(k); } while (k < 3);` → **`5`** (do-while — минимум 1 раз).
12. `for (int i = 10; i > 0; i -= 4) System.out.print(i + " ");` → **`10 6 2`**
13. ★★★ `int sum = 0; for (int i = 1; i <= 100000; i++) sum += i; System.out.println(sum);` → **`705082704`** (переполнение int; правильно 5000050000 в long).
14. ★★★ `for (char c = 'a'; c <= 'e'; c += 2) System.out.print(c);` → **`ace`** (char — число-код, модуль 2).

### Скомпилируется, но что будет при запуске?
15. `for (;;) { System.out.println("Hi"); }` → **компилируется, бесконечно печатает** (пустое условие = true).
16. `for (int k = 0; k < 3; k++); { System.out.println("Hi"); }` → **Hi один раз** (`;` — пустое тело).
17. `int i = 0; while (i < 3); { i++; }` → **зависает** (пустое тело, i не меняется).
18. `int i = 0; while (i < 5) { if (i == 2) continue; i++; }` → **зависает на i = 2.**
19. `for (int i = 1; i != 10; i += 2)` → **вечный** (10 перешагнули).
20. ★★★ `for (byte b = 0; b < 200; b++)` → **вечный**: после 127 идёт −128.
21. `for (int i = 10; i > 0; i++)` → **почти вечный**: i растёт до переполнения int (≈2 млрд кругов), потом становится отрицательным и цикл кончается. Хороший вопрос «а он точно бесконечный?».

### Скомпилируется ли?
22. `for (int i = 0; i < 3; i++) { } System.out.println(i);` → **нет**: i не видна после цикла.
23. ★★★ `while (true) { System.out.println("A"); } System.out.println("B");` → **нет: unreachable statement** (компилятор видит константу true без break). С `break` внутри — да.
24. `int i = 0; do { int k = i * 2; i++; } while (k < 6);` → **нет**: k не видна в условии while.
25. `do { … } while (x > 0)` без `;` → **нет**: `';' expected`.
26. `for (int i = 0, j = 10; i < j; i++, j--)` → **да!** В заголовке for можно несколько переменных через запятую (★★★, для любопытных).

### Найди ошибку
27. Сумма 1..3: `for (…) { int sum = 0; sum += i; } System.out.println(sum);` → **sum внутри цикла: обнуляется и не видна снаружи.**
28. Сумма нечётных: `if (i % 2 == 1) { sum = i; }` → **`=` вместо `+=`**, выведет последнее нечётное.
29. Максимум: `int max = 0; … if (x > max) max = x;` → **ломается на отрицательных.**
30. Флаг: `if (x == 7) found = true; else found = false;` → **флаг забывает находку.**
31. Прямоугольник печатается в одну строку: `println()` после **внешнего** цикла, а не внутри него.
32. Сумма цифр: `n = n / 10;` стоит **перед** `digit = n % 10;` → последняя цифра теряется.

### Почему здесь ошибка?
33. `error: cannot find symbol … symbol: variable count` после цикла → **count объявлен внутри тела цикла.**
34. `error: unreachable statement` после `while (true) { … }` → **нет break — компилятор знает, что код ниже недостижим.**
35. Сайт: «Программа работала дольше 5 секунд…» → **бесконечный цикл или программа ждёт ввода (Scanner читает больше чисел, чем подали).**

## Задачи Мастерской для экзамена

Не на сайте. Дай одну (или две, если первая прошла легко). Требуй план до кода. Эталона нет — проверяешь рассуждение и трассировку.

1. **Самая большая цифра числа.** 5293 → 9; 0 → 0; 7 → 7. *Ожидаемый план:* скелет цифр + рекордсмен (старт с первой цифры или с 0 — тут 0 допустим, т.к. цифры ≥ 0: хороший вопрос «почему здесь max = 0 не ловушка?»).
2. **Есть ли в числе цифра 7?** 1745 → да, 123 → нет. *План:* скелет цифр + флаг (+ break). Спроси про 7 и 0.
3. **Палиндром.** 12321 → да, 1231 → нет. *План:* сохранить копию n, развернуть, сравнить `==`. Ловушка: развернули сам n, а копию не сохранили — сравнивать не с чем.
4. **Сумма чётных цифр.** 123456 → 12. Скелет + условие + накопитель.
5. **Сколько раз число делится на 2 без остатка** (степень двойки в числе): 48 → 4, 7 → 0. *План:* while (n % 2 == 0) { n /= 2; count++ }. Ловушка: n = 0 → вечный цикл (0 % 2 == 0 всегда). Отличный граничный случай!
6. **НОД двух чисел перебором:** от min(a, b) вниз до 1, первый общий делитель → break. *Роли:* шагающая вниз, break как «нашёл».
7. **Рамка из звёздочек N×N** (внутри пробелы): табличка + условие «первая/последняя строка или первый/последний столбец».
