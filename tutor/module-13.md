## Цели модуля и вопросы

Формат: вопрос → **суть правильного ответа** → типичные заблуждения.

### О1. Зачем коллекции, List и ArrayList (урок 13.1)
- «Чем ArrayList лучше массива? А чем хуже?» → **размер меняется сам, есть add/remove/contains, красиво печатается; хуже — хранит только объекты (обёртки), чуть больше памяти.**
- «Что внутри у ArrayList?» → **обычный массив с запасом; кончилось место — новый массив в 1,5 раза больше, элементы копируются.**
- «Почему `List<String> x = new ArrayList<>()`, а не `ArrayList<String> x`?» → **программируем через интерфейс: остальной код зависит от контракта, реализацию легко заменить.**
- «Что будет: `List.of("a").add("b")`?» → **UnsupportedOperationException при запуске; компилятор молчит — add есть в интерфейсе.**
- Заблуждение: `size()` = ёмкость. Нет, размер — число элементов; ёмкость скрыта.
- Заблуждение: `list.length` / `list.length()`. У списка — `size()`.

### О2. Generics и обёртки (урок 13.2)
- «Зачем угловые скобки?» → **компилятор знает тип элементов: не даст положить чужое, не нужно приводить при get; ошибка переезжает из запуска в компиляцию.**
- «Почему нельзя `List<int>`?» → **коллекции хранят объекты (ссылки), int — примитив; нужна обёртка Integer.**
- «Что такое автоупаковка/распаковка? Когда распаковка падает?» → **Java сама вызывает Integer.valueOf / intValue; распаковка null — NullPointerException.**
- «Почему `Integer a = 127, b = 127; a == b` → true, а для 128 — false?» → **кэш −128..127: valueOf отдаёт готовый объект; 128 — каждый раз новый объект, == сравнивает ссылки. Сравнивать через equals.** Попросить нарисовать стек/кучу.
- «`Integer x = 1000; int y = 1000; x == y`?» → **true: с одной стороны примитив — распаковка и сравнение чисел.**
- Заблуждение: «== для Integer сравнивает числа». Только случайно, на кэше.

### О3. remove(int) и remove(Object) (уроки 13.1–13.2)
- «В `List<Integer> [10, 20, 1]` вызвали `remove(1)`. Что осталось?» → **[10, 1]: int-аргумент — индекс (точное совпадение перегрузки без упаковки).**
- «Как удалить значение 1?» → **`remove(Integer.valueOf(1))`.**

### О4. Перебор и ConcurrentModificationException (урок 13.3)
- «Три способа обойти список и когда какой?» → **по индексу (нужен номер, только List), for-each (обычно), Iterator (удаление во время обхода).**
- «Почему `list.remove` внутри for-each падает?» → **for-each — скрытый итератор; список изменён в обход него, итератор сверяет счётчик изменений в next() и бросает CME.**
- «Как правильно?» → **Iterator + it.remove() после it.next(); или цикл по индексу с конца.** (removeIf — модуль 14.)
- «Что не так с удалением в цикле по индексу от начала?» → **после удаления хвост сдвигается, i++ перепрыгивает следующий элемент — тихая ошибка без исключения.**
- ★ «Почему удаление предпоследнего элемента в for-each не падает?» → **hasNext() сравнивает позицию с размером, они совпали — цикл выходит до проверки в next(); последний элемент не проверен.**

### О5. Set, equals и hashCode (урок 13.4)
- «Чем отличаются HashSet, LinkedHashSet, TreeSet?» → **порядок: никакого / добавления / отсортировано. Уникальность у всех.**
- «Как HashSet ищет элемент быстро?» → **hashCode → номер корзины, equals — сравнение только внутри корзины.** Попросить нарисовать корзины.
- «Свой класс Point без equals/hashCode, две равные точки в HashSet — сколько элементов? А если только equals?» → **2 и (почти всегда) 2: разные хеш-коды → разные корзины, equals не вызывается. Нужны оба (или record).**
- «Контракт equals/hashCode?» → **равные по equals обязаны иметь равные hashCode; обратное не обязательно (коллизии).**
- «TreeSet своих объектов без Comparable?» → **ClassCastException при первом add.**
- «Как проверить, что у всех заказов в выгрузке разные номера?» → **`new HashSet<>(ids).size() == ids.size()`.**
- Заблуждение: «HashSet печатает в порядке добавления» — нет гарантий.

### О6. Map (урок 13.5)
- «Что вернёт `get` по отсутствующему ключу? Чем опасно?» → **null; `int x = map.get(k)` — NullPointerException; безопасно — getOrDefault или containsKey.**
- «Что делает `put` с существующим ключом? Что он возвращает?» → **заменяет значение, возвращает старое (или null).**
- «Как перебрать пары?» → **`for (Map.Entry<K, V> e : map.entrySet())`, getKey/getValue.**
- «HashMap / LinkedHashMap / TreeMap — разница?» → **порядок: нет / добавления / по ключам (не по значениям!).**
- «Почему Map — не Collection?» → **хранит пары, а не элементы; обходят её виды keySet/values/entrySet.**

### О7. Очереди и стек (урок 13.6)
- «FIFO и LIFO — примеры из жизни?» → **очередь в кассу / стопка тарелок, «Назад» в браузере, Ctrl+Z, стек вызовов.**
- «Чем стек делать в Java?» → **ArrayDeque: push/pop/peek; класс Stack устарел.**
- «poll() и remove() на пустой очереди?» → **null и NoSuchElementException.** `pop()` на пустом стеке — NoSuchElementException.
- «Что напечатает `println(priorityQueue)`?» → **внутренний порядок кучи, не отсортированный; по порядку — только poll() по одному.**
- «ArrayList или LinkedList?» → **get(i): ArrayList мгновенно, LinkedList проход; вставка в начало: LinkedList быстро, ArrayList сдвиг. На практике почти всегда ArrayList, очередь/стек — ArrayDeque.**

### О8. Сортировка: Comparable и Comparator (урок 13.7)
- «Чем Comparable отличается от Comparator?» → **Comparable — класс сам умеет сравниваться (compareTo, один естественный порядок); Comparator — отдельный судья (compare(a, b)), сколько угодно порядков.**
- «Что значит результат compare: −3, 0, 7?» → **a раньше / равны / a позже; важен только знак.**
- «Как отсортировать по убыванию?» → **поменять a и b местами в compare, или Collections.reverseOrder(…).**
- «Как сортировать по двум полям?» → **сравнить по первому; не 0 — вернуть; иначе сравнить по второму.**
- ★ «Почему `return a.x - b.x` — плохой компаратор?» → **переполнение int при больших значениях разных знаков; Integer.compare.**
- Заблуждение: «Collections.sort возвращает новый список» — нет, сортирует на месте; List.of отсортировать нельзя.

### О9. Свои generics (урок 13.8)
- «Напиши класс `Box<T>` с put/get» — устно или в чате.
- «Где пишут `<T>` у обобщённого метода?» → **перед типом результата: `static <T> T lastOf(List<T> list)`.**
- «Почему нельзя `new T()`?» → **тип неизвестен (и стирается после компиляции).**
- ★ «Почему `List<Integer>` нельзя присвоить в `List<Number>`?» → **иначе через него добавили бы Double в список Integer. Для чтения — `List<? extends Number>`.** Глубоко не требовать.

### О10. Выбор коллекции (урок 13.9)
- Дать 4–5 задач из реальных программ (магазин, банк, игра), ученик выбирает коллекцию и объясняет по дереву: **по ключу → Map; уникальные → Set; с краёв → ArrayDeque; по важности → PriorityQueue; иначе ArrayList. Потом реализация по порядку: Hash / Linked / Tree.**
- «Как проверить "в заказе ровно эти товары, порядок не важен"?» → **сравнить множества: Set.equals игнорирует порядок; List.equals — нет.**

## Банк головоломок

Давай по одной. Сначала ответ и «почему», потом разбор. ★★★ — со звёздочкой, честно предупреждай, что это на опережение.

### Что выведется?
1. `Integer a = 127, b = 127; Integer c = 128, d = 128; System.out.println((a == b) + " " + (c == d));` → `true false` (кэш −128..127).
2. `Integer x = 1000; int y = 1000; System.out.println(x == y);` → `true` (распаковка).
3. `List<Integer> l = new ArrayList<>(List.of(1, 2, 3)); l.remove(1); System.out.println(l);` → `[1, 3]`.
4. `List<Integer> l = new ArrayList<>(List.of(5, 0, 7)); l.remove(Integer.valueOf(0)); System.out.println(l);` → `[5, 7]`.
5. `Set<String> s = new LinkedHashSet<>(List.of("б", "а", "б", "в")); System.out.println(s);` → `[б, а, в]`.
6. `Map<String, Integer> m = new HashMap<>(); System.out.println(m.put("k", 1) + " " + m.put("k", 2) + " " + m.get("k"));` → `null 1 2`.
7. `Map<String, Integer> m = new TreeMap<>(); m.put("b", 1); m.put("a", 2); System.out.println(m);` → `{a=2, b=1}` (сортировка по ключам).
8. `Deque<Integer> s = new ArrayDeque<>(); s.push(1); s.push(2); s.push(3); System.out.println(s.pop() + " " + s.peek());` → `3 2`.
9. `Queue<Integer> q = new ArrayDeque<>(List.of(1, 2, 3)); q.poll(); q.offer(4); System.out.println(q);` → `[2, 3, 4]`.
10. `System.out.println(List.of(1, 2).equals(List.of(2, 1)) + " " + Set.of(1, 2).equals(Set.of(2, 1)));` → `false true`.
11. Цикл по индексу удаляет пустые строки из `["a", "", "", "b"]` с `i++` → в списке останется `[a, , b]` (одна пустая перепрыгнута).
12. ★ `PriorityQueue<Integer> pq = new PriorityQueue<>(List.of(5, 1, 4, 2, 3)); System.out.println(pq.poll() + " " + pq.poll());` → `1 2`. А `println(pq)` сразу после создания → `[1, 2, 4, 5, 3]` (не отсортировано).
13. `Map<Character, Integer> m = new TreeMap<>(); for (char c : "банан".toCharArray()) m.put(c, m.getOrDefault(c, 0) + 1); System.out.println(m);` → `{а=2, б=1, н=2}`.
14. ★★★ for-each по `[1, 2, 3]` удаляет `2` (предпоследний) → **без исключения**, `[1, 3]`.
15. `Collections.sort(w, Collections.reverseOrder())` для `["ёж", "кот", "ара", "ко"]` → `[ёж, кот, ко, ара]` (буква «ё» по коду после «я»; «ко» раньше «кот»).

### Скомпилируется ли?
16. `List<int> a = new ArrayList<>();` → **нет**: unexpected type, нужен Integer.
17. `List<Object> o = new ArrayList<String>();` → **нет**: incompatible types (List<String> не является List<Object>).
18. `Box<String> b = new Box<>(); b.put(5);` → **нет**: put принимает String.
19. `int x = lastOf(List.of("а", "б"));` (где `static <T> T lastOf(List<T>)`) → **нет**: T = String, в int не присвоить.
20. `for (String k : map) { }` для `Map<String, Integer>` → **нет**: Map не Iterable; нужно `map.keySet()`.
21. `Collections.sort(products);` где `Product` не реализует Comparable → **нет**: no suitable method found for sort.

### Скомпилируется, но что будет при запуске?
22. `List.of("a", "b").add("c");` → UnsupportedOperationException.
23. `Arrays.asList("a", "b").set(0, "x")` → работает; `.add("c")` → UnsupportedOperationException (★).
24. `Map<String, Integer> m = new HashMap<>(); int v = m.get("нет");` → NullPointerException (распаковка null).
25. for-each по `[1, -2, 3, 4]` с `list.remove(n)` для отрицательных → ConcurrentModificationException.
26. `new TreeSet<Point>().add(new Point(1, 2))` (Point без Comparable) → ClassCastException.
27. `new ArrayDeque<Integer>().pop()` → NoSuchElementException; а `poll()` → null.
28. `Iterator<String> it = list.iterator(); it.remove();` (до next) → IllegalStateException.
29. `new ArrayDeque<String>().push(null)` → NullPointerException.
