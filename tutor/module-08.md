## Цели модуля и вопросы

Формат: вопрос → **суть правильного ответа** → типичные заблуждения.

### О1. String — объект в куче
- «Нарисуй стек и кучу для `String name = "Мурзик"; int age = 3;`» → **age хранит 3 прямо в стеке; name — ссылку на объект String в куче, внутри которого символы и длина.**
- «Чем `""` отличается от `null`?» → **пустая строка — настоящий объект длины 0; null — ссылки нет. `"".length()` = 0, `null.length()` → NullPointerException.**
- «Что напечатает `String s = null; System.out.println(s + "!");`?» → **«null!» — при склейке null превращается в текст; падает только вызов метода у null.**
- Заблуждение: «в переменной String лежит сам текст».

### О2. Неизменяемость
- «Почему после `s.toUpperCase();` строка s осталась маленькими буквами?» → **методы String не меняют объект, а возвращают новый; результат нужно присвоить: `s = s.toUpperCase()`.**
- «Что происходит в памяти при `s = s + "!"`?» → **создаётся новый объект; стрелка s переставляется на него; старый, если на него нет ссылок, станет мусором.**
- «`String t = s; s = s + "!";` — изменилась ли t?» → **нет: t смотрит на старый объект, который никто не может изменить.** Сравнить с массивом из модуля 6, где изменение через вторую ссылку видно.
- «Зачем Java сделала строки неизменяемыми?» → **безопасно делиться ссылкой (никто не испортит), можно хранить литералы в пуле по одному экземпляру, надёжные ключи (модуль 13).**
- «Какая цена?» → **каждая склейка — новый объект; в цикле это медленно → StringBuilder.**

### О3. == и equals (классика собеседований)
- «Чем `==` отличается от `equals` для строк?» → **`==` сравнивает ссылки (тот же ли объект), `equals` — содержимое (те же ли символы).**
- «Почему `"Java" == "Java"` даёт true?» → **литералы хранятся в пуле строк в одном экземпляре — обе ссылки ведут на один объект. Это совпадение, а не сравнение текста.**
- «А `new String("Java") == "Java"`?» → **false: new всегда создаёт новый объект.**
- «Строка из Scanner `== "да"`?» → **false: Scanner создаёт новый объект вне пула.**
- «Как сравнить, если переменная может быть null?» → **`"да".equals(x)` — вернёт false, не упадёт.**
- «Как без учёта регистра?» → **`equalsIgnoreCase`.**
- ★ «Что такое `intern()`?» → **возвращает «пуловую» версию строки.** ★ «Почему `"Ja" + "va" == "Java"` — true, а `part + "va" == "Java"` — false?» → **склейку литералов делает компилятор (константа), склейка с переменной — при выполнении, новый объект.**
- Заблуждение: «`==` иногда работает, значит можно». Заблуждение: «equals сравнивает адреса, а == текст» (путает местами).
- Связь с тестами: `assertEquals`/`isEqualTo` — через equals, `assertSame` — через ==.

### О4. Индексы, substring, поиск
- «Последний индекс строки?» → **`length() - 1`; `charAt(length())` → StringIndexOutOfBoundsException.**
- «Чем `s.length()` отличается от `arr.length`?» → **у строки метод (со скобками), у массива поле.**
- «Что вернёт `"Hello".substring(1, 3)`? Почему?» → **«el»: начало включительно, конец — нет; длина = 3 − 1.** Числа — «разрезы между символами».
- «`"Hello".substring(5)`? `substring(6)`?» → **пустая строка; исключение.**
- «Что вернёт `indexOf`, если не нашёл?» → **−1.** «Чем опасно `s.substring(0, s.indexOf('@'))`?» → **если @ нет — substring(0, −1) → исключение; нужна проверка.**
- Вырезать домен из email, расширение файла (`lastIndexOf('.')`).

### О5. Методы-преобразования и split
- `trim`/`strip`, `isEmpty`/`isBlank`, `toUpperCase`, `replace`, `repeat`, `String.join`, `String.valueOf`, `Integer.parseInt`.
- «Чем `isEmpty` отличается от `isBlank`?» → **isBlank — true и для строки из одних пробелов.**
- «Что вернёт `"  кот   пёс ".split(" ")`?» → **с пустыми строками в начале и посередине; рецепт: `trim().split("\\s+")`.**
- «`"".split(" ").length`?» → **1 (массив с одной пустой строкой) — поэтому для пустого ввода проверяем isBlank отдельно.**
- «`"a,b,,c,,".split(",").length`?» → **4: пустые в середине остаются, в конце отбрасываются.**
- «`String.valueOf(42) + 1`? `Integer.parseInt("42") + 1`?» → **"421" и 43.**

### О6. Символы
- «Что такое char на самом деле?» → **число — код символа в Юникоде.**
- «`'a' + 1`? `(char) ('a' + 1)`? `'7' - '0'`?» → **98, 'b', 7.**
- «Почему `s.charAt(1) + s.charAt(2)` даёт число?» → **char + char — сложение кодов; склейка только если слева уже строка.**
- «Как проверить, что символ — цифра/буква/заглавная?» → **`Character.isDigit / isLetter / isUpperCase`; это статические методы, как в модуле 7.**
- «Как сравнить два символа?» → **`==` (примитивы). `c == "a"` не скомпилируется.**
- ★ «Почему проверка `c >= 'а' && c <= 'я'` пропускает ё?» → **ё (1105) вне диапазона а…я (1072…1103).**

### О7. StringBuilder
- «Зачем нужен StringBuilder?» → **изменяемая строка: append дописывает в тот же объект, без копирования всего текста; для сборки в цикле.**
- «Почему `s += c` в цикле медленно?» → **каждый раз новый объект и копия всего текста: для n символов ≈ n²/2 копирований (100 000 → ~5 млрд).**
- «Нужен ли StringBuilder для `"Привет, " + name`?» → **нет, компилятор оптимизирует одну склейку сам.**
- «`sb1.equals(sb2)` при одинаковом тексте?» → **false — у StringBuilder equals сравнивает ссылки; сравнивать `toString()`.**
- «Нужно ли присваивать результат `sb.append(...)`?» → **нет, меняется сам объект (в отличие от String).**
- ★ «String vs StringBuilder vs StringBuffer» → **неизменяемая / изменяемая быстрая / изменяемая потокобезопасная (медленнее).**

### О8. Форматирование
- «Что делают `%s %d %.2f %n %%`?»
- «`printf("%5d", 42)` / `%-5s` / `%05d`?» → **ширина и выравнивание; дополнение нулями.**
- «Почему у тебя печатается 4,57, а на сервере 4.57?» → **локаль: русская Windows — запятая; явно — `Locale.US`.**
- «Что будет: `String.format("%d", 3.5)`?» → **IllegalFormatConversionException при запуске, компилятор не ловит.**
- «Чем `printf` отличается от `String.format`?» → **печатает / возвращает строку.**
- Текстовые блоки `"""`: перевод строки после открывающих кавычек, общий отступ убирается, кавычки не экранируются (Java 15+).

### О9. Мастерская: решение задач на строки
- Ученик сам проговаривает шаблон: примеры (пустая строка, один символ, пробелы, регистр) → руками → роли → псевдокод → код → трассировка.
- «Разверни строку без reverse» → **i от length()−1 до 0 включительно + накопитель; или два указателя на char[]. Граничные: "" и одна буква — проверить вслух.**
- «Палиндром с игнором регистра и знаков» → **сначала чистка (isLetterOrDigit + toLowerCase), потом два указателя навстречу, несовпадение — сразу false.**
- Типичные ошибки, о которых спрашивать: старт с `length()` вместо `length() - 1`; `i > 0` вместо `i >= 0`; забытая последняя серия в сжатии; печать внутри цикла в проверке пароля; падение на пустой строке после split.
- ★ Регулярки (урок «для любопытных», на экзамене не требовать): `matches` проверяет строку целиком; `replaceAll("\\D", "")`; `split(".")` — пустой массив.

## Банк головоломок

Давай по одной. Сначала ответ и «почему», потом разбор. ★★★ — со звёздочкой.

### Что выведется?
1. ```java
   String a = "hello";
   String b = "hel" + "lo";
   String c = new String("hello");
   System.out.println(a == b);
   System.out.println(a == c);
   System.out.println(a.equals(c));
   ```
   → `true`, `false`, `true` (склейка литералов при компиляции → пул; new → новый объект).
2. ```java
   String part = "hel";
   String b = part + "lo";
   System.out.println(b == "hello");
   ```
   → `false` (склейка с переменной — при выполнении, новый объект).
3. `String s = "java"; s.toUpperCase(); s.concat("!"); System.out.println(s);` → `java`.
4. `String s = "Ку"; String t = s; s += "-ку"; System.out.println(t);` → `Ку`.
5. `System.out.println("a" + 1 + 2); System.out.println(1 + 2 + "a");` → `a12`, `3a`.
6. `System.out.println('a' + 1); System.out.println("" + 'a' + 1);` → `98`, `a1`.
7. `System.out.println('a' + 1 + "b" + 'c' + 1);` → `98bc1`.
8. `String s = "Java"; System.out.println(s.charAt(1) + s.charAt(2));` → `215` ('a' 97 + 'v' 118).
9. `char c = 'x'; c++; System.out.println(c);` → `y` (++ сохраняет тип char). А `c = c + 1;` — **не скомпилируется** (int в char без приведения).
10. `System.out.println("Hello".substring(1, 3) + "Hello".substring(4));` → `elo`.
11. `System.out.println("a,b,,c,,".split(",").length);` → `4`.
12. `System.out.println("".split(",").length);` → `1`.
13. `String s = null; System.out.println(s + "!");` → `null!`.
14. `System.out.println("banana".indexOf("an") + " " + "banana".lastIndexOf("an"));` → `1 3`.
15. ```java
    StringBuilder x = new StringBuilder("ok");
    StringBuilder y = x;
    y.append("!");
    System.out.println(x);
    ```
    → `ok!` (StringBuilder изменяемый, две ссылки на один объект).
16. `System.out.println(new StringBuilder("ab").equals(new StringBuilder("ab")));` → `false`.
17. `System.out.println(String.format("|%5d|%-4s|", 42, "ab"));` → `|   42|ab  |`.
18. `System.out.println("  hi  ".trim().length() + "   ".length());` → `5` (2 + 3 — числа складываются, строк в выражении нет).
19. ★★★ `System.out.println("a.b".replaceAll(".", "*"));` → `***` (точка — регулярка «любой символ»).

### Скомпилируется ли?
20. `if (s.charAt(0) == "J")` → **нет**: incomparable types: char and String.
21. `int n = "abc".length;` → **нет**: у строки length() — метод.
22. `int n = arr.length();` (arr — массив) → **нет**: у массива length — поле.
23. `String s = new StringBuilder("a");` → **нет**: разные типы, нужен `toString()`.
24. `char c = 'a'; c = c + 1;` → **нет**: possible lossy conversion from int to char. `c += 1` и `c++` — компилируются.
25. `if ("a" < "b")` → **нет**: < не применяется к строкам; есть `compareTo`.

### Скомпилируется, но что при запуске?
26. `String s = null; if (s.equals("да")) {…}` → NullPointerException. Починка: `"да".equals(s)`.
27. `"Hello".substring(2, 6)` → StringIndexOutOfBoundsException (длина 5).
28. `String.format("Цена: %d", 99.9)` → IllegalFormatConversionException.
29. `String.format("%s и %s", "a")` → MissingFormatArgumentException.
30. `"2.10.3".split(".")[0]` → ArrayIndexOutOfBoundsException (массив пустой).
31. `Integer.parseInt("42 руб.")` → NumberFormatException.
32. `for (int i = s.length(); i >= 0; i--) System.out.print(s.charAt(i));` → StringIndexOutOfBoundsException на первой итерации.

### Найди ошибку
33. ```java
    Scanner sc = new Scanner(System.in);
    String login = sc.nextLine();
    login.trim();
    if (login == "admin") { … }
    ```
    → результат trim потерян; == вместо equals (две логические ошибки, компилятор молчит).
34. ```java
    String result = null;
    for (char c : s.toCharArray()) {
        result = result + c;
    }
    ```
    → накопитель начат с null — результат начнётся со слова «null». Нужно `""`.
35. ```java
    for (int i = 0; i < pass.length(); i++) {
        if (Character.isDigit(pass.charAt(i))) {
            System.out.println("Есть цифра");
        } else {
            System.out.println("Нет цифр");
        }
    }
    ```
    → «Нет цифр» печатается для каждого не-цифрового символа. Решение «нет» — только после цикла, через флаг.
36. Палиндром: в цикле `while (left < right)` есть `left++`, но нет `right--` → неверный ответ для «abca».

### Почему здесь ошибка?
37. `error: incomparable types: char and String` → сравнение символа со строкой в двойных кавычках.
38. `Exception in thread "main" java.lang.StringIndexOutOfBoundsException: begin 0, end -1, length 9` → substring с результатом indexOf = −1 (разделитель не найден).
39. `java.util.IllegalFormatConversionException: d != java.lang.Double` → `%d` для дробного числа.

## Задачи Мастерской (для экзамена вживую)

Формат: ученик пишет примеры с граничными случаями, роли, псевдокод — ты одобряешь — потом код — потом трассировка на одном граничном случае. Подсказывай вопросами по шаблону, не кодом.

1. **Первый неповторяющийся символ** («swiss» → `w`; «aabb» → нет). Роли: шагающая + внутренний счётчик (или подсчёт через второй цикл). Граничные: пустая строка, все повторяются.
2. **Анаграммы** («листок» и «слиток» → да). План: привести к нижнему регистру, `toCharArray`, `Arrays.sort`, сравнить `Arrays.equals` (модуль 6). Граничные: разная длина, пробелы.
3. **Развернуть порядок слов** («я люблю java» → «java люблю я»). split + обход массива с конца + StringBuilder; не путать с разворотом символов.
4. **Убрать повторы подряд** («aaabccdd» → «abcd»). Роль «предыдущий символ». Граничные: пустая, одна буква.
5. **Сумма цифр в строке** («a1b22c3» → 8). Character.isDigit + `c - '0'`.
6. **Шифр Цезаря** (сдвиг латиницы на k, «abz», k=1 → «bca»). `(char) ('a' + (c - 'a' + k) % 26)`. ★★★
7. **Самое частое слово** — только для быстрых: без коллекций это двойной цикл; отметь, что в модуле 13 это решается через HashMap.
