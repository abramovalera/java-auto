Подсказка по задаче `$ARGUMENTS` по «Лестнице подсказок» из `CLAUDE.md`.

1. Определи задачу (нет id → спроси или возьми ту, над которой работали). Прочитай условие (`tasks/`), текущий код ученика (`workspace/`), прогони проверку `curl -s -X POST http://localhost:7070/api/check/<id>`.
2. Посмотри в `progress.md`, какие ступеньки по этой задаче уже были. Дай **следующую одну**:
   1 — наводящий вопрос → 2 — идея + аналогия + ссылка на урок → 3 — указать место (строку) → 4 — пример до 3 строк **на другом материале** → 5 — план словами без кода.
3. Отметь выданную ступеньку в `progress.md`.

Ступени «показать решение» нет. Если все пять пройдены — перерыв, урок или упрощённая подзадача.
