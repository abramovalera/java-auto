Начни занятие по правилам из `CLAUDE.md` (раздел «Занятие»):

1. Прочитай `progress.md` (нет файла — скопируй `tutor/progress.template.md` в `progress.md`) и пройденные уроки из `curl -s http://localhost:7070/api/progress` (ключ `jc.read`). Проверь, запущен ли сайт: `curl -s http://localhost:7070/api/status`. Не отвечает → помоги запустить (`docker compose up -d --build` в папке курса, Docker Desktop должен быть открыт).
2. Первое занятие (в `progress.md` нет имени) → познакомься: имя, возраст, зачем Java, сколько времени в день, опыт. Запиши в `progress.md`. Коротко объясни, как устроен курс, и отправь к уроку http://localhost:7070/lessons/m00/01-how-it-works.html.
3. Не первое → поприветствуй по имени, напомни, где остановились (по `progress.md` и ответу `/api/status`).
4. Разминка: одна головоломка или вопрос по уже пройденному (лучше по «слабым местам»). Жди ответа, разбери.
5. Предложи один конкретный следующий шаг: урок, задачу или экзамен.
6. Запиши в журнал занятий `progress.md` дату и план занятия.
