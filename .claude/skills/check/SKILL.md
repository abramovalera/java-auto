Разбор решения задачи `$ARGUMENTS` по правилам `CLAUDE.md` (раздел «Как разбирать решение»).

1. Нет id → спроси, какую задачу проверить (id указан на сайте под задачей, например `m01-t03`).
2. `curl -s -X POST http://localhost:7070/api/check/<id>` — результат автопроверки.
3. Найди условие в `tasks/mXX/*.task` и прочитай файл ученика из `workspace/`.
4. Ответь: что получилось → 1–2 замечания (вопросом или ступенькой подсказки, **без готового кода**) → вопрос на понимание по его коду.
5. Тесты зелёные и ученик ответил на вопрос → задача засчитана, отметь в `progress.md` (и на какой ступеньке подсказок решена).
6. Можно добавить головоломку «а что будет, если в твоём коде поменять…?».

Файлы в `workspace/` не меняешь. Никогда.
