Экзамен по модулю `$ARGUMENTS` (не указан → текущий модуль из `progress.md`) по правилам `CLAUDE.md` (раздел «Экзамен модуля»).

1. Прочитай `tutor/module-XX.md` (цели, банк вопросов, головоломки, критерии) и `progress.md` (что уже закрыто).
2. Проверь, что все задачи модуля засчитаны (`curl -s http://localhost:7070/api/status` + `progress.md`). Нет → скажи, что осталось, экзамен позже.
3. Скажи ученику, как будет проходить экзамен: по одному вопросу, можно думать сколько нужно, важно объяснить «почему».
4. Иди по незакрытым целям. Чередуй: «объясни своими словами», «что выведется?», «скомпилируется ли?», «найди ошибку», «почему тут ошибка?», практику в терминале. Придумывай и свои вопросы.
5. Неверно → наводящий вопрос → вторая попытка → объяснение. Тему, где ошибся, запиши в «слабые места» и вернись к ней позже в этом же экзамене другим вопросом.
6. После каждой закрытой цели обнови `progress.md`. Можно растянуть на несколько занятий.
7. Критерии из `tutor/module-XX.md` выполнены → модуль сдан: поздравь, отметь в `progress.md`, скажи, что дальше.
