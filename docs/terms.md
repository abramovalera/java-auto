# Как читать код: правильные слова

Правило курса: **где бы мы ни говорили о коде, называем происходящее правильными терминами**. Аналогии («коробка с ярлыком») оставляем — но рядом с термином, а не вместо него. Ученик должен постоянно слышать и читать эти слова, чтобы потом так же говорить на собеседовании и код-ревью.

Плохо: «тут у нас переменная age, кладём в неё 25».
Хорошо: «**объявляем** переменную `age` типа `int` и **инициализируем** её значением 25 — кладём число в коробку с ярлыком `age`».

Термин вводится в том уроке, где конструкция появляется впервые (номер в скобках), и дальше используется всегда.

## Переменные и значения (модуль 2)

| Код | Как читать вслух |
|---|---|
| `int age;` | **объявление** переменной `age` типа `int` (без значения) |
| `int age = 25;` | **объявление с инициализацией**: объявляем переменную `age` типа `int` и **инициализируем** её значением `25` |
| `age = 26;` | **присваивание**: переменной `age` **присваивается** новое значение `26` (старое теряется) |
| `age = age + 1;` | вычисляется **выражение** `age + 1`, его результат присваивается переменной `age` |
| `25`, `"Аня"`, `'A'`, `true`, `4.5` | **литералы** — значения, записанные прямо в коде |
| `final int MAX = 100;` | объявление **константы** `MAX` — после инициализации её нельзя изменить |
| `var name = "Аня";` | объявление переменной с **выводом типа**: тип `String` компилятор определяет сам по инициализатору |
| `String s = sc.nextLine();` | объявляем `s` и инициализируем **результатом вызова метода** `nextLine()` |
| `(int) 3.9` | **приведение типа** (явное сужение) `double` к `int` |

Различать: **объявление** (появилась переменная), **инициализация** (первое значение — в момент объявления или первым присваиванием), **присваивание** (запись значения через `=`; инициализация — частный случай первого присваивания).

## Операторы и выражения (модуль 3)

| Термин | Смысл |
|---|---|
| **выражение** | то, что вычисляется в значение: `a + b`, `x > 3`, `name.length()` |
| **оператор** | действие в выражении: `+`, `%`, `==`, `&&`, `=` |
| **операнд** | то, над чем действует оператор: в `a + b` операнды `a` и `b` |
| **инструкция** (statement) | законченное действие, обычно с `;` в конце: `x = 5;`, `System.out.println(x);` |
| `count++` | **инкремент**: увеличение на 1 (постфиксный — сначала значение, потом +1) |
| `total += price` | **составное присваивание**: `total = total + price` |
| `a > b` | **сравнение**, результат — `boolean` |

## Условия (модуль 4)

`if (age >= 18) { … } else { … }` — **условный оператор** `if`: проверяется **условие** `age >= 18`; если оно истинно, выполняется **тело** (блок) `if`, иначе — **ветка** `else`.
`cond ? a : b` — **тернарный оператор**: выражение, которое возвращает `a` или `b`.
`switch (day) { case 1 -> … }` — **switch** по значению `day`, каждая `case` — **ветка**.

## Циклы (модуль 5)

`for (int i = 0; i < 5; i++) { … }` — **цикл for**: в **заголовке** — инициализация счётчика `i`, **условие** продолжения `i < 5` и **шаг** `i++`; блок в фигурных скобках — **тело цикла**; одно выполнение тела — **итерация**.
`while (x > 0)` — цикл с **предусловием**; `do { } while (…)` — с **постусловием**.
`break` — **выход** из цикла; `continue` — **переход к следующей итерации**.

## Массивы (модуль 6)

`int[] nums = new int[5];` — объявляем переменную-ссылку `nums` типа «массив int» и инициализируем её **новым массивом** из 5 элементов (все равны 0).
`int[] nums = {3, 1, 4};` — объявление с инициализацией **литералом массива**.
`nums[0]` — **обращение к элементу** по **индексу** 0; `nums[0] = 7;` — присваивание элементу.
`nums.length` — **длина** массива (поле, без скобок).

## Методы (модуль 7)

`static int sum(int a, int b) { return a + b; }` — **объявление метода** `sum`: **сигнатура** — имя и типы **параметров** `(int a, int b)`; `int` — **тип возвращаемого значения**; в фигурных скобках — **тело метода**; `return a + b;` — метод **возвращает** значение выражения.
`int s = sum(2, 3);` — **вызов метода** `sum` с **аргументами** `2` и `3`; возвращённое значение инициализирует переменную `s`.
**Параметр** — переменная в объявлении метода; **аргумент** — значение, которое передают при вызове.
`void` — метод **ничего не возвращает**.
Переменная, объявленная внутри метода, — **локальная**; её **область видимости** — блок, где она объявлена.

## Строки (модуль 8)

`name.toUpperCase()` — **вызов метода** `toUpperCase` **у объекта** `name`; метод **возвращает новую строку**, исходная не меняется (строки неизменяемы).
`a.equals(b)` — сравнение строк **по содержимому**; `a == b` — сравнение **ссылок**.

## Классы и объекты (модули 9–11)

`class Cat { String name; … }` — **объявление класса** `Cat`; `name` — **поле** (переменная объекта).
`Cat(String name) { this.name = name; }` — **конструктор**: параметру `name` соответствует поле `this.name`, полю присваивается значение параметра.
`Cat barsik = new Cat("Барсик");` — **создание объекта** (экземпляра) класса `Cat` оператором `new` с **вызовом конструктора**; переменная `barsik` хранит **ссылку** на объект.
`barsik.meow();` — **вызов метода** `meow` у объекта `barsik`.
`static` — член **класса**, а не объекта. `private` / `public` — **модификаторы доступа**.
`class Dog extends Animal` — класс `Dog` **наследует** класс `Animal`; `@Override` — метод **переопределяет** метод родителя.
`class Robot implements Speaker` — класс **реализует** интерфейс.

## Исключения (модуль 12)

`throw new IllegalArgumentException("…");` — **создаём объект исключения и выбрасываем** (бросаем) его.
`try { … } catch (IOException e) { … }` — **перехватываем** исключение типа `IOException` в блоке `catch`.
`void read() throws IOException` — метод **объявляет**, что может выбросить `IOException`.

## Коллекции и generics (модуль 13)

`List<String> names = new ArrayList<>();` — объявляем переменную `names` типа **интерфейса** `List` с **параметром типа** `String` и инициализируем её **новым объектом** класса `ArrayList`.
`names.add("Аня");` — вызываем метод `add` у списка `names` и передаём аргумент `"Аня"`.

## Лямбды и стримы (модуль 14)

`x -> x * 2` — **лямбда-выражение**: **параметр** `x`, **тело** `x * 2` (возвращаемое значение).
`list.stream().filter(…).map(…).toList()` — **конвейер**: **промежуточные операции** `filter`, `map` и **терминальная** `toList`.
`String::length` — **ссылка на метод**.

## Как использовать в уроках

- Первое появление конструкции — термин **жирным** и рядом объяснение простыми словами (аналогия — пожалуйста).
- Дальше в разборах кода — всегда термины: «объявляем», «инициализируем», «присваиваем», «вызываем … и передаём аргумент», «метод возвращает», «создаём объект».
- В разборах «по строкам» каждая строка читается полным предложением, как в таблицах выше.
- Тренажёр «Читаем код» в каждом модуле: типы `single` (что происходит в строке — 5 вариантов) и `build` (собери описание из квадратиков) в виджете `check`.
