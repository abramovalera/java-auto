Git: сохранения для кода

Помнишь сохранения в играх? Дошёл до сложного места — сохранился. Не получилось — загрузился и пробуешь снова. Git — то же самое для кода. Каждое сохранение называется коммит (commit): снимок всех файлов проекта с подписью «что я сделал». К любому коммиту можно вернуться.

Git знает каждый программист — без него не работает ни одна команда. Поэтому МиниБанк с первого дня живёт в Git. Подробно Git разберём в модуле 17, а пока хватит трёх действий:

Выпиши себе: Git, часть 0

Задание

1. Создай проект МиниБанк

В IDEA: File → New → Project. Заполни окно, как на скрине. Важно: проект кладём в папку курса (там, где лежат папки workspace и site) — так сайт сможет его проверять.

Нажми Create. IDEA спросит, открыть проект в этом окне или в новом, — выбирай New Window: курс и МиниБанк будут открыты в двух окнах рядом.

2. Создай класс Main

В новом проекте есть папка src. Правый клик по ней → New → Java Class → имя Main. Так обычно называют класс, с которого начинается программа. Внутри — метод main (psvm + Tab).

3. Напиши вывеску банка

Программа должна напечатать четыре строки — вот такую вывеску:

==============================
   Добро пожаловать в МиниБанк
==============================
Часы работы: круглосуточно
  • одна строка на экране — один вызов System.out.println(…) (sout + Tab);
  • полоски — 30 знаков =; можно чуть больше или меньше, проверка не придирается;
  • перед «Добро пожаловать» три пробела — небольшой отступ от края, так вывеска смотрится аккуратнее (сколько пробелов, проверка не придирается).

4. Запусти и проверь

Нажми ▶ рядом с main — в консоли внизу должна появиться вывеска. Потом нажми «Проверить» ниже: сайт сам скомпилирует твой проект и сверит вывод.

5. Сохрани в Git — первый коммит

Нажми Ctrl+K. Слева откроется окно Commit:

Готово: Alt+9 → вкладка Log — там твой первый коммит. Первая запись в истории твоего банка.

Покажи наставнику

Когда проверка зелёная — напиши в Claude Code /check m01-star. Наставник спросит, что такое коммит и зачем он нужен.
