Обязательное задание для завершения модуля. Банк уже умеет здороваться, но не знает, кто к нему пришёл. Научим его спрашивать имя и показывать баланс.

Перед заданием — освежи

В этом шаге пригодится всё самое главное из модуля 2. Перечитай, если что-то подзабылось:

  • 2.1 Переменные — коробки с ярлыками, «переменные работают вместе»;
  • 2.3 Строки и имена — String, «всё, что в кавычках, — строка», говорящие имена;
  • 2.5 Ввод с клавиатуры: Scanner — import, nextLine(), программа ждёт ввода.

Git на этот раз: работаем в ветке

Новая идея: ветка. Это параллельная копия проекта, где можно спокойно пробовать. Основная ветка (main или master — смотря как настроен Git, это одно и то же) остаётся рабочей. Получилось в ветке — переносишь изменения в основную (merge, «слияние»). Не получилось — просто возвращаешься в основную, будто ничего не было.

Задание

1. Открой проект и создай ветку

Открой окно с проектом МиниБанк. Создай ветку module-02-client — дальше работаешь в ней.

2. Объяви переменные

Под вывеской из шага 1 (её не трогаем!) нужно объявить три переменные. Придумай им говорящие имена по-английски, как в уроке 2.3:

Что хранитТипЧем инициализироватьПример имени
сканер, чтобы читать с клавиатурыScannernew Scanner(System.in) (не забудь import)scanner
имя клиентаString — это текстрезультатом вызова метода nextLine() — он возвращает всю введённую строку, и «Анна Мария» тожеname, clientName
баланс клиента в рубляхint — целое числопока просто литералом 1000: каждому новому клиенту банк дарит 1000 ₽balance
Почему int, а не double?

Рубли в нашем банке целые. Кстати, в настоящих банках деньги в double не хранят вообще: дробные числа считаются с крошечными ошибками (помнишь 0.1 + 0.2?). Хранят в копейках — целым числом.

3. Выведи карточку клиента

Программа спрашивает имя, а потом печатает карточку. В IDEA это выглядит так (зелёным — то, что вводишь ты):

==============================
   Добро пожаловать в МиниБанк
==============================
Часы работы: круглосуточно
Как вас зовут? Анна
Клиент: Анна
Баланс: 1000 ₽
  • вопрос напечатай через print, а не println — тогда имя вводится на той же строке, как в примере;
  • имя и баланс подставляй из переменных через +. Написать "Клиент: Анна" в кавычках нельзя: ведь клиент может быть кем угодно. Вспомни таблицу «всё, что в кавычках, — строка».

4. Проверь

Запусти ▶ и введи своё имя. Потом нажми «Проверить»: сайт сам подставит разные имена — «Анна» и «Анна Мария».

Почему в проверке «Как вас зовут? Клиент: Анна» в одну строку?

Когда вводишь имя руками, ты нажимаешь Enter — и курсор переходит на новую строку. Сайт подставляет имя сам, без Enter на экране, поэтому вопрос и карточка «слипаются». Это нормально.

5. Сохрани и влей в основную ветку

  1. Ctrl+K → сообщение «Карточка клиента» → Commit.
  2. Вернись в основную ветку: имя ветки → main → Checkout. Посмотри на код — карточки клиента нет! Не пугайся: она в ветке.
  3. Имя ветки → module-02-client → Merge into Current. Карточка появилась и в основной ветке. Готово.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        System.out.println("==============================");
        System.out.println("   Добро пожаловать в МиниБанк");
        System.out.println("==============================");
        System.out.println("Часы работы: круглосуточно");

        Scanner scanner = new Scanner(System.in);
        System.out.print("Как вас зовут? ");
        String name = scanner.nextLine();
        int balance = 1000;

        System.out.println("Клиент: " + name);
        System.out.println("Баланс: " + balance + " ₽");
    }
}
