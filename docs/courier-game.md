# Игра «Джавик-курьер» — сквозная игра курса

Заменила «Раннер» (урок 4.7), раннер удалён из курса целиком. Одна игра, к которой ученик возвращается в модулях 4, 5, 6, 7 и 13: с каждым модулем его Джавик умнее, потому что у ученика появляется новый инструмент. Схема проверенная — так учат программированию через робота на клеточном поле (как Karel), но сюжет, персонаж и картинки свои. Курьер — маскот курса Джавик.

## Главное правило: код — в IDEA, смотрим — на сайте

1. Ученик пишет класс в IDEA в папке модуля (`workspace/module-04/CourierPart1.java` и т.д.).
2. На сайте жмёт «▶ Проверить» (страница «Практики») или «▶ Запустить мой код» (блок в уроке, виджет `courier`). Сервер компилирует файл настоящим `javac` вместе с движком и прогоняет на 3 картах.
3. Сайт показывает поездку по шагам: Джавик едет по полю, сбоку — номер хода, команда, какие датчики он спросил перед ходом и что они ответили. Врезался — пояснение.
4. Карты генерируются по номеру (seed): длина коридоров, повороты, места посылок разные. Маршрут «зашить» руками нельзя — нужна логика.
5. **Руками Джавиком управлять нельзя** — только программой (решение автора курса: так интереснее).

Класс робота — `CourierRobot`. В проекте ученика сервер сам кладёт `workspace/courier/CourierRobot.java` — заготовку с описанием (Javadoc) каждого метода: IDEA её видит, подсказывает при наведении и не подчёркивает код красным. Сам робот живёт на сайте, запускать класс в IDEA не нужно.

## Поле и правила

- Поле из клеток: стены, дорога, 📦 посылки (на клетке может быть несколько), 🏠 адреса доставки, 🏁 склад (старт). Джавик смотрит в одну из 4 сторон; «впереди/слева/справа» — относительно его взгляда.
- `move()` в стену — врезался, поездка окончена.
- `take()` без посылки на клетке, `drop()` не на адресе или без посылки — ошибка.
- У каждой карты лимит ходов (поворот — тоже ход). Превысил — «Похоже, Джавик ездит по кругу».
- Бесконечный цикл без команд роботу ловит таймаут сервера.

### Датчики и команды

| Датчики | Команды (часть 1 — строкой из `decide`, дальше — методами) |
|---|---|
| `wallAhead()`, `wallLeft()`, `wallRight()` — стена впереди / слева / справа | `"MOVE"` / `move()` — клетка вперёд |
| `parcelHere()` — на клетке посылка | `"LEFT"` / `turnLeft()`, `"RIGHT"` / `turnRight()` — поворот на месте |
| `carrying()` — Джавик везёт посылку | `"TAKE"` / `take()` — взять посылку |
| `atTarget()` — Джавик на адресе 🏠; `atDepot()` — на складе 🏁 | `"DROP"` / `drop()` — отдать одну посылку |
| `sign()` — табличка на развилке: `"LEFT"`, `"RIGHT"`, `"AHEAD"` или `""`; видна, пока Джавик на этой клетке не повернулся | |
| `houses()` — `int[]`: на скольких клетках от склада стоят дома (часть 4) | `goTo("Кафе")` — автопилот до дома (часть 5) |
| `orders()`, `newOrders()` — `List<String>` заказов; `houseName()` — название дома на клетке (часть 5) | |

## Части по модулям

### Часть 1 — модуль 4 «Условия»: ход за ходом
Класс `CourierPart1`, метод `public static String decide(CourierRobot robot)`. Игра вызывает его **на каждом ходу**, метод смотрит на датчики и возвращает одну команду. Циклов ещё нет — повторяет игра. Один файл на все три уровня: ученик его улучшает.

| Уровень | Карта | Что нужно понять |
|---|---|---|
| ★ «Коридор» (`m04-c1`) | извилистый коридор без развилок до 🏠 | `if/else`: впереди свободно — `MOVE`, иначе повернуть туда, где нет стены |
| ★★ «Первая посылка» (`m04-c2`) | на пути 📦, отдать на 🏠 | **порядок условий**: сначала «взять/отдать», потом «ехать» |
| ★★★ «Перекрёстки» (`m04-c3`) | развилки с тупиками, на развилках таблички; ходов в обрез | `switch`/`equals` по `sign()`; без табличек правило «вперёд-налево-направо» уводит в тупик |

### Часть 2 — модуль 5 «Циклы»: сам себе водитель
Класс `CourierPart2`, метод `public static void run(CourierRobot robot)` вызывается **один раз**, ученик сам командует методами робота. Один файл на три уровня.

| Уровень | Карта | Что нужно понять |
|---|---|---|
| ★ «Длинная улица» (`m05-c1`) | прямая улица длиной 5–15 | `while (!robot.wallAhead()) robot.move();` |
| ★★ «Лестница» (`m05-c2`) | ступеньки случайной длины | правило из части 1 в цикле `while (!robot.atTarget())` |
| ★★★ «Все посылки» (`m05-c3`) | посылки по улице, на клетке бывает две; сколько — неизвестно | вложенный цикл `while (robot.parcelHere()) take()`, счётчик, печать `Доставлено: N` |

### Часть 3 — модуль 6 «Массивы»: маршрут в массиве
Класс `CourierPart3`, `run`. Джавик стартует уже с посылкой, клиент — в конце извилистого коридора. Один файл на три уровня.

| Уровень | Что нужно понять |
|---|---|
| ★ «Запиши маршрут» (`m06-c1`) | каждый ход — в массив `String[]` + счётчик; после доставки напечатать `Маршрут: MOVE MOVE LEFT …` |
| ★★ «Дорога домой» (`m06-c2`) | после `drop()` ночь — датчики стен выключены; развернуться и пройти массив с конца, меняя `LEFT` ↔ `RIGHT`; вернуться на 🏁 |
| ★★★ «Сжатый маршрут» (`m06-c3`) | второй строкой `Кратко: MOVE x3, LEFT, MOVE x2` (одинаковые подряд сжать) + возврат домой |

### Часть 4 — модуль 7 «Методы»: свои команды
У каждого уровня свой класс.

| Уровень | Класс | Что нужно понять |
|---|---|---|
| ★ «Челнок» (`m07-c1`) | `CourierShuttle` | 3 посылки на складе, за раз берётся одна; свои методы `driveToWall(robot)`, `turnAround(robot)` |
| ★★ «Квартал» (`m07-c2`) | `CourierHouses` | дома — ниши слева, номера из `robot.houses()`; метод с параметром `driveSteps(robot, steps)` |
| ★★★ «Середина улицы» (`m07-c3`) | `CourierMiddle` | табличек нет (`atTarget()` не работает); метод `int driveToWall(robot)` возвращает число клеток, обратно — нужное количество |

### Часть 5 — модуль 13 «Коллекции»: служба доставки
Район с кольцевой дорогой, дома с названиями (Аптека, Кафе, Почта…), автопилот `goTo`.

| Уровень | Класс | Что нужно понять |
|---|---|---|
| ★ «Очередь заказов» (`m13-c1`) | `CourierOrders` | `Queue<String>`: доставлять строго по порядку поступления; после доставок приходят новые заказы `newOrders()` — в хвост очереди |
| ★★ «Один заезд на дом» (`m13-c2`) | `CourierShift` | адреса повторяются, к каждому дому — один `goTo`; посчитать посылки по адресам в `Map<String, Integer>` |
| ★★★ «Отчёт смены» (`m13-c3`) | `CourierShift` | тот же файл + отчёт по алфавиту (`TreeMap`) и `Всего: N`; бонус — собрать отчёт стримом (модуль 14) |

## Как это выглядит в курсе

- **Урок** «Джавик-курьер, часть N» (`/lessons/mXX/50-courier.html`) в модулях 4, 5, 6, 7 и 13: правила, карточка датчиков и команд, разбор идеи уровня без готового кода, подсказки «если не получается» по ступенькам, блок «▶ Запустить мой код» и просмотр поездки.
- **Задачи** — 3 уровня каждой части в «Практике» модуля. Засчитывается, когда пройдены все 3 карты уровня.
- **Наставник** при `/check`: спросить план («что Джавик делает, когда…?»), разобрать поездку, где врезался. Подсказки по уровням — в `tutor/module-XX.md`.
