# workspace — твоя мастерская

Здесь живёт **твой** код. Всё, что ты пишешь для задач, складывай сюда:

```
workspace/
├── module-01/        ← задачи модуля 1
│   ├── HelloWorld.java
│   ├── AboutMe.java
│   └── FixMe.java    ← этот файл уже есть, его надо починить
└── .history.log      ← сюда сайт записывает результаты проверок (не трогай)
```

Правила:

- Имя файла = имя класса внутри него. `HelloWorld.java` → `public class HelloWorld`.
- Какой файл нужен для какой задачи — написано в условии на сайте (страница «Практика»).
- Набирай код руками, а не копируй — так пальцы и голова запоминают синтаксис.
- Наставник (Claude Code) **не пишет и не правит** файлы в этой папке. Только ты.
