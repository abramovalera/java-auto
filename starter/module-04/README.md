## Что писать в этой части

`public static void step(CourierRobot robot)` — игра вызывает его **на каждом ходу**, а ты даёшь роботу **ровно одну** команду:

| Команда | Что сделает Джавик |
|---|---|
| `robot.move()` | проедет клетку вперёд |
| `robot.turnLeft()` | повернётся налево на месте |
| `robot.turnRight()` | повернётся направо на месте |
| `robot.take()` | возьмёт посылку |
| `robot.drop()` | отдаст посылку |
| `robot.jump()` | перепрыгнет яму впереди и приземлится на клетку за ней |

Ни одной команды за ход или две подряд — ошибка. Удобно писать цепочкой `if` / `else if`: в каждой ветке ровно одна команда.

Уровни: ★ коридор · ★★ первая посылка · ★★★ ямы. Один файл на все три — улучшай его.

## Поле и правила

- 🏁 склад (старт) · 📦 посылка · 🏠 адрес доставки · 🕳 яма · стены — тёмные клетки.
- «Впереди / слева / справа» — относительно того, **куда смотрит Джавик** (стрелка над ним).
- Ошибка и конец поездки: `MOVE` в стену или в яму; `JUMP`, когда впереди нет ямы; `TAKE` там, где нет посылки; `DROP` не на адресе или без посылки.
- Яма — не стена: `wallAhead()` перед ней ответит `false`.
- Поворот и прыжок — тоже ходы. У каждой карты есть лимит ходов: кончились — значит, Джавик ездит по кругу.

## Датчики — «что вокруг?»

| Метод | Что отвечает |
|---|---|
| `robot.wallAhead()` | `true` — впереди стена |
| `robot.wallLeft()` | `true` — слева стена |
| `robot.wallRight()` | `true` — справа стена |
| `robot.parcelHere()` | `true` — на этой клетке посылка |
| `robot.carrying()` | `true` — Джавик везёт посылку |
| `robot.atTarget()` | `true` — Джавик на адресе 🏠 |
| `robot.atDepot()` | `true` — Джавик на складе 🏁 |
| `robot.pitAhead()` | `true` — прямо впереди яма 🕳 |
