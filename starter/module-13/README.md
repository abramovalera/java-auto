## Что писать в этой части

| Метод | Что делает |
|---|---|
| `robot.orders()` | `List<String>` — заказы на начало смены (адреса) |
| `robot.newOrders()` | `List<String>` — новые заказы с прошлого вызова (бывает пустой) |
| `robot.goTo("Кафе")` | автопилот до дома с этим названием |
| `robot.houseName()` | название дома на этой клетке или `""` |
| `robot.drop()` | отдать одну посылку на адресе |

| Уровень | Файл | Условие |
|---|---|---|
| ★ очередь заказов | `module-13/CourierOrders.java` | строго по очереди поступления, новые заказы — в конец |
| ★★ один заезд на дом | `module-13/CourierShift.java` | к каждому дому — один `goTo`, адреса повторяются |
| ★★★ отчёт смены | `module-13/CourierShift.java` | ещё и отчёт: адреса по алфавиту, `Адрес: N`, в конце `Всего: N` |

## Поле и правила

- 🏁 склад (старт) · 📦 посылка · 🏠 адрес доставки · стены — тёмные клетки.
- «Впереди / слева / справа» — относительно того, **куда смотрит Джавик** (стрелка над ним).
- Ошибка и конец поездки: `MOVE` в стену; `TAKE` там, где нет посылки; `DROP` не на адресе или без посылки.
- Поворот — тоже ход. У каждой карты есть лимит ходов: кончились — значит, Джавик ездит по кругу.
- Строки сравнивай через `equals` или в `switch`, **не через `==`**.
