## Что писать в этой части

`public static void run(CourierRobot robot)` — вызывается **один раз**, командуешь сам. Каждая команда — один ход:

| Команда | Что сделает Джавик |
|---|---|
| `robot.move()` | проедет клетку вперёд |
| `robot.turnLeft()` | повернётся налево |
| `robot.turnRight()` | повернётся направо |
| `robot.take()` | возьмёт посылку |
| `robot.drop()` | отдаст посылку |

Уровни: ★ длинная улица · ★★ лестница · ★★★ все посылки (в конце напечатать `Доставлено: N`). Цикл без команд роботу — программа зависнет.

## Поле и правила

- 🏁 склад (старт) · 📦 посылка · 🏠 адрес доставки · стены — тёмные клетки.
- «Впереди / слева / справа» — относительно того, **куда смотрит Джавик** (стрелка над ним).
- Ошибка и конец поездки: `MOVE` в стену; `TAKE` там, где нет посылки; `DROP` не на адресе или без посылки.
- Поворот — тоже ход. У каждой карты есть лимит ходов: кончились — значит, Джавик ездит по кругу.
- Строки сравнивай через `equals` или в `switch`, **не через `==`**.

## Датчики — «что вокруг?»

| Метод | Что отвечает |
|---|---|
| `robot.wallAhead()` | `true` — впереди стена |
| `robot.wallLeft()` | `true` — слева стена |
| `robot.wallRight()` | `true` — справа стена |
| `robot.parcelHere()` | `true` — на этой клетке посылка |
| `robot.carrying()` | `true` — Джавик везёт посылку |
| `robot.atTarget()` | `true` — Джавик на адресе 🏠 |
| `robot.atDepot()` | `true` — Джавик на складе 🏁 |
| `robot.sign()` | табличка на развилке: `"LEFT"`, `"RIGHT"`, `"AHEAD"` или `""` (нет таблички) |
