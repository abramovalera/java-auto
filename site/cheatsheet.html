Главное

Сначала ответь вслух сам, потом открой ответ.

Чем отличаются JDK, JRE и JVM?

JVM выполняет байт-код. JRE — JVM плюс стандартные библиотеки, хватит, чтобы запускать. JDK — JRE плюс инструменты разработчика (компилятор javac, отладчик). Чтобы писать код, нужен JDK. С Java 11 отдельную JRE почти не выпускают — ставят сразу JDK.

Почему Java называют кроссплатформенной?

Код компилируется не в машинный код, а в байт-код. Его выполняет JVM, а JVM есть для Windows, macOS и Linux. Один и тот же .class работает везде: «написал один раз — запускай где угодно».

Что такое байт-код?

Промежуточный код в файлах .class: его делает javac из исходника, а выполняет JVM, превращая на ходу в команды процессора.

Как выглядит метод main и зачем он нужен?

public static void main(String[] args) — точка входа: с него JVM начинает выполнять программу. static — чтобы JVM могла вызвать его, не создавая объект (подробнее — модуль 9).

Какие бывают ошибки?

Компиляции — код не собрался (забыта ;, опечатка). Выполнения — программа упала с исключением во время работы. Логическая — программа работает, но результат неверный.

Модуль 2 · Переменные и типы данных

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Переменная — коробка с ярлыком: тип, имя, значение. = — «положи», а не «равно».
  • 8 примитивов: byte short int long float double char boolean. String — не примитив, а объект.
  • Примитив хранит само значение; объект лежит в куче, а в переменной — ссылка на него.
  • Имена: переменные — camelCase, классы — PascalCase, константы — UPPER_SNAKE_CASE.
  • Всё в кавычках — строка: "20" ≠ 20. Число из строки — Integer.parseInt, строка из числа — String.valueOf.
  • Сужение типа — только явно: (int) 3.9 даст 3.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Какие примитивные типы есть в Java?

Восемь: целые byte, short, int, long; дробные float, double; символ char; логический boolean.

String — это примитив?

Нет. String — класс, строка — объект. Поэтому у неё есть методы (length(), toUpperCase()) и её сравнивают через equals.

Чем примитив отличается от ссылочного типа? Что такое стек и куча?

Примитив хранит значение прямо в переменной. Объект создаётся в куче, а переменная хранит ссылку («адрес») на него. Локальные переменные живут в стеке, объекты — в куче.

Что будет при (int) 3.99 и при переполнении int?

(int) 3.99 = 3: дробная часть отбрасывается, не округляется. Переполнение: Integer.MAX_VALUE + 1 станет самым маленьким отрицательным числом — без ошибки, тихо.

Что такое var?

Тип локальной переменной выводит компилятор по значению справа: var age = 20; — это int. Тип всё равно фиксирован, просто его не пишут.

Как сделать константу?

final: final int max = 100; — второй раз присвоить нельзя. Настоящая константа класса — поле static final (модуль 9): static final int MAX_SIZE = 100; — такие пишут БОЛЬШИМИ_БУКВАМИ. Обычную локальную final-переменную называют, как всё остальное, в camelCase.

Как принято называть переменные, классы и константы?

Переменные и методы — camelCase: слова слитно, первое с маленькой (userName, getBalance). Классы — PascalCase, с большой (BankAccount). Константы — UPPER_SNAKE_CASE (MAX_SIZE). Компилятор не заставляет, но так пишут все — и на код-ревью за другое поправят.

Модуль 3 · Операторы и выражения

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Целое / целое = целое: 7 / 2 = 3. Остаток — %: 7 % 2 = 1.
  • i++ — сначала значение, потом +1; ++i — наоборот.
  • && и || «ленивые»: вторую часть не считают, если ответ уже ясен.
  • double неточен: 0.1 + 0.2 ≠ 0.3.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Чему равно 7 / 2, 7 % 2 и 7.0 / 2?

3, 1 и 3.5. Если оба числа целые — деление целочисленное, дробь отбрасывается.

Чем i++ отличается от ++i?

Оба увеличивают на 1. i++ в выражении отдаёт старое значение, ++i — новое: при i = 5 x = i++ даст 5, x = ++i — 6.

Чем && отличается от &?

&& — «короткое замыкание»: если левая часть false, правую не вычисляет. & для boolean всегда вычисляет обе части. Поэтому s != null && s.length() > 0 безопасно, а с & упадёт на null. (Для чисел & — это побитовое И, в курсе не нужно.)

Почему 0.1 + 0.2 != 0.3?

double хранит дроби в двоичном виде приближённо. Деньги в таких типах не считают: берут копейки в long или BigDecimal.

Как проверить, что число чётное?

n % 2 == 0.

Модуль 4 · Условия: if и switch

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • if / else if / else — проверяет условия сверху вниз, срабатывает первое истинное.
  • Сравнение — ==, присваивание — =. Строки сравнивают через equals.
  • Тернарный оператор: условие ? да : нет — короткий if, который возвращает значение.
  • Стрелочный switch (case 1 ->) не проваливается дальше, ему не нужен break.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Какие типы можно использовать в обычном switch?

В классическом switch по значениям: int и меньшие целые, char, String, enum и их обёртки. long, double, float и boolean — нельзя. (В новых версиях Java есть ещё switch по типам — pattern matching, в курсе его нет.)

Что будет, если в старом switch забыть break?

«Проваливание»: выполнятся и следующие case до первого break. Стрелочный switch (->) так не делает.

Что такое тернарный оператор?

a > b ? a : b — если условие истинно, берётся первое значение, иначе второе. Удобно для коротких выборов.

Зачем фигурные скобки у if с одной строкой?

Без них к if относится только первая строка. Добавишь вторую — она будет выполняться всегда. Скобки защищают от такой ошибки.

Модуль 5 · Циклы

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • while — пока условие истинно; do-while — хотя бы один раз; for — когда знаешь, сколько шагов.
  • break выходит из цикла, continue — переходит к следующему шагу.
  • Частые ошибки: бесконечный цикл, «на один больше/меньше» (< против <=).
  • Роли переменных: счётчик, накопитель (сумма), флаг, максимум.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Чем while отличается от do-while?

while сначала проверяет условие и может не выполниться ни разу. do-while сначала выполняет тело, потом проверяет — минимум один раз.

Чем break отличается от continue?

break — выйти из цикла совсем. continue — пропустить остаток текущего шага и перейти к следующему.

Задача: FizzBuzz

Числа от 1 до 100: кратные 3 — «Fizz», кратные 5 — «Buzz», кратные обоим — «FizzBuzz». Ключ — % и порядок проверок: сначала «и 3, и 5». Частая задача на собеседованиях.

Задача: сумма цифр числа

Пока число больше 0: прибавь n % 10 (последняя цифра) к сумме и сделай n = n / 10 (отрезать цифру).

Как получить бесконечный цикл и как из него выйти?

while (true) или условие, которое никогда не станет ложным. Выход — break по условию. Случайный бесконечный цикл останавливают кнопкой ■ (Ctrl+F2).

Модуль 6 · Массивы

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Массив — ряд ячеек одного типа фиксированной длины. Индексы с 0, последний — length - 1.
  • У массива length без скобок, у строки — length().
  • Массив — объект: b = a копирует ссылку, а не ячейки. Копия — Arrays.copyOf.
  • Arrays.toString — печать, Arrays.sort — сортировка, Arrays.equals — сравнение.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Можно ли изменить длину массива?

Нет, длина задаётся при создании. Нужен «резиновый» список — ArrayList (модуль 13).

Что будет при обращении к a[a.length]?

ArrayIndexOutOfBoundsException: последний индекс — length - 1.

Какие значения у нового массива?

Числа — 0, boolean — false, объекты (в том числе String) — null.

Почему a == b для двух одинаковых массивов даёт false?

== сравнивает ссылки: это два разных объекта. Содержимое сравнивает Arrays.equals(a, b).

Задача: найти максимум / развернуть массив

Максимум: запомни первый элемент, пройди циклом, обновляй, если нашёл больше. Разворот: меняй местами a[i] и a[length - 1 - i] до середины.

Модуль 7 · Методы

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Метод — именованный кусок кода: параметры на вход, return на выход.
  • Java передаёт аргументы по значению. Для объектов копируется ссылка.
  • Перегрузка — одно имя, разные параметры.
  • Каждый вызов кладёт кадр в стек вызовов; бесконечная рекурсия → StackOverflowError.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

В Java передача по значению или по ссылке?

Всегда по значению. Для примитива копируется число — метод не изменит переменную снаружи. Для объекта копируется ссылка: метод может поменять содержимое объекта, но не заменить сам объект у вызывающего.

Что такое перегрузка метода?

Несколько методов с одним именем и разными параметрами (числом или типами): print(int), print(String). Тип возврата на перегрузку не влияет.

Что входит в сигнатуру метода?

Имя и список типов параметров. Тип возврата в сигнатуру не входит.

Что такое рекурсия и чем она опасна?

Метод вызывает сам себя. Нужен базовый случай, где вызовы прекращаются, иначе стек переполнится: StackOverflowError.

Модуль 8 · Строки

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Строка неизменяема: toUpperCase() и другие методы возвращают новую строку.
  • Сравнение строк — только equals (без регистра — equalsIgnoreCase), не ==.
  • Много склеек в цикле — StringBuilder.
  • printf / String.format: %d — целое, %.2f — дробь с 2 знаками, %s — строка.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Чем == отличается от equals для строк?

== проверяет, один ли это объект в памяти. equals сравнивает символы. Для строк всегда нужен equals.

Почему String неизменяемая?

Так безопаснее: строку можно спокойно передавать куда угодно — её никто не испортит. А ещё одинаковые строки-литералы Java хранит один раз, в пуле строк, и может раздавать всем одну и ту же: раз строку нельзя изменить, это безопасно.

String, StringBuilder и StringBuffer — в чём разница?

String неизменяем. StringBuilder — изменяемая строка, быстрая для склеек. StringBuffer — то же, но потокобезопасный и медленнее; сейчас почти не нужен.

Задача: развернуть строку / проверить палиндром

new StringBuilder(s).reverse().toString() или цикл с конца строки. Палиндром — строка равна своей развёрнутой версии.

Задача: посчитать гласные в строке

Приведи строку к одному регистру (toLowerCase()), потом цикл по s.charAt(i) и проверка, есть ли символ в "аеёиоуыэюя" через indexOf. Без toLowerCase() заглавные гласные не посчитаются — частая ошибка.

Модуль 9 · Классы и объекты

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Класс — чертёж, объект — вещь по чертежу (new).
  • Конструктор задаёт начальное состояние; this — «этот объект».
  • static — общее для класса, а не для каждого объекта.
  • Доступ: private → без модификатора (пакет) → protected → public.
  • record — короткий класс для данных: конструктор, геттеры, equals, toString — сами.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Чем класс отличается от объекта?

Класс — описание (какие поля и методы). Объект — конкретный экземпляр в памяти со своими значениями полей.

Что такое конструктор? Есть ли конструктор по умолчанию?

Специальный блок кода с именем класса и без типа возврата, вызывается при new. Похож на метод, но методом не считается: не наследуется и не вызывается по имени — это любимая ловушка собеседований. Если не написать ни одного конструктора, компилятор добавит пустой. Напишешь свой с параметрами — пустой пропадёт.

Что такое static? Почему из static-метода нельзя обратиться к обычному полю?

static-поле или метод принадлежат классу, а не объекту. У static-метода нет this: непонятно, поле какого объекта брать.

Какие есть модификаторы доступа?

private — только внутри класса; без модификатора — внутри пакета; protected — пакет и наследники; public — всем.

Что такое record?

Класс для неизменяемых данных: record Point(int x, int y). Сам создаёт конструктор, методы x(), y(), equals, hashCode, toString.

Модуль 10 · ООП: инкапсуляция, наследование, полиморфизм

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Инкапсуляция — поля private, доступ через методы с проверками.
  • Наследование — extends; super — обращение к родителю. Класс наследует только один класс.
  • Полиморфизм — переменная типа родителя, а работает метод настоящего объекта.
  • Переопределил equals — переопредели и hashCode.
  • Композиция («имеет») часто лучше наследования («является»).

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Назови принципы ООП и приведи примеры.

Инкапсуляция — данные спрятаны в private-полях, наружу только методы: у счёта нельзя напрямую присвоить баланс, только вызвать deposit(). Наследование — общий родитель Account с общими полями и методами, от него наследуются DebitAccount и CreditAccount. Полиморфизм — переменная типа Account может хранить ссылку на CreditAccount, и вызовется его версия метода. Абстракция — показываем главное, прячем детали: вызываем transfer() и не думаем о проверках внутри. Самый частый вопрос на собеседовании.

Чем перегрузка отличается от переопределения?

Перегрузка (overload) — то же имя, другие параметры, в одном классе. Переопределение (override) — та же сигнатура в наследнике, своя реализация, пишут @Override.

Какой контракт у equals и hashCode?

Если a.equals(b), то a.hashCode() == b.hashCode(). Обратное не обязательно. Нарушишь — объект «потеряется» в HashSet и HashMap.

Что значит final у класса, метода, переменной?

Класс — нельзя наследовать (так сделан String). Метод — нельзя переопределить. Переменная — нельзя присвоить второй раз.

Есть ли в Java множественное наследование?

Классов — нет, только один extends. Интерфейсов можно реализовать сколько угодно (модуль 11).

Какие методы есть у Object?

Главные: toString, equals, hashCode, getClass. Их наследует любой класс.

Модуль 11 · Интерфейсы, абстрактные классы, enum, record

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Абстрактный класс — недоделанный родитель: есть общий код, часть методов без тела.
  • Интерфейс — контракт «умеет делать». Класс может реализовать много интерфейсов.
  • default-метод — метод с телом прямо в интерфейсе.
  • enum — фиксированный набор значений; Comparable / Comparator — правила сортировки.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Чем абстрактный класс отличается от интерфейса?

Абстрактный класс может хранить состояние (поля) и конструктор, наследуется только один. Интерфейс — контракт без состояния, реализовать можно несколько. «Является» — абстрактный класс, «умеет» — интерфейс.

Можно ли создать объект абстрактного класса?

Нет, только объект наследника, который реализовал все абстрактные методы.

Что такое функциональный интерфейс?

Интерфейс ровно с одним абстрактным методом: Runnable, Comparator. Его можно записать лямбдой (модуль 14).

Comparable или Comparator?

Comparable — «естественный» порядок внутри класса (compareTo). Comparator — внешнее правило, их может быть сколько угодно: по имени, по возрасту.

Зачем enum, если есть строки-константы?

Компилятор не даст передать несуществующее значение, работают switch и values(). Опечатку в строке он не поймает.

Модуль 12 · Исключения

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Исключение — объект-сигнал о проблеме. Stack trace читаем сверху: тип, сообщение, строка твоего кода.
  • try / catch / finally; ресурсы закрывает try-with-resources.
  • Checked (проверяемые) компилятор заставляет обработать или объявить throws. Unchecked (RuntimeException) — нет.
  • throw — бросить исключение, throws — предупредить в объявлении метода.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Какая иерархия исключений?

Throwable → Error (беды JVM, не ловим) и Exception. Внутри Exception — RuntimeException (unchecked) и остальные (checked).

Чем checked отличается от unchecked?

Checked (IOException) — компилятор требует try/catch или throws. Unchecked (NullPointerException, IllegalArgumentException) — обычно ошибка в коде, обрабатывать не заставляют.

Всегда ли выполняется finally?

Почти всегда: и после return, и после исключения. Не выполнится, если JVM остановили (System.exit) или она упала.

Чем throw отличается от throws?

throw new X() — бросить исключение здесь и сейчас. throws X — пометка в объявлении метода: «может бросить X».

Какие исключения встречал?

NullPointerException, ArrayIndexOutOfBoundsException, NumberFormatException, ArithmeticException, ClassCastException, IllegalArgumentException.

Модуль 13 · Коллекции и generics

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • List — порядок и повторы, Set — только уникальные, Map — ключ → значение.
  • В <> только объекты: List<Integer>, не List<int>. Автоупаковка переводит туда-обратно сама.
  • HashSet / HashMap опираются на hashCode и equals.
  • Удалять из списка во время for-each нельзя → removeIf или Iterator.remove().

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Какая иерархия коллекций?

Collection → List, Set, Queue. Map — отдельно, не наследник Collection.

ArrayList или LinkedList?

ArrayList — массив внутри: быстрый доступ по индексу, его берут почти всегда. LinkedList — цепочка узлов: быстрое добавление в начало, но медленный доступ по индексу.

Как устроен HashMap (коротко)?

По hashCode ключа выбирается «корзина», внутри корзины ключ ищется через equals. Поэтому у ключа должны быть правильно переопределены оба метода. Ключи уникальны, порядок не гарантирован.

HashSet, LinkedHashSet, TreeSet — в чём разница?

HashSet — без порядка, самый быстрый. LinkedHashSet — помнит порядок добавления. TreeSet — хранит отсортированными.

Почему Integer a = 128, b = 128; a == b даёт false?

== сравнивает ссылки. Числа от -128 до 127 Java кэширует (один объект), 128 — уже разные объекты. Обёртки сравнивают через equals.

Что будет, если удалять элементы в for-each?

Как правило — ConcurrentModificationException. Но не всегда: если удалить предпоследний элемент, цикл просто тихо закончится и последний элемент не проверится — это тоже ловушка. Правильно — list.removeIf(x -> …) или iterator.remove().

Чем HashMap отличается от Hashtable?

Hashtable — устаревший класс из Java 1.0: все методы синхронизированы (медленнее), null нельзя ни в ключ, ни в значение. HashMap не синхронизирован и допускает один null-ключ. Для нескольких потоков вместо Hashtable берут ConcurrentHashMap.

Почему не Vector и не Stack?

Оба — наследие Java 1.0 с лишней синхронизацией. Вместо Vector — ArrayList, вместо Stack — ArrayDeque через интерфейс Deque (те же push, pop, peek).

Чем List.of отличается от Arrays.asList и new ArrayList?

List.of — неизменяемый список без null: add и set бросают UnsupportedOperationException. Arrays.asList — фиксированного размера: set можно, add и remove нельзя. new ArrayList<>(…) — обычный изменяемый список.

Что такое O(1), O(log n), O(n)?

Как растёт время операции с ростом числа элементов. O(1) — не зависит от размера (get у ArrayList, contains у HashSet). O(log n) — растёт очень медленно (TreeSet, TreeMap). O(n) — растёт вместе с размером (contains у List).

Модуль 14 · Лямбды и Stream API

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Лямбда — короткая запись функционального интерфейса: x -> x * 2.
  • Стрим — конвейер: источник → промежуточные операции (filter, map, sorted) → терминальная (toList, count, collect).
  • Без терминальной операции стрим ничего не делает. Повторно использовать стрим нельзя.
  • Optional — «может быть пусто» вместо null.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Что такое лямбда?

Анонимная функция: реализация единственного метода функционального интерфейса в одну строку. list.forEach(s -> System.out.println(s)).

Промежуточные и терминальные операции — в чём разница?

Промежуточные (filter, map) возвращают новый стрим и ленивы. Терминальные (collect, count, forEach) запускают конвейер и дают результат.

Чем map отличается от filter?

filter оставляет элементы по условию. map превращает каждый элемент во что-то другое (строку — в её длину).

Зачем Optional?

Явно показать, что результата может не быть, и не ловить NullPointerException: findFirst().orElse("нет").

Назови функциональные интерфейсы из java.util.function

Predicate (проверка → boolean), Function (из одного в другое), Consumer (принять и сделать), Supplier (выдать значение).

Чем абсолютный путь отличается от относительного?

Модуль 16 · Многопоточность: основы

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Поток — отдельная линия выполнения. Запуск — start(), не run().
  • Состояние гонки (race condition) — потоки одновременно меняют общее поле. Лечится synchronized или атомиками.
  • Пул потоков — ExecutorService; результат — Future.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Чем start() отличается от run()?

start() создаёт новый поток, и run() выполняется в нём. Прямой вызов run() — обычный метод в текущем потоке, без параллельности.

Что такое состояние гонки (race condition) и как его избежать?

Два потока читают и пишут одно поле, результат зависит от случайности. Решения: synchronized, AtomicInteger, потокобезопасные коллекции, а лучше — не делить данные между потоками.

Что такое deadlock?

Взаимная блокировка: поток A держит замок 1 и ждёт 2, поток B держит 2 и ждёт 1. Оба ждут вечно.

Что делает volatile?

Гарантирует, что все потоки видят свежее значение переменной. Атомарность count++ он не даёт.

Почему многопоточная программа иногда даёт разный результат?

Потоки делят общие данные: общие static-поля, одна коллекция на всех. Порядок их работы каждый раз разный — отсюда «случайные» ошибки. Лечится так: каждому потоку свои данные, а общее — через synchronized, атомики или потокобезопасные коллекции.

Модуль 17 · Инструменты разработчика

Этот модуль ещё впереди. Ответы лучше открывать, когда пройдёшь его уроки, — иначе они просто запомнятся без понимания.

Главное

  • Отладчик: точка останова, шаги F8 / F7, значения переменных на паузе.
  • Git: commit — сохранить у себя, push — отправить, pull — забрать. Работа — в своей ветке.
  • Gradle (build.gradle.kts) скачивает зависимости и запускает тесты: gradlew test.

Могут спросить на собеседовании

Сначала ответь вслух сам, потом открой ответ.

Чем git fetch отличается от git pull?

fetch только скачивает чужие изменения, не трогая твою ветку. pull = fetch + влить их в твою ветку.

Что такое merge conflict и как его решать?

Два человека поменяли одни и те же строки. Git не знает, что оставить: открываешь файл (в IDEA — окно Merge), выбираешь или совмещаешь правки, коммитишь.

Maven или Gradle? Что такое зависимость?

Оба — сборщики: скачивают библиотеки (зависимости), компилируют, запускают тесты. Зависимость — чужая библиотека (например, JUnit), которую сборщик подтягивает по имени и версии. У Gradle настройки — скрипт на Kotlin (build.gradle.kts) или Groovy (build.gradle), у Maven — XML (pom.xml).

Какие аннотации JUnit 5 знаешь?

@Test, @BeforeEach / @AfterEach (до и после каждого теста), @BeforeAll / @AfterAll (один раз на класс), @DisplayName, @Disabled, @ParameterizedTest + @ValueSource / @CsvSource.

Чем assertEquals отличается от assertThat (AssertJ)?

Оба проверяют. AssertJ читается как фраза (assertThat(list).hasSize(3).contains("a")) и даёт понятные сообщения при падении.
