Коллекции: что выведется? Скомпилируется ли?

Коллекции — золотая жила собеседований: кэш Integer, два remove, equals без hashCode, падающий for-each. Запускать нельзя — только думать и объяснять.

Как решать

Сначала скажи ответ вслух и объясни почему, потом кликай. Для задач про Integer и HashSet помогает нарисовать стек, кучу и корзины — как в уроках 13.2 и 13.4.

Что выведется на экран?

1. Кэш Integer. Что напечатают две строки?

Integer a = 127, b = 127;
Integer c = 128, d = 128;
System.out.println(a == b);
System.out.println(c == d);
  • true и true
  • true и false
  • false и false

2. Два remove. Что напечатает?

List<Integer> list = new ArrayList<>(List.of(1, 2, 3));
list.remove(1);
System.out.println(list);
  • [2, 3]
  • [1, 3]
  • Ошибка компиляции

3. Своя точка в HashSet. Класс Point не переопределяет equals и hashCode. Что напечатает?

Set<Point> set = new HashSet<>();
set.add(new Point(1, 1));
set.add(new Point(1, 1));
System.out.println(set.size());
  • 1
  • 2
  • Исключение при запуске

4. Слово, которого нет. Что напечатает?

Map<String, Integer> ages = new HashMap<>();
ages.put("Аня", 20);
System.out.println(ages.get("Борис"));
  • 0
  • null
  • NoSuchElementException

5. put дважды. Что напечатает?

Map<String, String> m = new HashMap<>();
System.out.println(m.put("цвет", "синий"));
System.out.println(m.put("цвет", "красный"));
System.out.println(m.size());
  • синий, красный, 1
  • null, синий, 1
  • null, синий, 2

6. PriorityQueue. Что напечатает первая строка?

PriorityQueue<Integer> pq = new PriorityQueue<>(List.of(5, 1, 4, 2, 3));
System.out.println(pq.poll() + " " + pq.poll());
  • 5 1
  • 1 2
  • 3 2

7. Удаление в цикле по индексу. Что напечатает?

List<String> list = new ArrayList<>(List.of("a", "", "", "b"));
for (int i = 0; i < list.size(); i++) {
    if (list.get(i).isEmpty()) {
        list.remove(i);
    }
}
System.out.println(list.size());
  • 2
  • 3
  • ConcurrentModificationException

8. Списки и множества — равны? Что напечатают две строки?

System.out.println(List.of(1, 2).equals(List.of(2, 1)));
System.out.println(Set.of(1, 2).equals(Set.of(2, 1)));
  • true и true
  • false и true
  • false и false

Скомпилируется ли?

9. Скомпилируется?

List<int> numbers = new ArrayList<>();
  • Да
  • Нет: нужен Integer вместо int

10. ★ Скомпилируется?

List<Object> things = new ArrayList<String>();
  • Да, String ведь наследник Object
  • Нет: incompatible types

Скомпилируется, но что будет при запуске?

11. Неизменяемый список. Что будет при запуске?

List<String> menu = List.of("Главная", "Каталог");
menu.add("Корзина");
System.out.println(menu);
  • [Главная, Каталог, Корзина]
  • UnsupportedOperationException
  • Ошибка компиляции

12. Распаковка. Что будет при запуске?

Map<String, Integer> stock = new HashMap<>();
int pears = stock.get("груши");
System.out.println(pears);
  • 0
  • NullPointerException
  • Ошибка компиляции

13. Удаление в for-each. Что будет при запуске?

List<Integer> nums = new ArrayList<>(List.of(1, -2, 3, 4));
for (Integer n : nums) {
    if (n < 0) {
        nums.remove(n);
    }
}
  • nums станет [1, 3, 4]
  • ConcurrentModificationException
  • IndexOutOfBoundsException

14. ★ TreeSet своих объектов. Класс Point не реализует Comparable. Что будет при запуске?

Set<Point> points = new TreeSet<>();
points.add(new Point(1, 2));
  • Точка добавится, ведь она одна
  • ClassCastException
  • Ошибка компиляции

15. ★★★ На опережение. Удаляем в for-each предпоследний элемент. Что будет?

List<Integer> nums = new ArrayList<>(List.of(1, 2, 3));
for (Integer n : nums) {
    if (n == 2) {
        nums.remove(n);
    }
}
System.out.println(nums);
  • ConcurrentModificationException
  • [1, 3] — без исключения
  • [1, 2, 3]

Напиши наставнику: «Дай мне 3 головоломки по коллекциям, по одной. Ответ не говори, пока я не объясню, что происходит в памяти или в корзинах».

Читаем код

Прочитай каждую строку правильными словами: что объявляется, чем инициализируется, у какого объекта вызывается метод и что он возвращает.

Что тренирует этот набор

  • Обёртки: кэш Integer −128..127, == против equals, распаковка null.
  • Списки: remove(int) и remove(Object), неизменяемый List.of, равенство с учётом порядка.
  • Изменение коллекции во время обхода: ConcurrentModificationException и тихие пропуски.
  • Хеш-коллекции: equals + hashCode, get → null, put возвращает старое значение.
  • Сортированные коллекции требуют Comparable или Comparator.
