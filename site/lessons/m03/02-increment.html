++, -- и составные присваивания

Счётчики живут в каждой программе: лайки, попытки входа, номер заказа, очки в игре. Для них в Java есть короткие операторы — и одна знаменитая ловушка, которую обожают на собеседованиях.

Повторение

«Возьми, измени, положи обратно»

Вспомни, как читается присваивание: справа налево. Строку count = count + 1; математик назвал бы бредом (число не может быть равно самому себе плюс один). А для Java это присваивание: вычисляется выражение count + 1, и результат записывается в count. По шагам — три действия:

Писать count = count + 1 длинно, а делают это постоянно. Поэтому придумали сокращения.

Аналогия: кликер охранника

У охранника на входе в клуб есть кликер-счётчик: зашёл человек — щёлк, +1. Вышел — щёлк другой кнопкой, −1. Это и есть инкремент (увеличение на 1, ++) и декремент (уменьшение на 1, --).

int visitors = 0;
visitors++;          // зашёл первый — 1
visitors++;          // зашёл второй — 2
visitors--;          // один ушёл    — 1
System.out.println("В зале: " + visitors);   // В зале: 1

Составные присваивания

А если нужно прибавить не 1, а 10? Для этого есть составные присваивания: оператор и = склеены вместе. Правило одно: x ОП= y значит x = x ОП (y).

КороткоДлинноГде пригодится
score += 10;score = score + 10;начислить очки
balance -= 300;balance = balance - 300;списать деньги
price *= 2;price = price * 2;удвоить цену
total /= 3;total = total / 3;разделить поровну (с int — целочисленно!)
seconds %= 60;seconds = seconds % 60;оставить только «хвост»
text += "!";text = text + "!";со строками тоже работает — склейка
int k = 3; k *= 2 + 1; — чему равно k? 7 или 9?

9. Правая часть составного присваивания вычисляется целиком и только потом применяется: k = k * (2 + 1) = 3 × 3. Скобки как будто стоят сами.

🔎 Для любопытных: скрытое приведение типа в += 
int x = 10;
x += 2.7;          // компилируется! x = 12
x = x + 2.7;       // ошибка: possible lossy conversion from double to int

Почему одно можно, а другое нет? Составное присваивание само приводит результат к типу переменной: x += 2.7 на самом деле значит x = (int) (x + 2.7). 12.7 молча обрезается до 12. Удобно, но опасно: дробная часть теряется без предупреждения. Отличный вопрос для собеседования.

i++ или ++i: в чём разница

Оператор можно поставить после переменной (i++, постфиксный инкремент) или перед ней (++i, префиксный инкремент). Когда строка состоит только из него — разницы нет, оба просто прибавят 1. Разница появляется, когда i++ стоит внутри выражения: у него, как у любого выражения, есть значение.

Аналогия: электронная очередь

Автомат с талонами в банке. Постфикс n++: автомат печатает тебе талон с текущим номером, а потом переключает табло на следующий. Префикс ++n: сначала переключает табло, а потом печатает талон уже с новым номером.

Теперь самое интересное. Пройди программу по шагам и впиши значения сам — это та самая трассировочная таблица, которую на собеседовании просят нарисовать на бумажке.

Если запутался — это нормально, такой код путает и опытных. Поэтому в реальных проектах ++ пишут отдельной строкой и не прячут внутрь выражений. А на собеседовании такие загадки проверяют, умеешь ли ты выполнять код в голове строго по правилам.

Знаменитая ловушка: i = i++

int i = 5;
i = i++;
System.out.println(i);
Что выведет программа: 5 или 6?

5! Разбираем по правилам. Сначала вычисляется правая часть: i++ отдаёт старое значение 5 и увеличивает i до 6. Потом выполняется присваивание: переменной i присваивается значение правой части — 5. Шестёрка затёрта. Строка, которая «должна увеличить i», ничего не изменила. Хочешь увеличить — пиши просто i++;.

Ещё пара правил, которые помогут не ошибаться:

  • ++ и -- работают только с переменными: 5++ не скомпилируется — 5 это литерал, у него нет «коробки», куда положить 6.
  • Они работают с int, long, double и даже char: char c = 'A'; c++; — и в c уже 'B' (следующий код символа, помнишь коды из модуля 2?).
  • i++ и i += 1 для int делают одно и то же.

Проверь себя

Поговори с наставником

Напиши: «Дай мне три задачки на i++ и ++i уровня собеседования. Я нарисую трассировочную таблицу, а ты проверь».

Коротко

  • x = x + 1 — вычисляется выражение x + 1, результат присваивается x: «возьми, посчитай справа, положи обратно».
  • Инкремент ++ / декремент -- — плюс/минус 1. Составные присваивания += -= *= /= %= — то же для любого числа, правая часть считается целиком.
  • Постфиксный a++ отдаёт старое значение, потом увеличивает. Префиксный ++a — сначала увеличивает, потом отдаёт новое.
  • i = i++ ничего не меняет. В рабочем коде пиши ++ отдельной строкой.
