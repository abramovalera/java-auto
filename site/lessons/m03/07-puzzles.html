Модуль 3 · Головоломки

Что выведется? Скомпилируется ли?

Операторы — любимая тема собеседований: i++ + ++i, 7 / 2 * 2, остаток от отрицательного числа, символы, которые внезапно складываются как числа. Здесь собраны классические ловушки — решай в голове, запускать нельзя.

Как решать

Сначала скажи ответ вслух и объясни почему, только потом кликай. Для задач с ++ рисуй на бумажке табличку «переменная | значение» и меняй её на каждом шаге — как в трассировщике из уроков.

Что выведется на экран?

1. Разминка. Что напечатает?

System.out.println(7 / 2 * 2);
  • 7
  • 6
  • 7.0

2. Остаток с минусами. Что напечатает?

System.out.println(5 % -3 + " " + -5 % 3);
  • 2 -2
  • -2 2
  • 2 1

3. Классика собеседований. Что напечатает?

int i = 5;
i = i++ + ++i;
System.out.println(i);
  • 11
  • 12
  • 13

4. Символы и числа. Что напечатают две строки?

char c = 'A';
System.out.println(c + 1);
c++;
System.out.println(c);
  • B и B
  • 66 и B
  • 66 и 66

5. Цифра в кавычках. Что напечатает?

System.out.println('1' + 2);
  • 12
  • 3
  • 51

6. Что напечатает?

System.out.println((0.1 + 0.2 == 0.3) + " " + (0.5 + 0.25 == 0.75));
  • true true
  • false true
  • false false

7. Короткое замыкание. Что напечатает?

int x = 0;
boolean r = x == 0 || x++ > 0;
System.out.println(x + " " + r);
  • 1 true
  • 0 true
  • 0 false

Скомпилируется ли?

8. Проверка диапазона, как в математике. Скомпилируется?

int x = 5;
boolean ok = 1 < x < 10;
  • Да, ok = true
  • Нет: boolean нельзя сравнить с числом

9. Скомпилируется?

int power = Math.pow(2, 3);
  • Да, power = 8
  • Нет: pow возвращает double

10. ★★★ Скомпилируется? Если да — что выведет?

int x = 10;
x += 2.7;
System.out.println(x);
  • Нет: нельзя прибавить double к int
  • Да, выведет 12
  • Да, выведет 12.7

Скомпилируется, но что будет при запуске?

11. Что произойдёт при запуске?

System.out.println(10.0 / 0);
System.out.println(10 / 0);
  • Напечатает Infinity и Infinity
  • Напечатает Infinity, потом упадёт с ArithmeticException
  • Ошибка компиляции

12. Бросаем кубик. Какие числа будут выпадать?

int dice = (int) Math.random() * 6 + 1;
System.out.println(dice);
  • От 1 до 6
  • Всегда 1
  • Всегда 0

13. Бесплатный обед. Что напечатает?

int x = 0;
boolean r = x != 0 && 10 / x > 1;
System.out.println(r);
  • ArithmeticException: / by zero
  • false
  • true

14. ★★★ Переменная long — значит, места хватит? Что напечатает?

long big = 1_000_000 * 1_000_000;
System.out.println(big);
  • 1000000000000
  • -727379968
  • Ошибка: число слишком большое

Найди ошибки

15. Программа делит 17 конфет на 5 человек и проверяет, поровну ли вышло. Сколько здесь ошибок?

int total = 17;
int people = 5;
double each = total / people;
boolean fair = total % people = 0;
System.out.println(each + " " + fair);
  • Одна: в строке 4 = вместо ==
  • Две: = вместо == в строке 4 и целочисленное деление в строке 3
  • Ошибок нет

Читаем код

Головоломки решены — теперь прочитай каждую строку вслух правильными словами: выражение, оператор и операнды, инкремент, составное присваивание, сравнение, вызов метода. В одних заданиях выбери верное описание из пяти, в других собери его из квадратиков — лишние оставь на месте.

Хочешь ещё?

Напиши наставнику: «Дай мне 3 головоломки по операторам уровня собеседования — с ++, приоритетом и остатком. По одной, ответ не говори, пока я не объясню». На экзамене модуля такие тоже будут.

Что запомнить из головоломок

  • int / int — целое; дробь теряется на первом же делении и уже не возвращается.
  • Знак остатка — как у левого числа. Символ в одинарных кавычках — это число-код.
  • i++ отдаёт старое, ++i — новое; операнды вычисляются слева направо.
  • && и || не вычисляют правый операнд, если ответ уже ясен по левому.
  • Тип результата решает всё: Math.pow → double, int * int переполняется, += молча обрезает дробь.
