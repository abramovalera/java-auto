1. Спроси сумму пополнения

Тем же сканером: print("Сумма пополнения: ") и прочитай число вызовом метода nextInt(). Объяви переменную, например deposit (тип int), и инициализируй её значением, которое вернёт этот вызов.

2. Посчитай — каждое значение в своей переменной

Вспомни «эстафету значений» из урока 2.1: одна переменная считается из другой.

Подвох с округлением

2% от 50 ₽ — это 1 ₽, а от 1525 ₽ — 30,5 ₽. Банк округляет по-обычному: 30,5 → 31. Именно так работает Math.round. Но он возвращает long, а у нас int — значит, нужно приведение (int).

3. Выведи итог

Сумма пополнения: 800
Комиссия: 16 ₽
Зачислено: 784 ₽
Новый баланс: 1784 ₽
Хватит на перевод 1500 ₽: true

Последняя строка — без if (его ещё не было). Это просто boolean-выражение «баланс не меньше 1500», которое Java вычислит в true или false. Не забудь скобки вокруг сравнения внутри склейки — вспомни приоритет операций из урока 3.5.

4. Проверь

Сайт подставит разные суммы: 800, 50, 0 и 1525 — проверит и округление, и ноль.

5. Сохрани и влей

Коммит «Пополнение с комиссией» → основная ветка → Merge. Загляни в Alt+9 → Log: там уже три шага твоего банка.

🔒 Показать решение — открывай, когда проверка уже зелёная или ты честно попробовал сам 
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        System.out.println("==============================");
        System.out.println("   Добро пожаловать в МиниБанк");
        System.out.println("==============================");
        System.out.println("Часы работы: круглосуточно");

        Scanner scanner = new Scanner(System.in);
        System.out.print("Как вас зовут? ");
        String name = scanner.nextLine();
        int balance = 1000;

        System.out.println("Клиент: " + name);
        System.out.println("Баланс: " + balance + " ₽");

        System.out.print("Сумма пополнения: ");
        int deposit = scanner.nextInt();
        int commission = (int) Math.round(deposit * 0.02);
        int credited = deposit - commission;
        balance = balance + credited;

        System.out.println("Комиссия: " + commission + " ₽");
        System.out.println("Зачислено: " + credited + " ₽");
        System.out.println("Новый баланс: " + balance + " ₽");
        System.out.println("Хватит на перевод 1500 ₽: " + (balance >= 1500));
    }
}
