Зачем нужны методы

Учимся давать куску кода имя и вызывать его одной строкой — как кнопку «сделай X». А заодно наконец разбираем по словам public static void main(String[] args).

Один и тот же код — пять раз

Представь, что ты печатаешь чек магазина. Между блоками чека нужна линия из чёрточек. Без новых знаний программа выглядит так:

public class Receipt {
    public static void main(String[] args) {
        System.out.println("--------------------");
        System.out.println("Магазин «У Джавика»");
        System.out.println("--------------------");
        System.out.println("Кофе          150");
        System.out.println("Булочка        70");
        System.out.println("--------------------");
        System.out.println("Итого:        220");
        System.out.println("--------------------");
    }
}

Работает. Но вот приходит начальник: «Линию сделай из знаков =, так красивее». Тебе придётся найти и поменять четыре одинаковые строки. Пропустишь одну — чек станет кривым. А в настоящей программе таких мест может быть сорок.

Аналогия: кнопка на кофемашине

Чтобы сварить капучино, нужно смолоть зёрна, пролить воду, вспенить молоко… Но ты не делаешь это по шагам — ты жмёшь кнопку «Капучино». Кто-то один раз записал рецепт внутрь кнопки, а пользоваться им можно сколько угодно раз.

Метод — это такая кнопка в программе. Ты один раз записываешь шаги и даёшь им имя (объявляешь метод), а потом «нажимаешь» по имени (вызываешь метод).

Метод: кусок кода с именем

Метод — это именованный блок кода, который можно вызывать по имени из других мест программы. Перепишем чек с методом:

public class Receipt {
    public static void main(String[] args) {
        printLine();
        System.out.println("Магазин «У Джавика»");
        printLine();
        System.out.println("Кофе          150");
        System.out.println("Булочка        70");
        printLine();
        System.out.println("Итого:        220");
        printLine();
    }

    static void printLine() {
        System.out.println("--------------------");
    }
}

Теперь линия описана в одном месте. Захочешь знаки = — поменяешь одну строку, и все четыре линии изменятся сами.

static void printLine() {

Объявление метода (его ещё называют определением), точнее его первая строка — заголовок метода: «вот кнопка, её зовут printLine». Пока это только рецепт — сам по себе он ничего не печатает.

System.out.println("----");

Тело метода — то, что лежит между фигурными скобками. Эти строки выполнятся при каждом «нажатии кнопки».

printLine();

Вызов метода: имя + круглые скобки + точка с запятой. Это и есть «нажать кнопку». Скобки обязательны, даже если внутри пусто.

Метод
Именованный блок кода внутри класса. В других языках то же самое называют функцией или процедурой.
Объявить метод
Написать его: заголовок + тело в фигурных скобках. Объявление метод не выполняет.
Вызвать метод
Написать его имя со скобками: printLine();. Java выполнит тело метода и вернётся обратно.
Предскажи: что напечатает программа, если из main убрать все четыре строки printLine();, а сам метод оставить?

Ни одной линии. Объявление метода — это рецепт, а не действие. Пока метод никто не вызвал, его тело не выполняется ни разу. Ошибки тоже не будет: объявить метод и не пользоваться им можно (IDEA лишь покажет его имя серым — «не используется»).

Где писать метод

Метод объявляют внутри класса, рядом с main — но не в теле main. Класс — как коробка, в которой лежат методы-кнопки. Положить одну кнопку внутрь другой нельзя.

✅

Можно

Метод выше или ниже main, внутри фигурных скобок класса. Порядок не важен: Java сначала прочитает весь класс и знает про все его методы.

❌

Нельзя

Объявлять метод внутри другого метода. Компилятор скажет illegal start of expression — «тут не может начинаться такое».

⚠️

Частая опечатка

Вызов без скобок: printLine;. Ошибка not a statement — «это не инструкция»: для Java это не вызов, а просто имя.

Почему методы пишут с маленькой буквы, а классы — с большой? Это договорённость Java-программистов: Receipt — класс, printLine — метод. Имя метода обычно начинается с глагола: он ведь что-то делает. Если слов несколько, каждое следующее с большой буквы: printLine, showMenu, printReceipt. Это называют camelCase — «верблюжий регистр», большие буквы торчат, как горбы.

Предскажи: метод printLine написан выше main. Скомпилируется?

Да. В отличие от локальных переменных, методы можно вызывать «раньше», чем они объявлены в файле. Порядок методов в классе — дело вкуса. Обычно main ставят первым, а помощников — ниже.

Куда прыгает программа

Программа выполняется инструкция за инструкцией — это ты знаешь. Вызов метода — это прыжок: Java ставит закладку «откуда я ушла», выполняет тело метода и возвращается к закладке. Пройди по шагам и следи за номером строки и за стопкой справа.

Ты пользуешься методами с первого урока

Сюрприз: методы ты вызываешь уже давно. Просто их объявил не ты, а авторы Java.

ВызовЧто это
System.out.println("Hi")вызов метода println с аргументом "Hi" — печатает строку
scanner.nextInt()вызов метода nextInt у объекта scanner — читает число с клавиатуры и возвращает его
Math.max(3, 7)вызов метода max с аргументами 3 и 7 — возвращает большее из двух
mainтоже метод! Его вызывает сама JVM при запуске

Видишь общий узор? Имя, а за ним круглые скобки. Где скобки после имени — там вызов метода, а в скобках — аргументы, значения, которые методу передают. Точки перед именем (System.out., Math.) — это «адрес», где метод живёт. Наши собственные методы лежат в том же классе, что и main, поэтому их зовём просто по имени.

Под одной строчкой System.out.println прячется целая цепочка методов: один вызывает другой, тот — третий… В уроке 3 мы заглянем туда и посчитаем, сколько их.

Наконец-то: public static void main(String[] args)

С модуля 1 ты писал эту строку как заклинание. Теперь ты знаешь, что такое метод, массив и тип, — и можешь прочитать её по словам.

public
«Публичный» — метод можно вызвать откуда угодно, в том числе снаружи класса. JVM запускает твою программу «снаружи», поэтому main обязан быть public. Для своих методов внутри одного класса мы пока пишем без него — подробно про public и его родственников будет в модуле 9.
static
«Статический» — метод принадлежит классу целиком, и для вызова не нужно создавать объект. Пока все наши методы будут static: объекты появятся в модуле 9, и там станет понятно, какие методы бывают без static.
void
«Пустота» — метод ничего не возвращает: просто делает дело. В следующем уроке напишем методы, которые возвращают результат — у них вместо void будет тип, например int.
main
Имя метода. Имя вместе с типами параметров по порядку называют сигнатурой метода: у main это main(String[]). Имена параметров и тип результата в сигнатуру не входят — зачем это знать, увидишь в уроке 7.5. JVM ищет именно main с маленькой буквы — помнишь головоломку про Main?
String[] args
Параметр — переменная, объявленная в скобках заголовка: то, что метод получает на вход. Тут это массив строк по имени args (от arguments). Массивы ты уже знаешь из модуля 6.

Что будет, если у своего метода забыть static? Самая частая ошибка новичка в этом модуле — IDEA сразу подчеркнёт вызов:

Пока просто пиши static у каждого своего метода. Почему без него нельзя вызвать метод из main — станет понятно в модуле 9, когда появятся объекты.

Что лежит в args? Слова, которые передали программе при запуске. В IDEA их задают так: Run → Edit Configurations… → Program arguments. Попробуй:

public class ArgsDemo {
    public static void main(String[] args) {
        System.out.println("Аргументов: " + args.length);
        for (int i = 0; i < args.length; i++) {
            System.out.println(args[i]);
        }
    }
}

А если ничего не писать — Аргументов: 0: JVM передаёт аргументом пустой массив. Поэтому обращение к args[0] без проверки закончится уже знакомым ArrayIndexOutOfBoundsException.

Где это пригодится

В рабочих программах параметры запуска — обычное дело: например, на каком языке показывать интерфейс или какой файл настроек прочитать. Механизм тот же — программе что-то передают снаружи при старте.

Собери программу с методом

Строки программы перемешались. Метод printStars печатает пять звёздочек, а main вызывает его до и после приветствия.

Проверь себя

Поговори с наставником

Напиши: «Я прошёл урок 7.1. Объясню своими словами, чем объявление метода отличается от вызова, а ты задай мне каверзный вопрос про public static void main».

Коротко

  • Метод — блок кода с именем. Объявляешь один раз — вызываешь сколько угодно.
  • Объявление метода: заголовок static void имя() и тело { … } — внутри класса, рядом с main, но не в его теле.
  • Вызов метода: имя(); — Java прыгает в метод, выполняет тело и возвращается к следующей инструкции.
  • Имя метода — глагол в camelCase: printLine, showMenu.
  • public — виден всем, static — без объекта, void — ничего не возвращает, String[] args — параметр, массив аргументов запуска.
