Головоломки: методы, стек и рекурсия

Передача аргументов, перегрузка, return и рекурсия — любимые темы вопросов «что выведет этот код?» на собеседованиях. Запускать нельзя — только думать.

Как решать

Сначала скажи ответ вслух или запиши и объясни, почему так. Нарисуй на бумажке стек: какие фреймы, какие в них переменные. Только потом выбирай вариант. Не уверен — набери код в IDEA и пройди отладчиком: это тоже честный способ.

Что выведется на экран?

static void inc(int x) {
    x++;

4. ★★★ Перегрузка и символ. Что напечатает?

static void show(int x) {
    System.out.println("int: " + x);
}

    System.out.println("String: " + s);

show('A');

6. Сколько раз напечатается «Hi»?

static void hello(int n) {
    if (n <= 0) {
        return;
    }
    System.out.print("Hi ");
    hello(n - 2);
}

// в main:
hello(5);
  • 5
  • 3
  • Бесконечно — StackOverflowError

    p(n - 1);
    System.out.print(n);

8. return посреди цикла. Что напечатает?

static String find(int n) {
    for (int i = 0; i < 10; i++) {
        if (i == n) {
            return "нашёл " + i;
        }
    }
    return "нет";
}

// в main:
System.out.println(find(3));
System.out.println(find(20));
  • нашёл 3 и нет
  • нашёл 3, нет и нет
  • нашёл 3 и нашёл 20

9. ★★★ В каком порядке вызываются методы? Что напечатает?

static int say(int n) {
    System.out.print(n + " ");
    return n;
}

// в main:
System.out.println(say(1) + say(2) * say(3));
  • 2 3 1 7
  • 1 2 3 7
  • 1 2 3 9

Скомпилируется ли?

10. Скомпилируется?

static int one() {
    return 1;
    System.out.println("после return");
}
  • Да, строка после return просто не выполнится
  • Нет: unreachable statement

11. Скомпилируется?

static int sign(int n) {
    if (n > 0) {
        return 1;
    } else if (n < 0) {
        return -1;
    }
}
  • Да
  • Нет: missing return statement

12. В одном классе два метода. Скомпилируется?

static int getValue() {
    return 1;
}

static double getValue() {
    return 1.5;
}
  • Да, это перегрузка
  • Нет: метод уже объявлен

13. Скомпилируется?

public static void main(String[] args) {
    int coins = 10;
    spend();
}

static void spend() {
    coins = coins - 3;
}
  • Да, coins станет 7
  • Нет: cannot find symbol

14. Скомпилируется?

static void printLine() {
    System.out.println("----------");
}

// в main:
int x = printLine();
  • Да, x станет 0
  • Нет: void-метод ничего не возвращает

Скомпилируется, но что будет при запуске?

15. ★★ Что будет при вызове f(5)?

static int f(int n) {
    if (n == 0) {
        return 0;
    }
    return f(n - 2);
}
  • Вернёт 0
  • Ошибка компиляции
  • StackOverflowError

Читаем код

Головоломки проверяли, что делает код. Теперь — как о нём сказать: прочитай каждую строку правильными терминами модуля, как на собеседовании или код-ревью. В одних заданиях выбери описание из пяти, в других собери его из квадратиков — лишние оставь на месте.
