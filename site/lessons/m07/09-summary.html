Модуль 12: исключения

Stack trace вернётся: научишься ловить ошибки и выбрасывать свои. Стек вызовов из этого модуля — основа, без которой там не разобраться.

Коротко

  • Метод — блок кода с именем, параметрами и (возможно) возвращаемым значением. Объявляем один раз, вызываем сколько угодно.
  • Каждый вызов — фрейм на стеке со своими параметрами и локальными переменными; return снимает фрейм.
  • Аргументы передаются копией значения: параметр инициализируется копией; у массива это копия ссылки.
  • Перегрузка — одно имя, разные параметры. Область видимости локальной переменной — свой блок.
  • Рекурсия — метод вызывает себя; без достижимого базового случая будет StackOverflowError.
  • Пройди чек-лист, сделай задачи до зелёного и напиши наставнику /exam.Пройди чек-лист, сделай задачи до зелёного и пройди мини-экзамен у DeepSeek: промпт «Экзамен» (кнопка внизу страницы).
