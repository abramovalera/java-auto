Файлы: что выведется? Скомпилируется ли?

Файлы — тема, где программа «вроде бы работает», а в файле не то. Перезапись вместо дописывания, незакрытый поток, не та рабочая папка. Запускать нельзя — только думать и объяснять.

⏱ 20 минут🧩 15 задачек★★★ — со звёздочкой
Как решать

Сначала скажи ответ вслух и объясни почему, потом кликай. Во всех задачах, если не сказано иначе, main объявлен с throws IOException, импорты на месте, а программа запускается из IDEA (рабочая папка — корень проекта).

Что выведется на экран?

Path p = Path.of("result.txt");
Files.writeString(p, "чайник: оплачен\n");
Files.writeString(p, "утюг: отменён\n");
System.out.println(Files.readAllLines(p).size());

2. Список, потом дописка. Что напечатает?

Path p = Path.of("users.txt");
Files.write(p, List.of("anna", "boris"));
Files.writeString(p, "vera", StandardOpenOption.APPEND);
System.out.println(Files.readAllLines(p));

  • [anna, borisvera]

3. ★ Порядок закрытия. Класс Res печатает «open X» в конструкторе и «close X» в close(). Что напечатает?

try (Res a = new Res("A"); Res b = new Res("B")) {
    System.out.println("body");
    throw new RuntimeException("boom");
} catch (RuntimeException e) {
    System.out.println("catch");
} finally {
    System.out.println("finally");
}
  • open A, open B, body, catch, close B, close A, finally
  • open A, open B, body, close A, close B, catch, finally
  • open A, open B, body, close B, close A, catch, finally

Скомпилируется ли?

7. Здесь main — без throws. Скомпилируется?

public static void main(String[] args) {
    String text = Files.readString(Path.of("notes.txt"));
    System.out.println(text);
}
  • Да, если файл notes.txt существует
  • Нет: IOException не поймано и не объявлено
  • Да, но упадёт при запуске

8. ★★ Удаляем всё в папке. Скомпилируется?

try (Stream<Path> s = Files.walk(Path.of("build/tmp"))) {
    s.sorted(Comparator.reverseOrder()).forEach(Files::delete);
}
  • Да, ведь main объявлен с throws IOException
  • Нет: checked IOException нельзя выбросить из лямбды
  • Нет: ссылку на метод нельзя передать в forEach

9. Скомпилируется?

try (String name = "report.txt") {
    System.out.println(name);
}
  • Да, напечатает report.txt
  • Нет: String не AutoCloseable
  • Нет: не хватает catch

10. ★★ Ловим «на всякий случай». Скомпилируется?

try {
    System.out.println("Привет");
} catch (IOException e) {
    System.out.println("ошибка");
}
  • Да, catch просто не сработает
  • Нет: IOException в этом try никогда не бросается

Читаем код

Головоломки решены — теперь прочитай строки этого модуля вслух правильными словами: создание объекта Path, вызов статического метода Files.…, аргумент, возвращаемое значение, try-с-ресурсами. В одних заданиях выбери верное описание из пяти, в других собери его из квадратиков.

Хочешь ещё?

Что тренирует этот набор

  • Запись по умолчанию перезаписывает; дописывание — CREATE, APPEND.
  • Относительный путь — от рабочей папки; нет файла — NoSuchFileException.
  • Потоки надо закрывать; try-с-ресурсами закрывает в обратном порядке и до catch.
  • IOException — checked: компилятор требует обработку, не даёт ловить лишнее и не выпускает из лямбды.
  • Мелочи CSV и properties: хвосты split, повторный ключ, list против walk.
