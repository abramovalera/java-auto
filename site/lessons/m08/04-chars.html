Перебор строки по символам

Почти любая задача на строки — «пройди по символам и что-то с каждым сделай». Научимся обходить строку циклом, узнаем, что char — это на самом деле число, и познакомимся с помощником Character.

⏱ 20 минут🔢 char — это число🔍 трассировка

Повторение

Два способа обойти строку

Способ 1: for + charAt — когда нужен номер

String s = "Java";
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
    System.out.println(i + ": " + c);
}
0: J
1: a
2: v
3: a

Это главный цикл модуля 6, только вместо поля a.length — вызов метода s.length(), а вместо обращения по индексу a[i] — вызов s.charAt(i): на каждой итерации объявляем c и инициализируем символом, который вернул метод. Индекс i нужен, когда важно где символ: идти с конца, смотреть на соседа charAt(i + 1), сравнивать первую и последнюю букву.

Способ 2: toCharArray + for-each — когда номер не нужен

for (char c : s.toCharArray()) {
    System.out.println(c);
}

Вызов toCharArray() возвращает обычный массив char[] (копию — строка, как всегда, не меняется). По массиву удобно идти for-each: на каждой итерации переменной c присваивается очередной символ.

Какой выбрать

Нужен только сам символ — for-each. Нужна позиция, обратный порядок или сосед — обычный for с charAt. Изменить символ «на месте» в строке нельзя ни так, ни так. А вот элементу массива из toCharArray() — можно присвоить новый символ, и потом собрать новую строку: new String(chars).

char — это число в маскировке

Компьютер хранит только числа. Каждой букве, цифре и знаку в таблице Юникод (Unicode) присвоен свой номер — код. Переменная char хранит именно его, а на экран выводится картинка буквы.

Раз char — число, с ним работает арифметика:

char c = 'a';
System.out.println(c + 1);          // 98   — char + int = int, это число!
System.out.println((char) (c + 1)); // b    — обратно к char: следующая буква
c++;                                // ++ сам оставляет тип char
System.out.println(c);              // b

char digit = '7';
int value = digit - '0';            // 55 - 48 = 7 — настоящая цифра из символа
System.out.println(value * 2);      // 14

System.out.println('a' < 'z');      // true — символы сравниваются как числа
c + 1

Как только символ — операнд арифметического оператора, Java превращает его в int (помнишь расширение типов из модуля 3?). Значение выражения — число 98, его передают аргументом, и println печатает число.

(char) (c + 1)

Приведение типа обратно к char: «число 98 покажи как символ» — это b.

digit - '0'

Классический приём: выражение «код символа минус код нуля» = значение цифры. '7' - '0' → 7. Работает, потому что цифры в таблице идут подряд.

Что выведет System.out.println("Java".charAt(1) + "Java".charAt(2)); ?

215, а не «av»! Оба вызова charAt возвращают char, строковых операндов в выражении нет. Значит, оператор + — сложение кодов: 'a' (97) + 'v' (118) = 215. Чтобы получилась склейка, нужна строка в начале: "" + s.charAt(1) + s.charAt(2) → «av». Это снежный ком из модуля 1, только с символами.

'a' и "a" — разные вещи

'a' — символьный литерал, примитив char, сравнивается через == — и это правильно. "a" — строковый литерал, объект, сравнивается по содержимому через equals. А "a" == 'a' даже не скомпилируется: incomparable types: String and char. Частая ошибка: if (s.charAt(0) == "a") — справа должна быть одинарная кавычка.

Помощник Character

Проверять «это буква?» через коды — неудобно и опасно (кириллица, ё, другие алфавиты). В Java для этого есть класс Character с готовыми статическими методами — их вызывают, как Math.abs, через имя класса и передают символ аргументом:

МетодВопросПример
Character.isDigit(c)цифра?'7' → true, 'a' → false
Character.isLetter(c)буква (любого алфавита)?'ё' → true, '5' → false
Character.isLetterOrDigit(c)буква или цифра?'!' → false
Character.isUpperCase(c) / isLowerCase(c)заглавная / строчная?'Ж' → true / false
Character.isWhitespace(c)пробел, табуляция, перевод строки?' ' → true
Character.toUpperCase(c) / toLowerCase(c)вернуть букву в другом регистре'ё' → 'Ё'

Это статические методы — такие же, какие ты объявлял в модуле 7, только объявленные авторами Java. Символ передаётся аргументом и попадает в параметр, ответ метод возвращает через return.

🔎 Для любопытных: почему с ё вечные проблемы

Буква «ё» добавлена в Юникод отдельно от остального алфавита: 'а'…'я' — коды 1072…1103 подряд, а 'ё' — 1105, за пределами этого диапазона. Поэтому проверка «буква ли это» через c >= 'а' && c <= 'я' пропустит ё. А Character.isLetter('ё') — не пропустит. Ещё одна причина пользоваться готовыми методами.

Шаблон «собрать новую строку»

Строку поменять нельзя — значит, новую строку собирают символ за символом. Роль — накопитель: инициализируем его пустой строкой "" и на каждой итерации присваиваем результат склейки.

Пример из жизни: в логах нельзя хранить номер карты целиком. Нужно заменить все цифры, кроме последних четырёх, на звёздочки:

String card = "4276 1234 5678 9012";
String result = "";
for (int i = 0; i < card.length(); i++) {
    char c = card.charAt(i);
    if (Character.isDigit(c) && i < card.length() - 4) {
        result = result + '*';      // цифра не из последних четырёх — прячем
    } else {
        result = result + c;        // пробелы и последние 4 цифры — как есть
    }
}
System.out.println(result);
**** **** **** 9012
String result = "";

Накопитель инициализируют пустой строкой, а не null: иначе в начале результата окажется слово «null».

i < card.length() - 4

Последние 4 символа — индексы от length() - 4 до конца. Всё, что левее, маскируем. Строка длиной 19: прячем цифры с индексами 0…14.

result = result + c;

Каждая склейка создаёт новую строку, и её присваивают переменной result (урок 8.1). Для 19 символов — не страшно. Для 100 000 — уже да. Как правильно — следующий урок.

Что будет, если в теле цикла написать result = c + result; вместо result = result + c; ?

Каждый новый символ будет приклеиваться в начало, и строка соберётся задом наперёд! Для «кот»: «к» → «ок» → «ток». Это один из способов развернуть строку — разберём в Мастерской (урок 8.7).

Коротко

  • Обход: for + вызов charAt(i), если нужен индекс; for (char c : s.toCharArray()), если нет.
  • char — число (код в Юникоде). 'a' + 1 → 98, (char) ('a' + 1) → 'b', '7' - '0' → 7.
  • char + char — сложение чисел, не склейка. Для склейки нужен строковый операнд в начале.
  • Character.isDigit / isLetter / isUpperCase / toUpperCase… — готовые проверки и преобразования.
  • Символы сравнивают через ==, строки — по содержимому, через equals.
  • Новая строка собирается накопителем, инициализированным пустой строкой "".
