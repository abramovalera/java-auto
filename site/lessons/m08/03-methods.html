Методы строк: искать, резать, чистить

У строки десятки готовых методов. Разберём два десятка самых нужных: как найти кусок текста, вырезать его, почистить от пробелов, разбить на слова и склеить обратно.

Повторение

Строка — ряд пронумерованных символов

Всё, что ты знаешь про индексы массивов, работает и для строк: нумерация с нуля, последний символ — под номером length() - 1, выход за край — исключение.

length или length()?

У массива длина — поле, без скобок: arr.length. У строки — метод, со скобками: s.length(). Перепутаешь — не скомпилируется. Запоминалка: строка «умеет посчитать» себя — значит, это вызов метода, а у вызова есть скобки.

Найти: indexOf, contains, startsWith, endsWith

String url = "https://shop.ru/cart/items";

url.indexOf("/cart")       // 15 — позиция, с которой начинается кусок
url.indexOf('z')           // -1 — не нашли
url.lastIndexOf('/')       // 20 — ищет с конца, последнее вхождение
url.indexOf('/', 9)        // 15 — ищет, начиная с позиции 9
url.contains("cart")       // true  — есть ли кусок где-нибудь
url.startsWith("https")    // true  — начинается ли с…
url.endsWith("/items")     // true  — заканчивается ли на…
indexOf(...)

Метод возвращает индекс первого вхождения символа (аргумент — символьный литерал в одинарных кавычках) или куска строки (строковый литерал в двойных). Не нашёл — −1. Это тот самый приём «−1 = не нашли» из поиска по массиву в модуле 6.

lastIndexOf(...)

То же, но возвращает индекс последнего вхождения. Удобно для «всё после последнего слэша» или «расширение файла после последней точки».

contains / startsWith / endsWith

Возвращают boolean — их вызов сразу ставят в условие if. Их вызывают постоянно: «имя файла заканчивается на .pdf», «сообщение начинается с “Ошибка”».

"banana".indexOf("an") — сколько? А "banana".lastIndexOf("an")?

1 и 3. b-an-ana: первое «an» начинается с индекса 1. ban-an-a: последнее — с индекса 3. Метод возвращает позицию начала найденного куска.

Вырезать: substring и его границы

Метод substring вырезает кусок строки и возвращает его как новую строку. Два перегруженных варианта — с одним и с двумя аргументами:

String s = "Hello, Java!";
s.substring(7)        // "Java!"  — от индекса 7 до конца
s.substring(7, 11)    // "Java"   — от 7 ВКЛЮЧИТЕЛЬНО до 11 НЕ включительно
s.substring(0, 5)     // "Hello"
s.substring(3, 3)     // ""       — пустой кусок, не ошибка
s.substring(12)       // ""       — от самого конца: тоже пустая строка
s.substring(13)       // 💥 StringIndexOutOfBoundsException
Аналогия: батон и нож

Аргументы substring — не ломтики, а места, куда ставишь нож. substring(7, 11) — «режу перед 7-м ломтиком и перед 11-м». Всё, что между надрезами, — твоё. Отсюда удобные правила: длина куска = конец − начало, а substring(0, s.length()) — вся строка целиком.

А вот что будет, если поставить нож за краем батона — substring(13) у строки длиной 12:

Номера строк в String.java у тебя могут быть другими — они зависят от версии JDK. А вот Cut.java:5 будет таким же.

Самое частое применение — вместе с indexOf: найти разделитель, а его индекс передать аргументом в substring — и отрезать то, что до или после него.

String email = "ivan.petrov@mail.ru";
int at = email.indexOf('@');              // 11
String login = email.substring(0, at);    // "ivan.petrov" — всё ДО @
String domain = email.substring(at + 1);  // "mail.ru" — всё ПОСЛЕ @ (без @)
А что будет, если в строке нет @, а мы всё равно делаем email.substring(0, email.indexOf('@'))?

Вызов indexOf вернёт −1, и получится substring(0, -1) — StringIndexOutOfBoundsException. Поэтому перед вырезанием проверяют: if (at != -1) { … }. Граничный случай «а если не нашли?» — первое, о чём думает опытный программист.

Почистить и переделать: trim, toUpperCase, replace, repeat

Помни урок 8.1: все эти методы возвращают новую строку. Возвращаемое значение — присваиваем переменной.

String raw = "   Иван Петров  ";
raw.trim()               // "Иван Петров" — убрал пробелы только по краям
raw.strip()              // то же, но понимает и «экзотические» пробелы
raw.isEmpty()            // false — длина не 0
"   ".isEmpty()          // false — пробелы тоже символы!
"   ".isBlank()          // true  — пустая ИЛИ из одних пробелов
"".isEmpty()             // true

"Java".toUpperCase()     // "JAVA"
"Java".toLowerCase()     // "java"
"мама".replace('м', 'п') // "папа" — все вхождения, не только первое
"1 000 000".replace(" ", "")  // "1000000" — заменить кусок на пустоту = удалить
"-".repeat(10)           // "----------"
"Java".concat("!")       // "Java!" — склейка, то же, что "Java" + "!"
МетодКогда нужен
trim() / strip()Ввод пользователя, текст со страницы: лишние пробелы по краям — главная причина «одинаковые строки, а equals = false». strip() новее (Java 11) и убирает и необычные пробелы из Юникода, которые встречаются в текстах с сайтов.
isEmpty() / isBlank()Проверить, ввели ли хоть что-то. Для формы «имя обязательно» правильнее isBlank() — три пробела именем не считаются.
toLowerCase()Сравнить без учёта регистра или привести всё к одному виду перед поиском.
replace(a, b)Заменить все вхождения символа или куска. Удалить — заменить на "".
repeat(n)Повторить строку n раз — рамки, линии, отступы (Java 11).
concat(s)Приклеить строку s в конец и вернуть результат. Делает то же, что +, только это вызов метода. В коде обычно пишут +, а concat встречается в чужом коде и головоломках — и, как все методы String, исходную строку не меняет.
Что выведет: String s = " hi "; s.trim(); System.out.println("[" + s + "]"); ?

[ hi ] — с пробелами! Вызов trim() вернул новую строку, но её не присвоили. Надо s = s.trim();. Это уже второй раз в модуле — значит, правда важно.

Методы можно вызывать цепочкой: каждый вызов возвращает новую строку, и у неё сразу вызывается следующий метод. Как конвейер на кухне: помыли → почистили → нарезали.

String input = "  ДА  ";
// "  ДА  " → "ДА" → "да" → true
if (input.trim().toLowerCase().equals("да")) {
    System.out.println("Согласие получено");
}

Разбить и склеить: split и join

Метод split режет строку по разделителю (его передают аргументом) и возвращает массив строк — а с массивами ты умеешь всё.

String date = "2026-11-27";
String[] parts = date.split("-");          // ["2026", "11", "27"]
System.out.println(parts.length);          // 3
System.out.println(parts[0]);              // 2026

String csv = "Иван;Петров;25";
String[] cells = csv.split(";");           // ["Иван", "Петров", "25"]

String joined = String.join(", ", cells);  // "Иван, Петров, 25"
String path = String.join("/", "home", "user", "docs");  // "home/user/docs"
Ловушки split

1. Лишние пробелы. " кот пёс ".split(" ") даст ["", "", "кот", "", "", "пёс"] — пустые строки там, где пробелы шли подряд или стояли в начале. Пустые в конце Java отбрасывает сама, а в начале и в середине — нет.

Рецепт для слов: s.trim().split("\\s+") — сначала убрать пробелы по краям, потом резать по «одному или нескольким пробелам подряд». Пока бери как готовую формулу, подробности про такие шаблоны — в уроке 8.8.

Почему слэша два? Шаблон «пробелы подряд» сам по себе пишется \s+ — с одним обратным слэшем. Но внутри кавычек Java обратный слэш — спецсимвол: помнишь \n (перевод строки) из модуля 1? Чтобы в строку попал сам символ \, в кавычках его пишут дважды. Поэтому в коде пишем "\\s+", а в строке окажется \s+ — ровно то, что нужно методу split. Забудешь второй слэш — "\d" вообще не скомпилируется (illegal escape character), а "\s+" скомпилируется, но коварно: \s в кавычках Java понимает как обычный пробел, и табуляция разделителем уже не будет. Правило: в шаблонах для split слэш всегда двойной.

2. Пустая строка. "".split(" ") — это массив из одного элемента "", а не пустой массив. Подсчёт слов через длину массива split(...).length для пустого ввода скажет «1 слово». Проверяй isBlank() заранее.

3. Точка и некоторые другие символы. "a.b.c".split(".") вернёт пустой массив! Точка в split — особый символ «любой символ». Правильно: split("\\."). Тоже подробности в уроке 8.8.

"a,b,,c,,".split(",").length — сколько?

4: ["a", "b", "", "c"]. Пустая строка между двумя запятыми в середине остаётся, а пустые хвосты в конце отбрасываются.

Из числа в строку и обратно

Текст из файла и ввод пользователя — всегда строки. Чтобы посчитать, их надо превратить в числа, и наоборот: вызываем метод, передаём аргумент, и он возвращает значение нужного типа.

String s1 = String.valueOf(42);       // "42" — число → строка
String s2 = "" + 42;                  // "42" — тоже работает, через склейку
String s3 = String.valueOf('x');      // "x"  — символ → строка

int n = Integer.parseInt("42");        // 42   — строка → int
double d = Double.parseDouble("3.5");  // 3.5  — строка → double
int bad = Integer.parseInt("42 руб."); // 💥 NumberFormatException — не число

Типичная задача: из чека прочитали строку «Итого: 1 299 ₽», вырезали число, убрали пробелы, parseInt — и сверили с суммой товаров. Каждый шаг — метод из этого урока.

String.valueOf(42) + 1 — что получится? А Integer.parseInt("42") + 1?

"421" — строка плюс число = склейка. И 43 — parseInt вернул настоящее число типа int. Тип операндов решает всё.

Попроси задачку

Напиши наставнику: «Дай мне 3 мини-задачи на substring и indexOf: строка на входе, что нужно вырезать. Ответы не говори, пока я не напишу свои».

Коротко

  • Индексы строки — как у массива: с 0 до length() - 1. У строки length() со скобками.
  • Вызов indexOf возвращает позицию или −1. contains/startsWith/endsWith возвращают boolean.Вызов indexOf возвращает позицию или −1. contains/startsWith/endsWith возвращают boolean.
  • substring(a, b): от a включительно до b не включительно, длина b − a. Числа — «разрезы между символами».
  • trim/strip, toUpperCase, replace возвращают новую строку — присваивай возвращаемое значение.
  • split возвращает массив; для слов — s.trim().split("\\s+"). String.join склеивает обратно.
  • String.valueOf — в строку, Integer.parseInt — в число.
