Мастерская: задачи на строки

«Разверни строку» — та самая задача с LeetCode, на которой когда-то застрял автор этого курса. Не из-за сложного кода, а из-за пустого экрана: с чего начать? Сегодня разберём её по шаблону шаг за шагом, а потом так же — палиндром, гласные и «каждое слово с заглавной».

Повторение

Шаблон решения

Шесть шагов — те же, что в Мастерских модулей 5 и 6. Не прыгай сразу к коду: код — это пятый шаг, а не первый.

  1. Пойми задачу. Что на входе, что на выходе? 2–3 примера, обязательно граничные: пустая строка, одна буква, пробелы, разный регистр.
  2. Реши руками и запиши, что делал. Какие действия повторялись?
  3. Найди роли переменных: шагающая, накопитель, счётчик, максимум, флаг, временная.
  4. Псевдокод на русском — план без синтаксиса.
  5. Код — перевод псевдокода строка в строку.
  6. Трассировка: таблица «шаг | переменные» руками или отладчиком IDEA. Потом — граничные случаи.

Строки — идеальный полигон для этого шаблона: задачи короткие, примеры легко придумать, а граничных случаев полно. Первая задача — по всем шести шагам, подробно. Остальные — быстрее, но по тому же плану.

Задача 1. Разворот строки: понять, руками, роли

Задача. Дана строка. Получить строку, в которой символы идут в обратном порядке. Готовый reverse() не использовать — на собеседовании просят именно «руками».

Шаг 1. Вход и выход, примеры:

ВходВыходЗачем этот пример
"кот""ток"обычный, короткий — на нём будем решать руками
"Hello, Java!""!avaJ ,olleH"пробелы и знаки — тоже символы, тоже разворачиваются
"a""a"граничный: одна буква
""""граничный: пустая строка — код не должен упасть

Шаг 2. Руками. Возьми бумажку и напиши «кот» по буквам в клеточках. Как получить «ток»? Читаешь буквы с конца и выписываешь их по порядку на новую строчку: сначала «т», потом приписываешь «о», потом «к».

Шаг 3. Роли переменных. Что менялось, пока ты работал руками?

i
Шагающая (счётчик цикла) от конца к началу: инициализируем значением s.length() - 1, потом на один меньше… до 0 включительно. Это палец, который скользит по исходной строке справа налево.
result
Накопитель: инициализируем пустой строкой "", на каждой итерации к нему приписывается одна буква. В конце в нём ответ.
Аналогия: разобрать стопку тарелок

Тарелки ставили в стопку по одной: к, о, т (т сверху). Снимаешь сверху и ставишь в новую стопку рядом — первой окажется т, последней к. Чтобы получить обратный порядок, достаточно брать «с конца».

Разворот: псевдокод, код, трассировка

Шаг 4. Псевдокод:

result ← пустая строка
для i от последней позиции до 0 (включительно):
    приписать к result символ s[i]
напечатать result

Шаг 5. Код — строка в строку:

String s = "кот";
String result = "";
for (int i = s.length() - 1; i >= 0; i--) {
    result = result + s.charAt(i);
}
System.out.println(result);
int i = s.length() - 1

Инициализация счётчика: последняя позиция — длина минус один. Самая частая ошибка — инициализировать s.length(): первая же итерация бросит StringIndexOutOfBoundsException.

i >= 0

Условие цикла: включительно до нуля — первая буква тоже нужна. С i > 0 потеряется «к» и выйдет «то».

result + s.charAt(i)

Левый операнд — строка, значит оператор + склеивает (а не складывает коды, как char + char), и результат присваивается result.

Шаг 6. Трассировка. Пройди сам и предскажи значения:

Граничные случаи — в голове: "a": i = 0, одна итерация, result = «a» ✓. Пустая "": i инициализируется значением −1, условие -1 >= 0 ложно сразу, тело цикла не выполнится, напечатается пустая строка ✓. Ничего не падает.

Тот же алгоритм — через StringBuilder

Склейка в теле цикла создаёт новую строку на каждой итерации (урок 8.5). Для длинного текста правильно собирать в черновик. Алгоритм тот же, меняется только накопитель: вместо присваивания — вызов append:

StringBuilder result = new StringBuilder();
for (int i = s.length() - 1; i >= 0; i--) {
    result.append(s.charAt(i));
}
System.out.println(result.toString());

Версия с LeetCode: массив символов и два указателя

На LeetCode (задача 344 «Reverse String») строку дают сразу массивом char[] и просят развернуть на месте — без второй строки. Это ровно разворот массива из Мастерской модуля 6: два «пальца» с краёв меняют символы и идут навстречу.

char[] chars = s.toCharArray();
int left = 0;
int right = chars.length - 1;
while (left < right) {
    char tmp = chars[left];         // временная — «третий стакан»
    chars[left] = chars[right];
    chars[right] = tmp;
    left++;
    right--;
}
String reversed = new String(chars);   // из массива обратно в строку

Видишь? Задача, которая пугала пустым экраном, — это две уже знакомые вещи: обход с конца + накопитель или разворот массива + toCharArray. Новое в программировании почти всегда собирается из старых кирпичиков. Найти, из каких, — и есть шаги 1–3.

Новичок написал for (int i = s.length(); i >= 0; i--). Что произойдёт?

На первой же итерации выполнится вызов s.charAt(s.length()) — это за краем строки: StringIndexOutOfBoundsException. Последний индекс — length() - 1. Трассировка на бумаге поймала бы это на первой строке таблицы.

Задача 2. Палиндром: два указателя

Задача. Палиндром — строка, которая одинаково читается слева направо и справа налево: «шалаш», «казак». Проверить, палиндром ли строка, не обращая внимания на регистр, пробелы и знаки препинания: «А роза упала на лапу Азора» — палиндром.

Шаг 1. Примеры:

ВходОтветЗачем
"казак"дапростой, нечётная длина
"abba"дачётная длина — середины нет
"Казак!"дарегистр и знак не учитываем
"А роза упала на лапу Азора"дапробелы не учитываем
"кошка"нетобычное «нет»
"я", ""даграничные: одна буква и пустая строка — тоже палиндромы

Шаг 2. Руками. Задачу удобно разбить на две части — как в модуле 7, на два метода:

  1. Почистить: оставить только буквы и цифры, всё в нижнем регистре. «А роза упала…» → «арозаупаланалапуазора».
  2. Проверить чистую строку: смотрю на первую и последнюю букву — равны? Тогда на вторую и предпоследнюю… Пальцы идут навстречу. Нашёл разные — сразу «нет». Пальцы встретились — «да».

Шаг 3. Роли. Для чистки — накопитель clean (в коде — StringBuilder sb). Для проверки — две шагающие left (слева направо) и right (справа налево) и флаг ok («пока всё совпадает»).

Шаг 4. Псевдокод:

clean ← пустая строка
для каждого символа c строки:
    если c — буква или цифра: приписать к clean маленькую c
left ← 0, right ← последняя позиция clean, ok ← да
пока left левее right:
    если clean[left] ≠ clean[right]: ok ← нет, выйти из цикла
    left вправо, right влево
напечатать ok

Шаг 5. Код:

public static String clean(String s) {
    StringBuilder sb = new StringBuilder();
    for (char c : s.toCharArray()) {
        if (Character.isLetterOrDigit(c)) {
            sb.append(Character.toLowerCase(c));
        }
    }
    return sb.toString();
}

public static boolean isPalindrome(String w) {
    int left = 0;
    int right = w.length() - 1;
    while (left < right) {
        if (w.charAt(left) != w.charAt(right)) {
            return false;            // несовпадение — дальше смотреть незачем
        }
        left++;
        right--;
    }
    return true;                     // пальцы встретились, всё совпало
}

// в main (выведет true):
// System.out.println(isPalindrome(clean("А роза упала на лапу Азора")));
return вместо флага

В методе флаг ok и break можно заменить на return false: метод сразу возвращает значение и завершается. Это тот же «флаг», только Java хранит его за нас. А return true после цикла — «проверил всё, несовпадений нет».

Шаг 6. Трассировка проверки для уже чистого слова «казак»:

Граничный случай: что сделает isPalindrome для пустой строки ""? А для "я"?

Для "": right инициализируется значением −1, условие 0 < -1 ложно, тело цикла не выполнится, метод вернёт true. Для "я": left = right = 0, 0 < 0 ложно — тоже true. Без единого лишнего if. Хороший алгоритм часто сам правильно обрабатывает края — но проверить это надо обязательно.

Задача 3. Сколько гласных

Задача. Посчитать гласные в тексте — русские и английские, регистр не важен. «Привет, мир!» → 3 (и, е, и).

  1. Примеры: «Java» → 2; «ОКНО» → 2 (заглавные тоже); «ртуть» → 1; «Xyz» → 0; «» → 0.
  2. Руками: иду по буквам и для каждой спрашиваю «гласная?» — да: загибаю палец.
  3. Роли: шагающая по символам, счётчик count, инициализированный нулём.
  4. Хитрость для «гласная?»: вместо десяти || держим все гласные в одной строке и вызываем у неё indexOf, передав символ аргументом: метод вернул не −1 — значит, гласная.
Что посчитает программа, если забыть toLowerCase() и подать «ОКНО»?

0. В строке vowels только маленькие буквы, а 'О' и 'о' — разные символы с разными кодами. Поэтому приводим текст к одному регистру до проверки. Это граничный случай «другой регистр» из шага 1 — вот зачем его придумывать заранее.

Задача 4. Каждое слово с заглавной

Задача. «привет java мир» → «Привет Java Мир»: первая буква каждого слова — заглавная, остальные — строчные, между словами один пробел.

Шаг 1. Граничные случаи — их тут больше, чем кажется: лишние пробелы в начале, в конце и между словами; слово из одной буквы («я»); «КРИК» → «Крик»; пустая строка.

Шаги 2–4. Руками: делю на слова → у каждого слова первую букву делаю большой, остальное маленьким → склеиваю через пробел. Роли: шагающая по словам (переменная w в for-each), накопитель-StringBuilder.

если строка пустая или из пробелов: результат — пустая строка, конец
слова ← разбить обрезанную строку по пробелам
для каждого слова w:
    если это не первое слово: приписать пробел
    приписать заглавную первую букву w
    приписать остаток w маленькими

Шаг 5. Код:

String line = "  привет   java мир ";
StringBuilder sb = new StringBuilder();
if (!line.isBlank()) {
    String[] words = line.trim().split("\\s+");
    for (String w : words) {
        if (sb.length() > 0) {
            sb.append(' ');
        }
        sb.append(w.substring(0, 1).toUpperCase());
        sb.append(w.substring(1).toLowerCase());
    }
}
System.out.println(sb);    // Привет Java Мир
if (!line.isBlank())

Защита от пустой строки. Без неё цепочка вызовов "".trim().split(...) вернёт массив с одной пустой строкой, и вызов w.substring(0, 1) упадёт. Граничный случай из шага 1 спас программу.

w.substring(1)

Метод возвращает всё, кроме первой буквы. Для «я» это пустая строка — не ошибка: вызов substring(1) у строки длины 1 законно возвращает "".

sb.length() > 0

Пробел — перед каждым словом, кроме первого. Знакомый приём против лишнего разделителя.

🔎 Другой способ: флаг «начало слова» без split

Можно идти по символам и держать флаг newWord: «следующая буква — начало слова». Встретил пробел — присвоил флагу true. Встретил букву при поднятом флаге — сделал её заглавной и опустил флаг. Такой вариант сохраняет пробелы как были (не схлопывает их) — смотря что нужно по условию.

boolean newWord = true;
StringBuilder sb = new StringBuilder();
for (char c : line.toCharArray()) {
    if (c == ' ') {
        newWord = true;
        sb.append(c);
    } else if (newWord) {
        sb.append(Character.toUpperCase(c));
        newWord = false;
    } else {
        sb.append(Character.toLowerCase(c));
    }
}

Проверь себя

Тренируй план, а не код

Напиши наставнику: «Дай задачу на строки уровня собеседования. Я сначала напишу примеры с граничными случаями, роли переменных и псевдокод — проверь план, прежде чем я начну кодить». Задачи на сайте — «Разворот строки», «Палиндром», «Гласные», «Каждое слово с заглавной» — решай по тому же шаблону.

Коротко

  • Шаблон: примеры с краями → руками → роли → псевдокод → код → трассировка.
  • Разворот: шагающая i, инициализированная значением length() - 1, до 0 включительно + накопитель. Или два указателя на char[].
  • Палиндром: сначала почистить (буквы/цифры, нижний регистр), потом два указателя навстречу; несовпадение — сразу «нет».
  • Подсчёт: счётчик + условие; «символ из набора?» — набор.indexOf(c) != -1.
  • Слова: защита от пустой строки, trim().split("\\s+"), первая буква — substring(0, 1).toUpperCase().
