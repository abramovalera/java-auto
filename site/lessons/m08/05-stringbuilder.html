StringBuilder: изменяемая строка

Строки неизменяемы, и склейка в цикле каждый раз создаёт новую. Для сборки текста по кусочкам в Java есть специальный «черновик» — StringBuilder. Узнаем, зачем он, как им пользоваться и во сколько раз он быстрее.

Повторение

Что не так со склейкой в цикле

Посмотрим, что творится в памяти, когда мы собираем строку из трёх букв обычной склейкой:

Аналогия: переписывать письмо начисто

Представь, что после каждого нового слова ты берёшь чистый лист и переписываешь всё письмо заново плюс одно слово. Первые строчки — быстро. На сотой странице ты уже переписываешь роман ради одной запятой. Так работает result = result + c в цикле.

StringBuilder — черновик, который можно дописывать

StringBuilder («строитель строк») — это изменяемая строка. Внутри у него массив символов с запасом места. Вызов метода append дописывает аргумент в конец того же объекта — без копирования всего текста.

StringBuilder sb = new StringBuilder();   // пустой черновик
sb.append("Привет");                      // дописали строку
sb.append(", ");
sb.append("мир").append('!');             // можно цепочкой — и char тоже
sb.append(2026);                          // и число
String result = sb.toString();            // готово — превращаем в String
System.out.println(result);               // Привет, мир!2026
new StringBuilder()

Создаём объект оператором new — как массив — и инициализируем им переменную sb. Можно сразу передать начальный текст аргументом: new StringBuilder("abc").

sb.append(x)

Вызываем метод append у объекта sb и передаём аргумент — строку, символ, число, boolean: он дописывается в конец. Метод меняет сам объект — присваивать возвращаемое значение не нужно (в отличие от методов String!).

.append('!')

append возвращает ссылку на тот же самый sb, поэтому вызовы можно нанизывать цепочкой.

sb.toString()

Когда собрали — вызов toString() возвращает обычную неизменяемую String, ею инициализируем result. Почти все методы Java ждут аргументом именно String.

Насколько это быстрее — на пальцах

Соберём строку из 100 000 букв «a». Посчитаем, сколько символов придётся скопировать.

Разница — в десятки тысяч раз по объёму работы. На обычном ноутбуке это примерно секунда против нескольких миллисекунд. А для миллиона букв склейка будет работать уже минуты, StringBuilder — всё так же мгновенно.

Проверь сам в IDEA

Замерь время: long start = System.currentTimeMillis(); перед циклом и System.currentTimeMillis() - start после — это миллисекунды. Попробуй оба варианта на 100 000 и на 300 000 итерациях. Заметь: у склейки время растёт гораздо быстрее, чем число итераций.

Когда StringBuilder, а когда обычный +

В теле цикла собираешь строку — StringBuilder. Одна строчка вроде "Привет, " + name + "!" — обычный +: компилятор сам превратит её в эффективный код. Не надо писать StringBuilder ради двух склеек — код станет только длиннее.

Что ещё умеет StringBuilder

StringBuilder sb = new StringBuilder("Java");
sb.insert(0, "I love ");      // вставить в позицию 0   → "I love Java"
sb.append('!');               // в конец                → "I love Java!"
sb.reverse();                 // развернуть ЭТОТ объект  → "!avaJ evol I"
sb.reverse();                 // и обратно              → "I love Java!"
sb.setCharAt(0, 'U');         // заменить символ        → "U love Java!"
sb.deleteCharAt(sb.length() - 1); // удалить последний → "U love Java"
sb.delete(0, 2);              // удалить [0, 2)         → "love Java"
System.out.println(sb.length());   // 9
System.out.println(sb.charAt(0));  // l
System.out.println(sb.indexOf("Java")); // 5
МетодЧто делает
append(x)дописать в конец
insert(i, x)вставить перед позицией i
reverse()развернуть задом наперёд — меняет сам объект
setCharAt(i, c) / deleteCharAt(i)заменить / удалить один символ
delete(a, b)удалить кусок, границы как у substring: a включительно, b нет
length(), charAt(i), indexOf(s)как у String
toString()получить готовую String

new StringBuilder(s).reverse().toString() — разворот строки в одну строчку. Красиво! Но на собеседовании скажут: «А теперь без reverse». Поэтому в Мастерской мы научимся разворачивать руками, а в задаче на сайте reverse будет запрещён 😉

StringBuilder a = new StringBuilder("hi"); StringBuilder b = a; b.append("!"); System.out.println(a); — что выведется?

hi! StringBuilder изменяемый, как массив. Инициализация b = a скопировала ссылку — две стрелки на один объект. Меняем через b — видно через a. Вот она, цена изменяемости: со String такого бы не случилось.

Ловушки

1. equals у StringBuilder сравнивает ссылки

new StringBuilder("abc").equals(new StringBuilder("abc")) → false! В отличие от String, у StringBuilder метод equals не сравнивает по содержимому — он сравнивает по ссылке, как ==. Сравнивать нужно готовые строки, которые вернул toString(): sb1.toString().equals(sb2.toString()).

2. StringBuilder — не String

String s = sb; не скомпилируется: инициализировать переменную типа String значением типа StringBuilder нельзя. Нужен вызов sb.toString(). А вот System.out.println(sb) работает — println сам вызывает toString у аргумента.

3. Методы String vs методы StringBuilder

У String «изменяющие» методы возвращают новую строку — возвращаемое значение надо присвоить. У StringBuilder методы меняют сам объект — присваивать не нужно. Если перепутать в одну сторону, изменения потеряются; в другую — ничего страшного, просто лишний код.

🔎 Для любопытных: StringBuffer — старший брат

Есть ещё класс StringBuffer с теми же методами. Он старше (Java 1.0) и безопасен при работе из нескольких потоков одновременно, но из-за этого медленнее. В обычном коде берут StringBuilder. На собеседовании иногда спрашивают «String vs StringBuilder vs StringBuffer» — ответ: неизменяемая / изменяемая быстрая / изменяемая потокобезопасная. Про потоки — модуль 16.

Коротко

  • Склейка + в теле цикла на каждой итерации создаёт новую строку и копирует весь текст — медленно.
  • StringBuilder — изменяемая строка: append, insert, reverse, delete… меняют сам объект.
  • Готовый результат возвращает вызов sb.toString().
  • 100 000 склеек: миллиарды копий против сотни тысяч — секунда против миллисекунд.
  • Одну строчку с + оставляй как есть. equals у StringBuilder сравнивает ссылки.
