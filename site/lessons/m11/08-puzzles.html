Что выведется на экран?

★★★ Ловушка: конструктор абстрактного класса

Эту задачку дают на собеседованиях уровня «выше джуна». Попробуй сначала сам: что напечатает new Child()?

abstract class Base {
    Base() {
        System.out.println("Создаю: " + name());
    }
    abstract String name();
}

class Child extends Base {
    private String n = "Ребёнок";

    @Override
    String name() {
        return n;
    }
}

new Child();
Подумал? Открой ответ

Создаю: null. Не «Ребёнок»! Разбери по шагам ниже, почему так.

Читаем код

Головоломки решаются быстрее, когда каждую строку читаешь правильными словами: «объявляем абстрактный метод», «класс реализует интерфейс», «переменная типа интерфейса хранит ссылку на объект». Выбери верное описание или собери его из квадратиков — лишние оставь на месте.

Найди ошибки

Ещё головоломок

Напиши наставнику: «Дай мне 3 головоломки “скомпилируется ли?” по модулю 11 — я отвечу и объясню почему». Ошибся — попроси похожую через пару дней.

Коротко

  • new нельзя: абстрактный класс, интерфейс, enum. Массив ссылок этих типов — можно.
  • abstract-метод — без тела; конкретный наследник обязан его реализовать.
  • Ромб из default-методов — ошибка компиляции, пока класс не переопределит метод сам (можно вызвать X.super.m()).
  • Константы enum сравниваются ==; valueOf строг к регистру; ordinal — с нуля.
  • record: equals по данным, == по ссылкам, поля не меняются.
  • Не вызывай переопределяемые методы из конструктора родителя — поля наследника ещё не готовы.
