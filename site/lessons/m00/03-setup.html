Что такое IDE и зачем она нужна

Код можно писать хоть в Блокноте — это обычный текст. Но программисты работают в IDE (Integrated Development Environment, «среда разработки»). Мы будем использовать самую популярную для Java — IntelliJ IDEA.

Аналогия

Блокнот — это лист бумаги и ручка. IDE — мастерская: верстак, инструменты на стене, линейка, которая сама подсказывает размер, и мастер, который заранее говорит: «тут криво, переделай».

Скачиваем и ставим IntelliJ IDEA

Потянет ли компьютер

Нужны: Windows 10 или 11, 8 ГБ оперативной памяти и 10 ГБ свободного места на диске. Посмотреть: Пуск → Параметры → Система → О системе — там строка «Установленная ОЗУ». Свободное место — в Проводнике, раздел «Этот компьютер», под диском C:. С 4 ГБ памяти IDEA тоже запустится, но будет заметно тормозить.

Ставим на Windows по шагам (на macOS — в конце списка):

  1. Открой страницу jetbrains.com/idea/download. Вверху должна быть выбрана вкладка Windows. Нажми большую кнопку Download. Рядом с ней есть список формата — оставь .exe (это установщик). .zip не бери: его надо распаковывать и настраивать вручную. Вариант .exe (ARM64) — только для редких ноутбуков на процессорах Snapdragon; если не знаешь, какой у тебя процессор, — тебе нужен обычный .exe.
  2. Платить ничего не нужно. Сайт может открыть страницу «спасибо за загрузку» или предложить подписку — просто закрой её: файл уже качается. Он большой, загрузка займёт несколько минут.
  3. Браузер сохранит файл в папку «Загрузки»: открой Проводник (Win+E) → слева «Загрузки». Файл называется примерно idea-2026.3.exe (цифры — номер версии, у тебя могут быть другие). Ещё проще — в браузере нажми Ctrl+J, там список скачанного. Запусти файл двойным щелчком.
  4. Windows спросит: «Разрешить этому приложению вносить изменения на вашем устройстве?», издатель — JetBrains s.r.o. Это обычный вопрос при установке любой программы. Нажми «Да».
  5. Откроется мастер установки на английском. На первом экране — Next. На экране Choose Install Location (куда ставить) оставь папку как есть — Next.
  6. Экран Installation Options (что ещё сделать):
    • Create Desktop Shortcut — ярлык на рабочем столе. Отметь: так проще запускать.
    • Add "Open Folder as Project" — пункт в меню правого клика по папке. По желанию.
    • Create Associations → .java — файлы .java будут открываться в IDEA двойным щелчком. По желанию.
    • Update PATH Variable (restart needed) → Add "bin" folder to the PATH — не отмечай. Это нужно, чтобы запускать IDEA командой из чёрного окна командной строки, а в курсе её нет.
    Нажми Next, на следующем экране — Install. Установка идёт пару минут.
  7. На последнем экране может быть вопрос про перезагрузку: Reboot now («перезагрузить сейчас») или I want to manually reboot later («перезагружу сам позже»). Это нормально, ничего не сломалось: обычно так бывает, если отмечен пункт про PATH (рядом с ним так и написано: restart needed — «нужна перезагрузка»). Сохрани открытые документы и выбери Reboot now — или «позже», если сейчас неудобно. Если вопроса нет — отметь Run IntelliJ IDEA и нажми Finish.
  8. Запусти IDEA (ярлык на рабочем столе или Пуск → IntelliJ IDEA). При первом запуске она может попросить принять пользовательское соглашение (User Agreement: отметь галочку и нажми Continue), спросить, можно ли отправлять анонимную статистику (Don't Send — не отправлять, можно смело), и предложить импорт настроек из другой программы — выбери Skip (пропустить): импортировать нечего.
  9. macOS: на странице загрузки выбери вкладку macOS и формат под свой процессор (Apple Silicon — для M1/M2/M3/M4, Intel — для старых). Открой скачанный файл .dmg и перетащи значок IDEA в папку «Программы» (Applications), запусти оттуда.
Пробный период Ultimate: что это и что будет потом

IntelliJ IDEA — одна программа с бесплатной частью и платной подпиской Ultimate. При первом запуске IDEA сама включает пробный период Ultimate на 30 дней — бесплатно, без карты и без регистрации. Справа вверху окна будет надпись Trial: по ней видно, сколько дней осталось.

Через 30 дней пробный период закончится сам. IDEA продолжит работать бесплатно, твои проекты и настройки останутся. Пропадут только платные функции для веб-разработки и больших фреймворков — в курсе они не нужны. Если IDEA предложит купить подписку, закрой окно: ничего покупать не надо, бесплатной части хватит на весь курс.

Язык интерфейса

Оставь интерфейс на английском. Во всех статьях и видео пункты меню называются по-английски — и в этом курсе тоже. Так проще находить нужное.

Где лежит папка курса

Курс — это папка java-course на твоём компьютере. Внутри неё лежит workspace — твой учебный проект. Сайт знает, где она, и показывает путь:

Твоя папка workspace: определяю…

Это настоящий путь на твоём компьютере, поэтому он может не совпадать с примерами в уроках. — имя твоей учётной записи Windows, под ней лежат все твои папки.

Не получилось определить автоматически. Обычно папка курса лежит в C:\Users\ТВОЁ_ИМЯ\IdeaProjects\java-course, а workspace — внутри неё. Найти точно: открой Проводник, в строке поиска справа вверху напиши java-course и дождись результата.

Скопируй путь — он понадобится в следующем шаге. Остальные папки рядом с workspace — устройство курса, их не трогай.

Скачиваем Java прямо из IDEA

Чтобы писать программы на Java, нужен JDK (Java Development Kit) — набор инструментов программиста. Что у него внутри, разберём в уроке 1.2, а сейчас просто скачаем: IDEA сделает это сама.

Иногда IDEA уже сама подставила Java, если она есть на компьютере. Тогда в поле SDK будет не <No SDK>, а номер версии. 21 или больше — ничего качать не нужно, переходи к проверке.

Открой окно Project Structure: нажми ☰ слева вверху (главное меню, как в шаге 5) → File → Project Structure… Или сразу сочетанием Ctrl+Alt+Shift+S. Слева выбери пункт Project. Окно выглядит так:

Щёлкни по выпадающему списку SDK в этом окне (там, где написано <No SDK>, выноска 2) и выбери Download JDK… (если такого пункта сразу не видно — наведи на Add SDK, он там). Откроется маленькое окно загрузки:

Ещё раз всё по шагам:

  1. Открой ☰ → File → Project Structure… (или Ctrl+Alt+Shift+S). Слева выбери Project.
  2. В поле SDK раскрой список → Download JDK… (или Add SDK → Download JDK…).
  3. В окне выбери Version: 21 (не 25 и не другую, даже если IDEA подставила её сама) и Vendor: Eclipse Temurin. Нажми Download — IDEA скачает Java (пару минут).
  4. Взгляни на Language level: там SDK default или 21 — оба варианта верные. Нажми OK.
  5. Подожди, пока IDEA закончит индексацию: внизу окна бежит полоска с надписью вроде Indexing JDK… или Scanning files to index… IDEA читает скачанную Java и составляет себе «оглавление», чтобы потом быстро подсказывать. Это 1–5 минут, в это время IDEA может подтормаживать. Она не зависла — ничего не нажимай и не закрывай, просто дождись, пока полоска исчезнет.

Готово: на твоём компьютере теперь есть настоящий JDK. Просто ставила его IDEA, а не ты руками.

Выключаем ИИ-дописывание целых строк

Пока идёт пробный период Ultimate, в IDEA работает Full Line completion — встроенный искусственный интеллект, который дописывает за тебя целые строки кода. Ты начинаешь печатать, а дальше появляется серый текст: нажал Tab — строка готова. Для работы удобно, а для учёбы вредно: это то же самое, что копировать код, — руки и голова ничего не запоминают. Выключим.

  1. Открой настройки: ☰ → File → Settings… или Ctrl+Alt+S.
  2. Слева раскрой Editor → General → Code Completion → Inline.
  3. Сними галочку Enable inline completion using language models («дописывать строки с помощью языковых моделей»).
  4. Нажми OK.

Обычные подсказки IDEA (список слов, который всплывает, пока печатаешь) остаются — это не ИИ, а словарь: он подсказывает названия, но думать за тебя не будет. Ими пользоваться можно.

Нет пункта Inline?

Значит, пробный период уже закончился или ИИ-дописывание у тебя не включено: эта функция есть только в Ultimate. Делать ничего не нужно. А если IDEA предложит включить AI Assistant или JetBrains AI — откажись: с вопросами у нас есть наставникИИ-помощник из уроков, и он не пишет код за тебя.

Застрял на подготовке

Напиши: «Готовлю IntelliJ IDEA по уроку 0.3 курса «Java с нуля», на шаге … вижу вот это: …» — и приложи скриншот экрана.

Как сделать скриншот

Нажми Win+Shift+S (Win — клавиша с логотипом Windows). Экран потемнеет — обведи мышкой нужный кусок. Картинка попадёт в буфер обмена: щёлкни в поле сообщения в чате и нажми Ctrl+V — скриншот вставится. На macOS — Cmd+Shift+4, картинка сохранится на рабочий стол, перетащи её в чат.

Коротко

  • Нужны две вещи: IntelliJ IDEA и Java (JDK 21), Java качаем прямо из IDEA. Пробный Ultimate через 30 дней закончится сам — IDEA останется бесплатной.
  • ИИ-дописывание строк выключаем: Settings → Editor → General → Code Completion → Inline.
  • Учебный проект — папка workspace в папке курса. Открываем: Open (или ☰ → File → Open…) → путь → OK → Trust Project.
  • Свой проект для уроков не создаём: сайт проверяет только workspace.
  • Всё ли готово — показывает кнопка «Проверить подготовку».
