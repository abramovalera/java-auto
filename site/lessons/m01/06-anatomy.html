Анатомия программы

Первая программа уже работает. Теперь разберём её по косточкам: что значит каждое слово, каждая скобка и каждая точка — и что из этого важно запомнить уже сейчас.

Вот она, наша программа

Это та самая программа, которую ты набрал в уроке 1.4. Всего пять строк, но в них уже есть почти всё, из чего состоит любая программа на Java:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

В уроке 1.4 ты набрал эти строки, не вникая в смысл слов, — помог шаблон psvm. Пора их расшифровать! Сначала посмотрим издалека — как на здание, — а потом зайдём внутрь.

В этом уроке ты будешь специально «ломать» программу и смотреть, что скажет IDEA. Для этого пригодятся ещё четыре клавиши. Допиши их к своей таблице из урока 1.4 — руками, на тот же листочек:

Коробки в коробках

Главное, что надо увидеть в этом коде, — вложенность. Фигурные скобки { и } работают как стенки коробки: открывающая — «тут коробка начинается», закрывающая — «тут закончилась». Внутрь одной коробки можно положить другую.

Аналогия: дом

Файл — участок земли. На нём стоит дом — это класс. В доме есть комнаты — это методы, и одна из них особенная: прихожая main, через неё в дом входят все гости. А инструкции — то, что происходит в комнате: «включи свет», «поставь чайник».

Забыл закрыть скобку — получилась комната без стены. Java не поймёт, где кончается одно и начинается другое, и откажется компилировать.

Разбор по строкам

Теперь зайдём внутрь. Слева — код, справа — что он значит.

public class HelloWorld {

Объявление класса. class — «вот класс», HelloWorld — его имя (придумываешь ты). public — «публичный», доступный всем. { открывает коробку класса.

public static void main(String[] args) {

Объявление метода main — точка входа. Когда ты жмёшь ▶, IDEA запускает JVM, а JVM ищет именно этот метод и начинает выполнение с него. { открывает коробку метода — его тело: всё, что между { и }.

System.out.println("Hello, World!");

Инструкция — одно законченное действие: «напечатай в консоль строку Hello, World!». Здесь это вызов метода println: в скобках ему передаётся аргумент — строка "Hello, World!", которую надо напечатать. Инструкция заканчивается точкой с запятой ;.

}

Закрываем тело метода main. Когда выполнение дойдёт сюда, программа закончится.

}

Закрываем класс HelloWorld.

Метод main — входная дверь

Метод — именованный кусок кода, который что-то делает. В классе их может быть много, но у программы должен быть один особый — main (по-английски «главный»). С него JVM начинает выполнение — строчка за строчкой, сверху вниз. Пройди программу по шагам сам:

Аналогия: книга

Книгу читают с первой страницы, а не с середины. Метод main — первая страница программы. Если его нет, JVM не знает, откуда начинать, и при запуске сообщит: main method not found.

А что за слова вокруг main? Честно: сейчас их нужно запомнить как формулу. Каждое по-настоящему разберём в модулях про методы и классы. Но краткое объяснение полезно уже сейчас:

public
«Публичный» — JVM снаружи может вызвать этот метод.
static
«Статический» — метод можно вызвать, не создавая объект. Что такое объект — помнишь котов из урока 1.1? Подробно — в модуле 9.
void
«Пустота» — метод ничего не возвращает в ответ, просто делает свою работу.
main
Имя метода. Именно такое — с маленькой буквы, иначе JVM его не найдёт.
String[] args
Сюда попадают аргументы — то, что можно передать программе при запуске. Пока не используем, но писать обязательно.
Лайфхак IDEA

Внутри класса напечатай psvm (public static void main) или main и нажми Tab — строка появится сама. Но первые несколько раз набери её руками: так она быстрее запомнится.

Забыл, как называлось сокращение? Ctrl+J покажет список всех шаблонов с пояснениями. А Ctrl+Space подскажет, чем можно закончить начатое слово. Выписывать их пока не обязательно.

System.out.println — читаем по точкам

Точка в Java означает «внутри» или «у кого». Читать System.out.println удобно как почтовый адрес — от большого к маленькому:

Текст для печати пишется в двойных кавычках: "Hello, World!". Такой текст называется строкой (по-английски string), а строка, записанная прямо в коде в кавычках, — строковым литералом. Кавычки говорят Java: «это не код, а просто текст — выведи его как есть».

Скомпилируется ли строка System.out.println(Hello); — без кавычек?

Нет. Без кавычек Hello — уже не текст, а имя чего-то, что Java должна знать. Ничего с таким именем нет, поэтому будет ошибка cannot find symbol — «не знаю такого имени». Текст всегда в двойных кавычках: "Hello".

🔎 Для любопытных: что на самом деле стоит за System.out.println

System — класс из стандартной библиотеки Java, out — объект внутри него, который умеет печатать, println — метод (умение) этого объекта. Вся строка читается так: «вызываем метод println у объекта System.out и передаём ему аргумент». За одной строкой прячется длинная цепочка готового кода — вплоть до операционной системы. Подробно «провалимся» туда в модулях 7 и 9, когда будешь знать методы и классы.

Точка с запятой и регистр букв

Каждая инструкция в Java заканчивается точкой с запятой ; — как точка в конце предложения: «мысль закончена, дальше следующая». После строк с { и } точку с запятой не ставят: скобки — стенки коробок, а не инструкции.

public class HelloWorld {                   // без ; — это начало коробки
    public static void main(String[] args) {  // без ;
        System.out.println("Раз");          // ; — инструкция закончилась
        System.out.println("Два");          // ;
    }                                       // без ;
}
Аналогия: диктант

Без точек диктант превращается в кашу: «я пришёл домой мама сказала иди обедать». Где кончается одна мысль? Компилятор думает так же: без ; он не понимает, где кончается инструкция, и пишет ';' expected — «ожидалась точка с запятой».

И ещё: для Java System и system — два совершенно разных слова. Как «Иван» и «иван» для паспортного стола: одна буква — и человека «не существует».

ПравильноНеправильноПочему
Systemsystemкласс System пишется с большой буквы
printlnPrintLn, printInвсе буквы маленькие; и это «л» (line), а не «ай»
String[] argsstring[] argsString — тоже класс, с большой буквы
mainMainJVM ищет метод именно main
В println: буква перед «n» — это «I» (большая i) или «l» (маленькая L)?

Маленькая L: println — от print line, «напечатай строку». Опечатка printIn — одна из самых частых у новичков: в некоторых шрифтах эти буквы почти одинаковые. IDEA подчеркнёт её красным: cannot resolve method, а компилятор скажет cannot find symbol.

Комментарии и отступы

Комментарий — текст в коде, который компилятор полностью пропускает. Он нужен людям: тебе через месяц, коллеге, наставнику. Чаще всего встречаются два вида:Комментарий — текст в коде, который компилятор полностью пропускает. Он нужен людям: тебе через месяц, коллеге, DeepSeek. Чаще всего встречаются два вида:

/*
   Многострочный комментарий.
   Всё от открывающих до закрывающих знаков игнорируется.
*/
public class HelloWorld {
    /** Документирующий комментарий: что делает метод ниже */
    public static void main(String[] args) {
        // Однострочный комментарий: от // до конца строки
        System.out.println("Hello, World!"); // можно и после кода
        // System.out.println("Эта строка не выполнится");
    }
}

Видишь строку над main с двумя звёздочками /** … */? Это третий вид — документирующий комментарий (Javadoc). Его пишут над классом или методом и объясняют, что он делает. Из таких комментариев IDEA собирает подсказку, которая всплывает при наведении мышки на имя метода. Пока просто узнавай его в чужом коде.

Зачем это тебе прямо сейчас

Подписывай своими словами, что делает строка, — так лучше запоминается. А чтобы временно «выключить» строку, не удаляя её, закомментируй её: в IDEA — Ctrl + /.

А вот та же программа, сжатая в две строки без отступов. Она скомпилируется и заработает:

public class HelloWorld { public static void main(String[] args) {
System.out.println("Hello, World!"); } }

Компилятору безразличны пробелы, переносы и отступы. Но человеку читать такое — пытка. Поэтому правило: каждый уровень вложенности сдвигается на 4 пробела вправо — по отступу сразу видно, в какой коробке строка. Имя класса и имя файла

В Java весь код живёт внутри классов: нельзя написать println посреди пустого файла. Пока считай класс контейнером для кода. И есть железное правило: имя файла совпадает с именем public-класса буква в букву, плюс .java.

Класс в кодеИмя файлаРезультат
public class HelloWorldHelloWorld.java✅ всё хорошо
public class HelloWorldhelloworld.java❌ регистр букв не совпадает
public class HelloWorldMain.java❌ имена разные
Типичная ловушка

Поменял имя класса в коде (например, HelloWorld на Hello), а файл — нет. IDEA подчеркнёт имя красным, а компилятор скажет: class Hello is public, should be declared in a file named Hello.java. Чтобы переименовать правильно, щёлкни по имени класса и нажми Shift + F6 (Refactor → Rename) — IDEA переименует и класс, и файл.

Имя придумываешь ты, но программисты договорились о правилах — соглашениях об именовании. Компилятор их не проверяет, но код не по правилам выглядит как сочинение без заглавных букв:

  • Класс — с большой буквы: HelloWorld, Calculator, Tree.
  • Слова склеиваются, каждое с большой буквы: MyFirstProgram. Это называют PascalCase (иногда — CamelCase с большой буквы): большие буквы торчат, как горбы верблюда. А имена переменных и методов пишут в camelCase — так же, но первое слово с маленькой: main, firstName. Подробнее — в модуле 2.
  • Только латиница и цифры, без пробелов и дефисов: AboutMe — хорошо, About Me и about-me — ошибка компиляции.
  • Имя объясняет, что внутри: Postcard лучше, чем Test1.
Попробуй сам в IDEA

Открой свой HelloWorld.java и по очереди сделай маленькие «поломки». Каждый раз смотри, что подчеркнула IDEA, наведи мышку на красное и прочитай сообщение. После каждой поломки возвращай как было (Ctrl + Z):

  1. убери точку с запятой в конце строки с println;
  2. напиши system с маленькой буквы;
  3. удали последнюю закрывающую скобку };
  4. переименуй класс в Hello прямо в тексте, не трогая файл.

Непонятные сообщения пока не пугают — в уроке 1.7 научимся их читать.

Коротко

  • Программа — вложенные коробки: файл → класс → метод main → инструкции. У каждой { есть пара }.
  • main — точка входа: JVM выполняет его инструкции сверху вниз. Строку с main пока запоминаем как формулу.
  • System.out.println("…") — вызов метода println у объекта System.out с аргументом-строкой: «система, напечатай в вывод строку и перейди на новую». Текст — в двойных кавычках (строковый литерал).
  • Инструкция заканчивается ;. Регистр важен: System ≠ system.
  • Имя файла = имя public-класса. Классы — PascalCase: каждое слово с большой буквы (MyFirstProgram).
  • Комментарии // и /* */ — заметки для людей, /** */ — документация к классу или методу (Javadoc); отступы — для читаемости.
