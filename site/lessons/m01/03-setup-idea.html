⏱ 20 минут🗂 проект и окно IDEA🖼 со скринами

Как устроен твой проект

Папка workspace, которую ты открыл в уроке 0.3, — это и есть твой учебный проект в IDEA. Вот что внутри:

  • Новый класс — правый клик по нужной папке → New → Java Class → имя (покажем в следующем уроке).
  • Папки модулей module-01 … module-18 уже на месте. Заготовки задач (например, сломанный код, который надо починить) появляются в папке модуля, когда открываешь его страницу «Практика».

Если папка вдруг серая

Синяя папка — значит «здесь код». Если какая-то папка серая (например, ты создал её сам), IDEA не будет её компилировать: не будет ▶ и всё подчеркнётся красным. Лечится так: правый клик по папке → Mark Directory as → Sources Root.

Зачем это

Это как сказать библиотекарю: «книги — вот на этой полке». В проекте бывают картинки, заметки, настройки, а компилировать нужно только код. Синяя папка — значит «здесь код, его надо собирать».

Код не запускается?

Первым делом проверь две вещи: папка синяя? SDK выбран (урок 0.3, шаг 6)?

Как устроено окно IDEA

Мастерская готова. Запомни четыре главных места в окне IDEA — дальше в уроках мы будем постоянно на них ссылаться. Вот как окно будет выглядеть уже в следующем уроке, когда ты напишешь и запустишь первую программу:

Свой проект с нуля: что выбрать

Для уроков ничего создавать не нужно — workspace уже готов. Но свой проект тебе однажды понадобится: после курса — для пет-проекта (урок 17.9), а потом на работе. Поэтому разберём окно создания проекта по каждому полю.

Сейчас — бегло

Прочитай этот шаг один раз, чтобы знать, где он. Пригодится в конце курса, когда заведёшь свой пет-проект (урок 17.9). Что такое класс, main, psvm и sout — подробно в следующих уроках, 1.4 и 1.5.

Меню File → New → Project… (или кнопка New Project на стартовом экране). Слева выбери Java.

Если в поле JDK пусто

Значит, на компьютере ещё нет Java (или IDEA её не нашла). Раскрой список JDK и выбери Download JDK… — откроется то же окно, что в уроке 0.3: Version 21, Vendor Eclipse Temurin, Download.

А JVM настраивать надо?

Нет. JVM лежит внутри JDK (помнишь матрёшку JDK ⊃ JRE ⊃ JVM?). Выбрал JDK 21 — у проекта есть и компилятор, и JVM. Больше ничего настраивать не нужно.

Позже, в больших программах, иногда передают параметры JVM — например, сколько памяти можно взять программе. Они задаются в Run → Edit Configurations… → Modify options → Add VM options. Сейчас туда заходить не нужно — просто знай, где это.

«Модули» курса и модули IDEA — разные вещи

В меню IDEA есть File → New → Module. Модуль IDEA — это часть большого проекта со своими папками кода и своими библиотеками (в Gradle-проектах так выглядят подпроекты). Нам он не нужен. Модуль курса — просто папка module-01, module-02… в workspace, они уже готовы и синие.

Зачем помечать папку как Sources Root?

  • Чтобы папка была красивого синего цвета
  • Чтобы IDEA знала, что в этой папке лежит код, который надо компилировать
  • Чтобы скачалась Java

Коротко

  • Учебный проект — workspace: папки module-01…18 для задач и training для примеров из уроков.
  • Папку с кодом помечаем как Sources Root — она синяя.
  • Свой проект: File → New → Project → Java, Build system IntelliJ, JDK 21. JVM отдельно не настраивается — она внутри JDK.
  • Новый класс: правый клик по синей папке → New → Java Class.
