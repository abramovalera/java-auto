Привет! Я Джавик ☕

Я кружка кофе — и талисман этого курса. Почему кофе? Ява — остров в Индонезии, где растёт знаменитый кофе. Создатели языка пили его литрами и назвали язык в его честь.

Java — это язык программирования: язык, на котором люди пишут компьютеру инструкции. «Покажи на экране это», «посчитай то», «если нажали кнопку — сделай вот это».

Вот как выглядит маленький кусочек программы на Java:

System.out.println("Привет, мир!");

Эта строка — одна инструкция, то есть законченное действие программы: она выводит на экран текст Привет, мир! Пока она похожа на заклинание — это нормально. К концу модуля ты будешь понимать в ней каждую букву, а в середине курса мы заглянем «под капот» и увидим, сколько всего за ней стоит.

Java ≠ JavaScript

Самая частая путаница! JavaScript назвали так в 1995 году маркетологи — чтобы прокатиться на популярности Java. Общего у языков почти ничего нет. Ищешь ответ в интернете — проверяй, что пример именно про Java.

Объекты: чертёж и вещи

Про Java часто говорят: объектно-ориентированный язык (ООП). Звучит страшно, а идея простая.

Посмотри вокруг: мир состоит из вещей. У каждой вещи есть свойства (цвет, размер, имя) и умения (кот мяукает, машина едет). Java предлагает собирать программу так же — из «вещей», которые называются объектами.

Аналогия

Класс — это чертёж. По чертежу дома можно построить сколько угодно домов: у одного красная крыша, у другого синяя, но устроены они одинаково. Каждый построенный дом — это объект.

Попробуй сам: ниже чертёж (класс) Кот. Построй по нему несколько котов и нажми на любого.

Запомни три слова: класс — чертёж, объект — вещь по чертежу, метод — то, что вещь умеет. Писать свои классы начнём в модуле 9, а пока просто держи в голове эту картинку.

Java убирает за собой

Пока программа работает, каждый объект занимает место в памяти компьютера. Когда объект больше не нужен, Java сама освобождает его место. Этим занимается специальная часть Java — сборщик мусора. В некоторых других языках программисту приходится убирать за собой вручную.

Пока этого достаточно. Как устроена память, разберём в модуле 2, когда появятся переменные.

🔎 Для любопытных: как сборщик понимает, что объект — мусор (можно пропустить)

Программа держит объекты за ниточки, как воздушные шарики. Если к объекту не ведёт ни одна ниточка, программа уже никогда до него не дотянется. Это и есть мусор.

Переменная
Имя-ярлычок, которое держит ниточку. В игре это кот1, кот2, кот3. Подробно — в модуле 2.
Ссылка
Та самая ниточка от переменной к объекту. Программисты говорят: «переменная ссылается на объект».
null
«Пусто», «ни на кого». Написать кот1 = null — значит, отпустить ниточку.
Куча
Так называют область памяти, где живут объекты. Справа в игре — это она.

Поиграй с памятью: создавай котов, отпускай ниточки и смотри, что сделает сборщик.

Две переменные смотрят на одного кота. Одну обнулили. Уберёт ли сборщик кота?

Нет. Пока хотя бы одна ниточка держит объект, он «живой», и сборщик его не тронет. Мусор — только то, к чему не ведёт ни одна ниточка. Проверь это в игре кнопкой = кот1.

Коротко

  • Java показали миру в 1995 году, первая версия Java 1.0 вышла в 1996-м. Мы учимся на Java 21 (LTS — версия с долгой поддержкой: её исправляют и обновляют много лет).
  • Java работает в банках, на серверах, в Android и даже в Minecraft. JavaScript — другой язык.
  • Класс — чертёж, объект — вещь по чертежу, метод — умение вещи.
  • Объекты живут в памяти. Ненужные объекты Java убирает сама — это работа сборщика мусора.
