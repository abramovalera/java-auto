Чек-лист: я умею…

Отметь про себя каждый пункт

  • объяснить своими словами, что такое Java и где её используют;
  • рассказать путь программы: .java → javac → .class → JVM — и что происходит на каждом шаге;
  • объяснить разницу между JDK, JRE и JVM и почему Java работает на любой системе;
  • установить IntelliJ IDEA, скачать в ней JDK 21 и пометить папку как Sources Root;
  • создать класс, запустить его кнопкой ▶ — и объяснить, что эта кнопка делает под капотом;
  • написать программу с нуля, не подглядывая: объявление класса, метод main, инструкция вывода;
  • объяснить, зачем нужны { }, ;, кавычки у строковых литералов и почему имя файла совпадает с именем класса;
  • выводить текст через print/println, со спецсимволами и склейкой — и не попадаться в ловушку «2 + 2 = 22»;
  • прочитать сообщение компилятора и найти ошибку по номеру строки.
