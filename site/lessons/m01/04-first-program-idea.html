Первая программа в IntelliJ IDEA

Сейчас мы вместе напишем первую программу. Шаг за шагом: что нажать, что ты увидишь на экране и что это значит. Открой IDEA рядом и повторяй.

Прежде чем начать: выпиши себе

Опытные программисты почти не пользуются мышкой: у IDEA есть сочетания клавиш и короткие слова-шаблоны, которые экономят кучу времени. Возьми листочек или заметки в телефоне и выпиши эту таблицу руками — так она запомнится быстрее. Ко всем пунктам мы ещё вернёмся в уроке.

Не надо запоминать сразу — выпиши и подглядывай, через неделю пальцы запомнят сами.

Выпиши себе: IntelliJ IDEA, часть 1

Шаблоны набираешь в редакторе и жмёшь Tab (или Enter в подсказке).

На macOS вместо Ctrl обычно Cmd.

Про Ctrl+Y: в первый раз IDEA спросит, что назначить на эти клавиши — «Удалить строку» (Delete Line) или «Повторить» (Redo). Выбери Delete Line и подтверди — дальше строка будет удаляться одним нажатием.

Создаём класс

IDEA создала файл

Файл называется HelloWorld.java, а класс внутри — HelloWorld. В Java они обязаны совпадать буква в букву. IDEA следит за этим сама.

Точка входа: метод main

Когда ты запускаешь программу, Java ищет, с какой строчки начать. Это место называется точкой входа, и в Java это всегда метод main — как входная дверь в дом. Без него программу нельзя запустить.

Можно набрать его целиком, а можно хитро: внутри класса напечатай psvm — IDEA покажет подсказку. Нажми Tab или Enter:

IDEA вставит метод main целиком. Теперь внутри него таким же приёмом: sout + Tab превращается в System.out.println();. Курсор окажется между скобками — впиши туда текст в кавычках:

Первые пару раз — руками

Шаблоны — это ускорение, а не замена понимания. Набери public static void main(String[] args) и System.out.println целиком хотя бы два-три раза — пальцы должны знать, что вставляет psvm. Что значит каждое слово, разберём в следующем уроке «Анатомия программы».

Запускаем ▶

Нажми на зелёный треугольник ▶ слева от строки public class HelloWorld и выбери Run 'HelloWorld.main()'. Или просто Ctrl+Shift+F10 — из твоей шпаргалки.

Смотрим в консоль

Внизу откроется панель Run — это консоль: сюда программа печатает всё, что ты велел ей напечатать. Вот что ты увидишь:

Поздравляю, ты программист! 🎉 Серьёзно: каждый разработчик в мире начинал ровно с этой строчки.

Под капотом кнопка ▶ сделала весь конвейер из урока 1.2: вызвала компилятор javac, положила HelloWorld.class в папку out (её видно в дереве проекта слева, если раскрыть; трогать её не нужно — IDEA сама её заполняет), запустила JVM — и показала тебе вывод.

Микроприёмы: попробуй прямо сейчас

Пора опробовать шпаргалку. Каждый приём — 10 секунд, а экономит часы.

Ctrl+Alt+L — выровнять код

Специально «сломай» отступы: сдвинь строки как попало. Нажми Ctrl+Alt+L — IDEA всё расставит ровно:

Ctrl+Alt+O — убрать лишние импорты

Проведём эксперимент. Добавь в самую первую строку файла import java.util.Scanner; (это «подключение» класса для ввода с клавиатуры — пройдём в модуле 2). Мы его нигде не используем, поэтому IDEA покажет строку серой:

Ctrl+D и Ctrl+Y — копия строки и удаление строки

Поставь курсор на строку с System.out.println и нажми Ctrl+D — строка задублируется. Поменяй текст в копии и запусти: напечатаются две строки. Теперь удали копию: курсор на неё и Ctrl+Y (в первый раз выбери Delete Line). Никакого выделения мышкой.

Помощники, а не волшебники

Alt+Enter иногда «чинит» не то, что нужно. Прежде чем соглашаться, прочитай, что он предлагает.

Первая задача и проверка

Твой HelloWorld — это уже решение задачи 1! Открой страницу Практика, найди «Привет, мир!» и нажми Проверить. Сайт сам скомпилирует и запустит твой файл.

Покажи наставнику

Когда проверка зелёная, напиши в Claude Code: /check m01-t01. Наставник посмотрит код и задаст пару вопросов — так задача засчитывается окончательно.

Коротко

  • Новый класс: правый клик по module-01 → New → Java Class.
  • Точка входа — метод main (psvm + Tab), печать — инструкция System.out.println (sout + Tab).
  • Запуск — зелёный ▶ или Ctrl+Shift+F10; вывод — в панели Run, exit code 0 = всё хорошо.
  • Выписанная шпаргалка: Ctrl+Alt+L, Ctrl+Alt+O, Ctrl+D, Ctrl+Y — пользуйся каждый день.
