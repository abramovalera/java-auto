Вывод в консоль

Консоль — первый способ программы «поговорить» с тобой. Научимся печатать в ней что угодно: несколько строк, текст с кавычками, таблички и даже результаты вычислений.

⏱ 25–30 минут⌨️ много практики — открой IDEA

Песочница в IDEA

Консоль — это панель Run внизу IDEA, куда программа печатает текст. Через неё программа сообщает результат, а программист подглядывает, что происходит внутри. Даже в больших программах консоль пригодится: туда пишут, какой шаг сейчас выполняется и что пошло не так.

Как проходить этот урок

В твоём проекте есть синяя папка training — тренировочная: туда до конца курса пойдут все примеры из уроков (схема проекта — в уроке 1.3). Один раз заведи в ней песочницу:

  1. Правый клик по папке training → New → Java Class → Playground.
  2. Внутри — точка входа main (psvm + Tab), как в уроке 1.4.

Нет папки training или она серая? Правый клик по workspace → New → Directory → training, затем правый клик по ней → Mark Directory as → Sources Root.

Дальше в уроках будут два вида кода. Кусочек без класса — набираешь внутрь main песочницы (старое можно стирать). Целая программа с class — создаёшь в training новый класс с таким именем. Над каждым примером есть кнопка «✍️ Куда набирать?» — она напомнит. Набирай руками и перед каждым запуском ▶ пробуй угадать, что выведет программа.

Примеры ниже — это строчки для вставки внутрь main твоей песочницы. Класс и main вокруг них я не повторяю, чтобы не загромождать.

print и println

Ты уже знаешь метод System.out.println. У него есть «брат» — метод System.out.print, без ln. Разница в одном: что происходит после печати.

  • println (print line) — печатает текст и переходит на новую строку.
  • print — печатает текст и остаётся на той же строке. Следующий вывод приклеится сразу за ним.

Чтобы это увидеть, представь каретку — невидимый курсор в консоли, который показывает, куда попадёт следующий символ.

Аналогия: пишущая машинка

На старой пишущей машинке после каждой буквы каретка сдвигалась вправо, а чтобы начать новую строку, нужно было дёрнуть рычаг. print — печатает и не трогает рычаг. println — печатает и в конце дёргает рычаг.

Что выведет: print("А"); println("Б"); print("В"); 
АБ
В

print("А") оставил каретку после «А», и «Б» приклеилась к ней. println после «Б» перевёл строку, и «В» оказалась на новой.

Если вызвать println без аргумента — с пустыми скобками, — он просто переведёт строку. Так удобно делать пустую строку между блоками текста:

System.out.println("Глава 1");
System.out.println();            // пустая строка
System.out.println("Жил-был код...");
Глава 1

Жил-был код...
А print() так нельзя

Вызов System.out.print() без аргумента, с пустыми скобками, — ошибка компиляции: «напечатай ничего и останься на месте» бессмысленно, и Java такого не разрешает. IDEA сразу подчеркнёт это красным.

Строки и спецсимволы

Всё, что внутри кавычек, Java печатает как есть — даже если там что-то похожее на код:

System.out.println("System.out.println(1 + 1);");
System.out.println(1 + 1);

Но как напечатать саму кавычку? Ведь кавычка для Java значит «строка закончилась». Для этого есть спецсимволы (escape-последовательности): обратный слеш \ и символ после него. Слеш говорит Java: «следующий символ — особенный, не понимай его буквально».

Обратный слеш — как фраза «внимание, это не всерьёз» перед репликой. Без неё кавычка значит «конец строки», с ней — «просто нарисуй кавычку». \n — не «буква n», а «перенеси строку». \\ — «нарисуй сам слеш».

Слеш не тот

Спецсимволы начинаются с обратного слеша \ (наклон влево, клавиша над Enter). Прямой слеш / — обычный символ: "1/2" печатается как есть.

А если после \ стоит буква, которой нет в таблице, IDEA сразу покажет ошибку. Частый случай — путь к папке с одиночными слешами:

Как одним вызовом println вывести три строки: «Раз», «Два», «Три»?

Поставить между словами \n: System.out.println("Раз\nДва\nТри");. Результат как от трёх отдельных вызовов println. Какой вариант выбрать — дело вкуса: три println обычно читать проще.

Склейка строк через +

Знак + между строками их склеивает — по-научному конкатенация:

System.out.println("Привет, " + "Вася" + "!");
System.out.println("Привет," + "Вася");
Привет, Вася!
Привет,Вася

Видишь вторую строку? Java не добавляет пробелы сама: склейка — это буквально «приставить одно к другому». Пробел кладут внутрь одной из строк.

Строку можно склеивать и с числом — число превратится в текст:

System.out.println("Мне " + 17 + " лет");
Мне 17 лет

Зачем, если можно написать "Мне 17 лет" целиком? Сейчас — незачем. Но уже в модуле 2 вместо 17 будет стоять переменная, и склейка станет главным способом собрать текст из кусочков. Например, так собирают сообщения вроде "Товаров в корзине: " + count.

Java как калькулятор

Если передать в println аргументом число без кавычек, Java напечатает число. А если написать в скобках пример — сначала посчитает, а потом выведет ответ:

System.out.println(2 + 2);       // без кавычек — это пример
System.out.println("2 + 2");     // в кавычках — просто текст
System.out.println(10 - 3);
System.out.println(6 * 7);       // * — умножение
System.out.println(20 / 4);      // / — деление
System.out.println(2 + 3 * 4);   // сначала умножение, как в школе
System.out.println((2 + 3) * 4); // скобки меняют порядок

Сюрприз с делением

Попробуй System.out.println(7 / 2);. Ответ будет 3, а не 3.5! Целое число, делённое на целое, даёт целое: дробная часть отбрасывается. Почему так и как получить 3.5 — в модуле 3. Пока просто запомни, что так бывает.

Ловушка: строка + число + число

Хочется вывести красивое «2 + 2 = 4». Новички пишут так:

System.out.println("2 + 2 = " + 2 + 2);
Как думаешь, что выведет эта строка? Подумай, прежде чем открывать. 
2 + 2 = 22

Не 4, а 22! Разбираемся ниже.

Java выполняет плюсы по очереди, слева направо. А знак + ведёт себя по-разному: между двумя числами — складывает, а если хотя бы с одной стороны строка — склеивает.

Починка простая — скобки: «сначала посчитай это, а потом приклеивай»:

System.out.println("2 + 2 = " + (2 + 2));
2 + 2 = 4
Аналогия: снежный ком

Выражение катится слева направо, как снежный ком. Пока ком — число, к нему прибавляются числа. Но стоит ему налипнуть на строку, он сам становится строкой, и всё дальше просто прилипает сбоку как текст. Скобки — способ слепить отдельный комочек заранее и приклеить его целиком.

На этой ловушке спотыкаются все — и на собеседованиях её спрашивают постоянно. Правило одно: смотри, что стоит слева от плюса. Строка — дальше всё склеивается.

Коротко

  • println печатает и переводит строку, print — печатает и остаётся на месте. Пустой println() — просто перевод строки.
  • Спецсимволы начинаются с \: \n — новая строка, \t — табуляция, \" — кавычка, \\ — сам слеш.
  • + со строкой склеивает, между числами — складывает. Пробелы сами не появляются.
  • Без кавычек Java считает: + - * /, умножение раньше сложения. Целое делить на целое — дробь отбрасывается.
  • Ловушка: "2 + 2 = " + 2 + 2 даёт «22». Лечится скобками: "2 + 2 = " + (2 + 2).
