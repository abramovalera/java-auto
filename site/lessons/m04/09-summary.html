Карта модуля

Раньше программа была поездом на одних рельсах. Теперь у неё есть стрелки, и она сама выбирает путь — даже ведёт Джавика-курьера по коридорам и развилкам. Это огромный шаг!

Чек-лист: я умею…

Отметь про себя каждый пункт

  • написать if, if-else и цепочку else if, назвать в них условие, тело и ветки и нарисовать цепочку блок-схемой с ромбами;
  • объяснить, почему в цепочке выполняется только первая подходящая ветка и как из-за порядка ветка может стать «мёртвой»;
  • сказать, сколько веток выполнится в if, if-else, цепочке с else и без него, в нескольких отдельных if — и почему переменная, которой значение присвоено только в ветках без последнего else, «might not have been initialized»;
  • найти ловушки: = вместо ==, ; после if, if без скобок, «висячий» else, == у строк, == у double, 0 < x < 10;
  • записать выбор из двух значений тернарным оператором — и понять, когда он вредит читаемости; не писать лишний if там, где хватит boolean ok = x > 0;;
  • написать классический switch с break и новый со стрелками; объяснить провал без break; сделать switch по строке без учёта регистра через toLowerCase();
  • сделать switch-выражение и объяснить, зачем в нём default;
  • перед кодом составить таблицу случаев с граничными значениями и псевдокод;
  • найти максимум или минимум «рекордсменом».
