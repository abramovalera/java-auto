Тернарный оператор ? :

Иногда if-else нужен только для того, чтобы выбрать одно из двух значений. Для этого в Java есть короткая запись в одну строку. Разберёмся, как она работает и когда ей лучше не пользоваться.

⏱ 12 минут❓ выбор в одну строку

Повторение

if-else, который выбирает значение

Частая ситуация: переменной нужно присвоить одно значение или другое — в зависимости от условия.

int age = 15;
int price;
if (age < 18) {
    price = 150;
} else {
    price = 300;
}

Пять строк ради одного выбора. Тернарный оператор ? : — это выражение, которое возвращает одно из двух значений. Он делает то же самое в одну строку:

int price = age < 18 ? 150 : 300;

Читается так: «возраст меньше 18? Тогда 150, иначе 300». Схема всегда одна: условие ? значение_если_да : значение_если_нет. А целиком строка читается так: «объявляем переменную price типа int и инициализируем её результатом тернарного оператора: если условие age < 18 истинно — 150, иначе — 300».

Слово «тернарный» значит «тройной»: у этого оператора три операнда — условие и два значения. Это единственный такой оператор в Java, поэтому его так и зовут.

Где он хорош

int a = 7, b = 12;
int max = a > b ? a : b;                          // 12 — большее из двух

int n = 9;
String parity = n % 2 == 0 ? "чётное" : "нечётное";

boolean isVip = true;
System.out.println("Пропуск: " + (isVip ? "VIP" : "обычный"));
Пропуск: VIP

В последней строке тернарный стоит прямо внутри выражения склейки строк, а результат всего выражения передаётся аргументом в println. Обрати внимание на скобки вокруг него — без них не обойтись.

Предскажи: скомпилируется ли строка без скобок? System.out.println("Возраст: " + age >= 18 ? "взрослый" : "ребёнок");

Нет. У + приоритет выше, чем у >=, а у тернарного — ниже, чем у них обоих. Java сначала склеит "Возраст: " + age — получится строка, потом попробует сравнить строку с 18: bad operand types for binary operator '>='. Правило: тернарный внутри println или склейки — всегда в скобках.

Тернарный — это выражение, а не инструкция

Главное отличие от if: тернарный оператор возвращает значение. Его нельзя использовать, чтобы просто «сделать одно или другое»:

// не скомпилируется
age >= 18 ? System.out.println("Можно") : System.out.println("Нельзя");
// правильно
System.out.println(age >= 18 ? "Можно" : "Нельзя");

Метод println ничего не возвращает: у его вызова нет значения, которое можно куда-то положить, — это действие. Поэтому тернарный должен выбирать что напечатать, а печатать будет один println снаружи.

Оба варианта — одного типа

String s = ok ? "да" : 0; не скомпилируется: результат тернарного должен поместиться в переменную, а 0 — не строка. Если ветки — числа разных типов, Java приводит их к общему: true ? 1 : 2.0 даёт 1.0, а не 1.

Когда тернарный не нужен

Тернарные можно вкладывать друг в друга. Технически это работает:

String grade = score >= 90 ? "Отлично" : score >= 75 ? "Хорошо"
        : score >= 60 ? "Удовл." : "Пересдача";

Но через неделю ты сам не поймёшь эту конструкцию с первого взгляда. Цепочка else if из урока 4.2 длиннее, зато читается как список.

Коротко

  • условие ? a : b — если условие true, значение a, иначе b.
  • Это выражение: его результат присваивают переменной или передают аргументом в println. Делать «действия» им нельзя.
  • Внутри склейки строк — всегда в скобках: у тернарного оператора приоритет ниже, чем у + и сравнений.
  • Хорош для выбора одного из двух коротких значений. Больше вариантов — бери else if.
