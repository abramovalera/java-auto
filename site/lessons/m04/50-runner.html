Игра «Раннер»: научи Джавика прыгать

Джавик бежит по трассе, навстречу — жуки и летучие ошибки. Сначала пробеги сам, а потом научи его делать это без тебя — с помощью if, который ты только что выучил.

⏱ 30–40 минут🏃 3 уровня✍️ код прямо на странице

Сначала — руками

Джавик бежит сам. Твоя работа — вовремя нажимать: прыжок через жука 🐛 на земле и присесть под летучей ошибкой 🦇 на уровне головы. Попробуй — и обрати внимание, за сколько клеток до препятствия ты нажимаешь (это показывает радар справа).

Что ты сейчас делал

Перед каждым нажатием ты смотрел вперёд и решал: если впереди близко жук — прыгаю, если летучая ошибка — приседаю, иначе просто бегу. Это и есть программа. Осталось записать её на Java — и Джавик будет бегать сам.

Как то же самое записать кодом

На каждом ходу игра вызывает твой метод decide и передаёт ему аргумент — радар. Метод смотрит на радар и возвращает команду: "RUN" — бежать, "JUMP" — прыгнуть, "DUCK" — пригнуться.

Вызов метода у радараЧто вернёт
radar.distance()Сколько клеток до ближайшего препятствия. Впереди пусто — 99.
radar.isLow()true — это жук на земле (прыгай), false — летучая ошибка (пригнись).
radar.speed()Сколько клеток Джавик пробегает за ход: 1 или 2 (понадобится на уровне 3).
Новые слова: метод, вызов метода, return

Методы подробно будут в модуле 7, а для игры хватит трёх вещей. Вот метод с одним правилом «жук близко — прыгай» (в редакторе ниже он такой же, только пока без if — сразу return "RUN";):

public String decide(Radar radar) {
    if (radar.distance() <= 2) {
        return "JUMP";
    }
    return "RUN";
}✍️ код пишется в редакторе ниже
decide(Radar radar)

Метод — кусок кода с именем, как main. Запускаешь его не ты: его вызывает игра на каждом ходу и передаёт ему аргумент — радар. Внутри метода он доступен под именем radar. String перед именем значит: метод обязан вернуть строку.

radar.distance()

Вызов метода у объекта radar — ты уже так делал: scanner.nextInt(), "Да".equals(answer). Радар отвечает числом, и это число можно сразу сравнивать в условии, как обычное значение.

return "JUMP";

return — «верни»: метод отдаёт игре значение "JUMP" и сразу заканчивается. Строки ниже на этом ходу уже не выполнятся. Поэтому после if с return не нужен else: до последнего return "RUN"; доходим, только если условие было ложным.

Прыжок длится 4 хода, присед — 3. Прыгнешь поздно — врежешься в жука. Прыгнешь рано — приземлишься прямо на него. А за сколько клеток надо? Мы специально не говорим: пробуй разные числа и смотри забег — так работают настоящие программисты.

Как искать ошибку

Открой трассу с ❌ и пролистай ходы до столкновения. Спроси себя: что показывал радар? какая ветка if сработала? какая должна была? Можно печатать подсказки себе: System.out.println("до жука " + radar.distance()); — напечатанное появится под трассой на нужном ходу.

Наставник

Застрял — напиши /hint m04-r2 (номер уровня в конце). Прошёл уровень — /check m04-r1: наставник спросит, почему выбрал именно такое число клеток.

Коротко

  • Игра на каждом ходу вызывает метод decide, передаёт ему радар аргументом и выполняет команду, которую метод вернул.
  • Правила записываются через if / else: «если близко жук — прыгай, если летучая — пригнись, иначе беги».
  • Не знаешь число — экспериментируй: запусти, посмотри ход столкновения, поправь.
