switch: выбор из многих

Когда одну переменную сравнивают с длинным списком значений, цепочка else if превращается в простыню. Для таких случаев есть switch — сначала старый, с известной ловушкой, а потом современный, без неё.

Повторение

Зачем нужен switch

Программа выводит название дня недели по номеру. Через else if это выглядит так:

if (day == 1) {
    System.out.println("Понедельник");
} else if (day == 2) {
    System.out.println("Вторник");
} else if (day == 3) {
    System.out.println("Среда");
} // … и ещё четыре раза одно и то же: day == …

Все проверки задают один и тот же вопрос: «чему равен day?». Для этого и придуман оператор switch («переключатель»): он берёт одно значение и сразу прыгает к нужному варианту — к своей ветке case.

Аналогия: лифт

В лифте ты не спрашиваешь на каждом этаже: «Это пятый? Нет. Это шестой? Нет…». Ты нажимаешь кнопку 7 — и лифт едет прямо на седьмой. switch так же: смотрит на значение и едет прямо к подходящему case («случаю»).

Классический switch с break

Этот вариант был в Java с самого начала. Его до сих пор много в рабочем коде, поэтому знать его надо обязательно.

int day = 3;
switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
    case 3:
        System.out.println("Среда");
        break;
    default:
        System.out.println("Нет такого дня");
}
Среда
switch (day)

Что проверяем — в скобках: выражение, по значению которого выбирается ветка. Это значение, а не условие: не day == 3, а просто day.

case 3:

Метка: «если day равно 3 — начинай отсюда». После case — конкретное значение и двоеточие: литерал (3, 'A', "start") или константа — переменная с final, которую сразу инициализировали литералом (урок 2.3: final int SUNDAY = 7; → case SUNDAY:). Обычную переменную после case поставить нельзя — значение метки должно быть известно ещё до запуска программы. Двух одинаковых меток быть не может.

break;

Инструкция break — выход из switch. Без неё начнётся самое интересное — см. следующий шаг.

default:

Ветка default — «во всех остальных случаях», как последний else. Необязательна, но почти всегда полезна. Заметь: после неё break нет. В последней ветке он не нужен — ниже switch и так заканчивается. Многие всё равно ставят его и там, по привычке: если позже кто-то допишет снизу новый case, провала в него не будет.

Провал без break

Метка case — это только точка входа, а не граница. Java прыгает на подходящую метку и дальше выполняет инструкции подряд, вниз, не глядя на остальные метки, — пока не встретит break или конец switch. Это называется провал (по-английски fall-through).

Предскажи: что напечатает этот же код для day = 1? А для day = 9?

Для 1: «Пн», «Вт», «Ср», «Готово» — провал через два case до break. Для 9: подходящей метки нет, прыгаем на default: «?», «Готово».

Иногда провал полезен — когда для нескольких значений нужно одно действие. Метки ставят друг под другом:

switch (day) {
    case 6:
    case 7:
        System.out.println("Выходной");
        break;
    default:
        System.out.println("Рабочий день");
}

Забытый break — одна из самых известных ошибок в истории программирования. Компилятор молчит: вдруг ты провалился специально? Поэтому в Java 14 появился switch, где проваливаться нельзя.

Новый switch со стрелками

Вместо двоеточия — стрелка ->. После стрелки выполняется только своя инструкция (или свой блок в фигурных скобках), и сразу выход. Никакого провала и никаких break.

switch (day) {
    case 1 -> System.out.println("Понедельник");
    case 2 -> System.out.println("Вторник");
    case 3 -> System.out.println("Среда");
    case 4 -> System.out.println("Четверг");
    case 5 -> System.out.println("Пятница");
    case 6, 7 -> {
        System.out.println("Выходной!");
        System.out.println("Можно поспать");
    }
    default -> System.out.println("Нет такого дня");
}
  • case 6, 7 -> — несколько значений через запятую вместо «лесенки» меток.
  • Если в ветке несколько инструкций — блок в фигурных скобках.
  • Смешивать : и -> в одном switch нельзя — компилятор не пустит.
Какой писать

В новом коде пиши switch со стрелками: он короче и безопаснее. Классический надо уметь читать — его полно в старых проектах и на собеседованиях («что выведет switch без break?»).

По чему можно делать switch

В скобках switch может стоять int (и меньшие целые byte, short), char и String. Нельзя: long, double, float, boolean.

Scanner scanner = new Scanner(System.in);
String command = scanner.nextLine();
switch (command) {
    case "start" -> System.out.println("Запускаю игру");
    case "stop" -> System.out.println("Останавливаю");
    case "help" -> System.out.println("Команды: start, stop, help");
    default -> System.out.println("Неизвестная команда: " + command);
}

Хорошая новость: switch по строкам сравнивает их по тексту (внутри он сам вызывает equals), так что ловушки с == из урока 4.3 здесь нет. Но регистр важен: "Start" не совпадёт с "start". Вот запуск, где ввели команду с большой буквы:

Как принять и «start», и «Start», и «START»? Перед switch переведём ввод в маленькие буквы: вызовем у строки метод toLowerCase(). Он возвращает новую строку — ту же, но из маленьких букв (сама command не меняется; подробнее о методах строк — в модуле 8). switch сравнивает уже её:

Scanner scanner = new Scanner(System.in);
String command = scanner.nextLine();
switch (command.toLowerCase()) {          // "Start", "START" → "start"
    case "start" -> System.out.println("Запускаю игру");
    case "stop" -> System.out.println("Останавливаю");
    case "help" -> System.out.println("Команды: start, stop, help");
    default -> System.out.println("Неизвестная команда: " + command);
}
Предскажи: что напечатает эта программа, если ввести STOP? А если Jump?

Для STOP: «Останавливаю» — toLowerCase() вернул "stop", и он совпал с меткой. Для Jump: «Неизвестная команда: Jump» — "jump" ни с чем не совпал. Заметь: в default печатается сама command, то есть ввод как есть, с большой буквы. Метки при этом пиши маленькими буквами: case "Start" теперь не совпадёт никогда.

char mark = 'B';
switch (mark) {
    case 'A' -> System.out.println("Отлично");
    case 'B' -> System.out.println("Хорошо");
    default -> System.out.println("Надо подтянуть");
}
Диапазоны — только if

В case пишут конкретные значения. «От 90 до 100» в switch не запишешь (case score >= 90 — ошибка). Если вопрос «больше / меньше» — нужен if. Если вопрос «равно чему из списка» — switch.

switch как выражение

Новый switch умеет то же, что тернарный оператор: возвращать значение. Такой switch называют switch-выражением: его результатом можно сразу инициализировать переменную:

int day = 6;
String name = switch (day) {
    case 1 -> "Понедельник";
    case 2 -> "Вторник";
    case 3 -> "Среда";
    case 4 -> "Четверг";
    case 5 -> "Пятница";
    case 6 -> "Суббота";
    case 7 -> "Воскресенье";
    default -> "???";
};
System.out.println(name);
Суббота
String name = switch

Объявляем переменную name и инициализируем её результатом switch-выражения — оно стоит справа от =.

case 1 -> "Понедельник";

После стрелки — не инструкция, а значение (здесь строковый литерал), которое станет результатом.

default -> "???";

Здесь default обязателен: switch-выражение должно вернуть что-то для любого int. Без него ошибка: the switch expression does not cover all possible input values.

};

Точка с запятой после закрывающей скобки — это конец всей инструкции String name = …; (объявления с инициализацией). Её часто забывают.

Предскажи: что вернёт это switch-выражение для day = 0?

"???" — значение из default. Ноль не совпал ни с одним case.

🔎 Для любопытных: если ветке нужно несколько строк — yield

Если перед тем, как вернуть значение, нужно что-то сделать, ветку пишут в фигурных скобках, а значение отдают словом yield («выдай»):

int price = switch (size) {
    case "S" -> 100;
    case "M" -> 150;
    case "L" -> {
        System.out.println("Большая порция!");
        yield 200;
    }
    default -> 0;
};

Почему не return, раз ветка «возвращает» значение? Слово return (модуль 7) завершает весь метод, а switch-выражение обязано выдать значение для переменной. Поэтому return внутри switch-выражения просто не скомпилируется: attempt to return out of a switch expression — «попытка выйти return из switch-выражения». Значение ветки-блока отдают только через yield.

Проверь себя

Поговори с наставником

Напиши: «Дай мне классический switch с пропущенными break и разными входными значениями — я скажу, что напечатается в каждом случае».

Коротко

  • switch сравнивает одно значение со списком конкретных вариантов. Диапазоны — через if.
  • Классический (case 1:): метка — только вход; без break выполнение проваливается вниз.
  • Новый (case 1 ->, Java 14+): без провала, несколько значений через запятую.
  • Работает с int, char, String (строки сравнивает по тексту, регистр важен — выручает switch (cmd.toLowerCase())). Не работает с long, double, boolean.
  • После case — литерал или константа (final). В последней ветке break не обязателен.
  • switch-выражение возвращает значение: String s = switch (x) { … default -> …; }; — default обязателен.
