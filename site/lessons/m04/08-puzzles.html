Ещё головоломки

Напиши наставнику: «Дай мне 3 головоломки по условиям из модуля 4, по одной: что выведется, скомпилируется ли и найди ошибку». У него есть целый банк таких задачек.

Коротко

  • В цепочке else if побеждает первая подходящая ветка — следи за порядком.
  • case — только вход; без break выполнение идёт вниз, в том числе через default.
  • else цепляется к ближайшему if без пары. Отступы ничего не значат — значат скобки и ;.
  • if (x = 5) с int не скомпилируется, а if (ok = true) с boolean — скомпилируется и всегда будет true.
  • Тернарный внутри склейки — в скобках; оба его значения приводятся к общему типу.
