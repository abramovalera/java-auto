Разбор: конструктор родителя вызывает переопределённый метод

Самая коварная головоломка модуля. Сначала подумай, потом жми «Шаг».

class Base {
    Base() {
        show();
    }
    void show() { System.out.println("Base"); }
}

class Child extends Base {
    private String name = "Child";

    @Override
    void show() { System.out.println("Hi, " + name); }
}

// в main:
new Child();

Головоломки от наставника

Напиши: «Дай мне 3 головоломки по ООП из модуля 10 — про полиморфизм, конструкторы и equals/hashCode, по одной, ответ не говори, пока я не объясню». На экзамене модуля такие тоже будут.

Что запомнить

  • По объекту выбирается только версия переопределённого метода — даже если её вызывает родитель или конструктор родителя.
  • Поля, static- и private-методы, выбор перегрузки — по ярлыку, при компиляции.
  • Конструкторы: от старшего родителя к младшему; поля наследника инициализируются после конструктора родителя.
  • equals — с параметром Object и вместе с hashCode; проверяй null.
  • Приведение вниз без instanceof — риск ClassCastException; между неродственными классами — ошибка компиляции.
