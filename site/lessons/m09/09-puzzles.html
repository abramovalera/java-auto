Напиши: «Дай мне 3 головоломки по модулю 9 на ссылки, static и конструкторы — по одной, ответ не говори, пока я не нарисую стек и кучу и не объясню». На экзамене модуля они тоже будут.

Главные ловушки модуля

  • Объектов столько, сколько new. b = a копирует стрелку, а не объект; == сравнивает стрелки.
  • Затенение: локальная переменная или параметр с именем поля загораживают поле — нужен this..
  • void перед «конструктором» превращает его в обычный метод.
  • static — один на класс; в static-методе нет this.
  • new Cat[3] — три null, а не три кота. По null — NullPointerException.
  • В stack trace ищи первую сверху строку своего кода; java.base/ — JDK.
