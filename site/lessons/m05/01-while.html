Зачем циклы. Цикл while

Компьютер обожает однообразную работу: повторить действие миллион раз ему не скучно. Учимся говорить ему «повторяй, пока…» — и рисуем ёлочку любой высоты.

⏱ 20 минут🔁 первый цикл🔍 трассировка

Копипаст — не выход

Задача: вывести числа от 1 до 5. С тем, что ты уже знаешь, получится так:

System.out.println(1);
System.out.println(2);
System.out.println(3);
System.out.println(4);
System.out.println(5);

Работает. А если нужно до 1000? Тысяча одинаковых строк, и в каждой можно опечататься. А если число вводит пользователь и заранее оно неизвестно? Тут копипаст бессилен.

Вспомни ёлочку из модуля 1: ты рисовал её руками, строка за строкой. Ёлку высотой 50 так рисовать никто не станет.

Присмотрись: в примере выше пять раз делается одно и то же, меняется только число. Как только видишь «одно и то же много раз» — это работа для цикла.

Цикл — это конструкция, которая повторяет блок кода много раз. В реальных программах циклы повсюду: посчитать сумму по всем 200 строкам банковской выписки, дать три попытки ввести PIN-код, ждать, пока файл не скачается.

Выпиши себе: IntelliJ IDEA, остановка программы

Цикл while: «пока — повторяй»

Аналогия: тарелка супа

Ты не решаешь заранее: «съем ровно 23 ложки». Ты действуешь по правилу: пока в тарелке есть суп — зачерпни ложку. Перед каждой ложкой смотришь в тарелку. Пусто — встаёшь из-за стола.

По-английски «пока» — while [уайл]. Так и называется первый цикл Java:

int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
System.out.println("Готово");

Готово
int i = 1;

Подготовка. Объявляем переменную i типа int и инициализируем её значением 1 — кладём в коробку единицу. Это счётчик цикла: переменная, которая отсчитывает итерации, — по ней условие решает, когда остановиться. Это ещё не цикл — строка выполнится один раз.

while (i <= 5)

Заголовок цикла. В скобках — условие продолжения: логическое выражение, как в if из модуля 4. Пока оно true, тело цикла выполняется снова и снова.

{ … }

Тело цикла — то, что повторяется. Одно выполнение тела называют итерацией (от латинского «повторение»), в разговоре — «круг».

i++;

Шаг. Инкремент счётчика: оператор ++ из модуля 3 увеличивает i на 1. Без шага условие никогда не станет ложным.

println("Готово")

Вызов println стоит после закрывающей скобки — уже вне тела цикла. Выполнится один раз, когда цикл закончится.

Похоже на if, правда? Разница в одном слове: if проверяет условие один раз, а while — перед каждой итерацией.

Как цикл крутится

Посмотри на путь, который проходит программа. Обрати внимание на стрелку, которая возвращается вверх: это и есть «петля», за которую цикл получил своё название.

Теперь пройди программу сам, строка за строкой. На некоторых шагах трассировщик спросит, какое значение будет у переменной, — впиши своё, прежде чем смотреть.

Три части любого цикла

У каждого «послушного» цикла есть три части. Забыл одну — жди беды.

🎬

Подготовка

До цикла: объявление и инициализация счётчика цикла. int i = 1;

🚦

Условие

Перед каждой итерацией: продолжаем или хватит? i <= 5

👣

Шаг

В теле: меняем счётчик цикла, чтобы условие однажды стало ложным. i++

Шаг не обязан быть +1. Можно шагать через одно или идти назад:

int n = 10;
while (n > 0) {
    System.out.print(n + " ");
    n = n - 3;
}
Что напечатает этот код?

10 7 4 1. После печати 1 переменной n присваивается −2, условие -2 > 0 ложно — цикл закончится. Число 0 так и не напечатается: на него мы просто «перешагнули».

А если в первом примере начать с int i = 10; при условии i <= 5? Сколько раз выполнится тело?

Ни разу. while проверяет условие до первой итерации. 10 <= 5 — ложь, программа сразу перепрыгнет цикл. Это нормально: «пока в тарелке есть суп» — а если тарелка пустая с самого начала, ни одной ложки не будет.

Бесконечный цикл и красный квадрат

Что будет, если забыть шаг?

int i = 1;
while (i <= 5) {
    System.out.println(i);
    // забыли i++
}

i навсегда остаётся равным 1, условие 1 <= 5 всегда верно — цикл крутится бесконечно. В панели Run бегут единицы, вентилятор компьютера начинает шуметь, а программа сама не остановится никогда.

Не пугайся — с этим сталкивается каждый программист, и не раз. Компьютер не сломается. Просто останови программу.

  1. Найди в панели Run (или сверху, рядом с зелёным ▶) красный квадрат ■ Stop и нажми его. То же самое — Ctrl+F2.
  2. В конце вывода появится Process finished with exit code … с ненулевым числом (на Windows обычно -1, на Mac и Linux — 130): программу остановили снаружи.
  3. Найди в коде цикл и спроси себя: что в теле приближает условие к false? Если ничего — вот и ошибка.
На сайте тоже есть защита

Если программа с бесконечным циклом попадёт на проверку задач, сайт остановит её через 5 секунд и напишет: «Возможно, она застряла в бесконечном цикле».

🔎 Для любопытных: бывают ли бесконечные циклы нарочно?

Да! Игра крутит цикл «нарисуй кадр → прочитай кнопки → сдвинь героя» всё время, пока ты играешь. Сервер банка крутит цикл «жди запрос → обработай» месяцами без перерыва. Пишут такое как while (true) { … }, а выходят из цикла инструкцией break — её разберём в уроке 5.3.

Лесенка любой высоты

Соединим цикл со Scanner из модуля 2: пользователь вводит высоту, а программа рисует лесенку из звёздочек. Высота заранее неизвестна — значит, без цикла не обойтись.

import java.util.Scanner;

public class Stairs {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Высота: ");
        int height = scanner.nextInt();

        String row = "*";
        int line = 1;
        while (line <= height) {
            System.out.println(row);
            row = row + "*";
            line++;
        }
    }
}

Хитрость в строке row = row + "*": вычисляется выражение row + "*" (к строке приклеивается ещё одна звёздочка), и результат присваивается переменной row. Так на каждой итерации строка «растёт» вместе с номером ступеньки. Переменная line — счётчик цикла: отсчитывает ступеньки и останавливает цикл через условие line <= height.

Что напечатает программа, если ввести 0?

Ничего, кроме «Высота: ». Условие 1 <= 0 ложно с самого начала, и тело не выполнится ни разу. Для лесенки высотой 0 это как раз правильно.

Попробуй сам

Набери программу в module-05, запусти и введи 10, потом 1, потом 0. Затем поменяй "*" на "#" и сделай так, чтобы каждая ступенька росла на две звёздочки, а не на одну.

Проверь себя

Поговори с наставником

Напиши в Claude Code: «Дай мне 3 коротких цикла while, а я скажу, сколько раз выполнится каждый и почему. Ответ не говори сразу».

Коротко

  • Цикл повторяет блок кода — тело цикла; одно выполнение тела — итерация. Видишь «одно и то же много раз» — нужен цикл.
  • while (условие) { тело } — «пока условие верно, повторяй тело». Условие проверяется перед каждой итерацией.
  • Три части: подготовка (объявление и инициализация счётчика цикла), условие, шаг. Тело может не выполниться ни разу.
  • Забыл шаг или шагаешь не туда — бесконечный цикл. Останавливается красным квадратом Stop (Ctrl+F2).
