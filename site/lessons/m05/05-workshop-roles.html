Мастерская: роли переменных

Синтаксис циклов ты знаешь. Но как придумать решение задачи? Секрет: в циклах переменные почти всегда играют одну из шести ролей. Узнаёшь роль — решение наполовину готово.

⏱ 30 минут🛠 мастерская🔍 5 трассировок

Повторение

У переменных есть профессии

Новичок смотрит на задачу «посчитай что-нибудь» и не знает, с чего начать. Опытный программист думает иначе: «Ага, здесь нужен счётчик и шагающая переменная». Финский учёный Йорма Саяниеми изучил тысячи учебных программ и заметил: почти каждая переменная в цикле выполняет одну из немногих типовых «работ». Он назвал их ролями.

Аналогия: футбольная команда

На поле нет «просто игроков»: есть вратарь, защитник, нападающий. У каждого своя работа, и по позиции сразу понятно, что он будет делать. Так и в цикле: роль подсказывает, каким значением переменную инициализировать и как она меняется на каждой итерации.

👣

Шагающая

Проходит значения по порядку: 1, 2, 3… Обычно это i, объявленная в заголовке for (её же называют счётчиком цикла).

🔢

Счётчик

Считает, сколько раз что-то случилось: инкремент count++.

🧺

Накопитель

Собирает сумму или произведение: составное присваивание sum += x.

🏆

Рекордсмен

Помнит лучший результат: максимум или минимум.

🚩

Флаг

Да или нет: «нашёл?», «было ли?». Тип boolean.

🕰️

Последнее значение

Помнит, что было на прошлой итерации: prev.

Посмотри, как все шесть ролей «смотрят» на одни и те же числа, которые по очереди вводит пользователь: 4, 9, 2, 9.

Напомню шаблон «Мастерской», по которому решаем любые задачи на логику:

  1. Пойми задачу. Что на входе, что на выходе? 2–3 примера, включая граничные: 0, 1, отрицательное.
  2. Реши руками и запиши, что делал. Какие действия повторялись?
  3. Найди роли переменных — шагающая, счётчик, накопитель, рекордсмен, флаг, последнее значение.
  4. Псевдокод на русском.
  5. Код — перевод псевдокода строка в строку.
  6. Трассировка: таблица значений по шагам, потом граничные случаи.

Дальше — по мини-задаче на каждую роль. Шаги 1–4 проговариваем коротко, шаг 6 делаешь ты в трассировщике.

👣 Шагающая и 🔢 счётчик

Задача. Сколько чисел от 1 до N делятся на 3 или на 5?

  1. Вход/выход: N = 10 → 5 (это 3, 5, 6, 9, 10). N = 2 → 0. N = 0 → 0.
  2. Руками: иду по числам 1, 2, … 10 и на каждом ставлю галочку, если подходит. В конце считаю галочки.
  3. Роли: «иду по числам» — шагающая i; «галочки» — счётчик count. Счётчик инициализируем нулём, и он растёт только на +1.
  4. Псевдокод: count = 0; для i от 1 до N: если i делится на 3 или на 5 — count + 1; вывести count.
int n = 6;
int count = 0;
for (int i = 1; i <= n; i++) {
    if (i % 3 == 0 || i % 5 == 0) {
        count++;
    }
}
System.out.println(count);

🧺 Накопитель

Задача. Посчитать сумму квадратов от 1 до N: 1² + 2² + … + N².

  1. Вход/выход: N = 3 → 1 + 4 + 9 = 14. N = 1 → 1. N = 0 → 0.
  2. Руками: держу в голове «сумму пока что» и прибавляю к ней очередной квадрат.
  3. Роли: i — шагающая, sum — накопитель: он «копит» результат: на каждой итерации sum = sum + что-то — вычисляем выражение и присваиваем результат той же переменной.
  4. Псевдокод: sum = 0; для i от 1 до N: sum += i·i; вывести sum.
int n = 3;
int sum = 0;
for (int i = 1; i <= n; i++) {
    sum += i * i;
}
System.out.println(sum);
С чего начинать накопитель

Накопитель суммы инициализируем нулём: ноль не меняет сумму. Для произведения — с 1: единица не меняет произведение. Начнёшь произведение с 0 — и всё, что ни умножай, останется нулём. Это пригодится в задаче «Факториал».

Где объявить sum — до цикла или внутри него?

До цикла. Переменная, объявленная внутри тела, создаётся заново на каждой итерации: объявление с инициализацией int sum = 0; в теле обнулит накопленное. И после цикла её уже не будет видно. Это одна из самых частых ошибок — разберём её в уроке 5.7.

🏆 Рекордсмен (максимум и минимум)

Задача. Пользователь вводит температуру за 5 дней. Найти самую низкую.

  1. Вход/выход: −3 2 −8 0 −8 → −8. 5 3 7 1 4 → 1 (все плюсовые). Все одинаковые 2 2 2 2 2 → 2.
  2. Руками: смотрю на первое число и запоминаю его как «самое холодное пока». Каждое следующее сравниваю с запомненным: холоднее — запоминаю новое.
  3. Роли: day — шагающая, t — очередное число, min — рекордсмен: его инициализируем первым введённым числом.
  4. Псевдокод: min = первое число; для дней со 2-го по 5-й: прочитать t; если t < min — min = t; вывести min.
Scanner scanner = new Scanner(System.in);
int min = scanner.nextInt();       // первый день — пока рекордсмен
for (int day = 2; day <= 5; day++) {
    int t = scanner.nextInt();
    if (t < min) {
        min = t;
    }
}
System.out.println("Самый холодный день: " + min);
Главная ловушка рекордсмена

Хочется инициализировать рекордсмена нулём: int min = 0;. Проверь на примере 5 3 7 1 4: ни одно число не меньше 0 — программа напечатает 0, а такой температуры не было! С максимумом то же самое: max = 0 ломается, когда все числа отрицательные. Надёжный способ — инициализировать рекордсмена первым значением.

🚩 Флаг

Задача. Пользователь вводит 3 числа. Было ли среди них отрицательное? Ответ: «да» или «нет».

  1. Вход/выход: 4 −1 7 → да. 4 1 7 → нет. −5 −5 −5 → да.
  2. Руками: держу в голове «пока не видел». Увидел отрицательное — поднимаю флажок, и он остаётся поднятым, что бы ни пришло дальше.
  3. Роли: found — флаг: boolean, инициализируем значением false; дальше ему можно только присвоить true — «поднять».
  4. Псевдокод: found = false; 3 раза: прочитать x; если x < 0 — found = true. После цикла: found ? «да» : «нет».
Scanner scanner = new Scanner(System.in);
boolean found = false;
for (int i = 1; i <= 3; i++) {
    int x = scanner.nextInt();
    if (x < 0) {
        found = true;
    }
}
System.out.println(found ? "да" : "нет");
Ловушка: else у флага

Если дописать ветку else { found = false; }, флаг будет «забывать»: после 7 он опустится, и программа скажет «нет», хотя −1 было. Флаг поднимают, но внутри цикла не опускают. Когда флаг поднят, дальше можно не искать — тут к месту break из урока 5.3.

🕰️ Последнее значение: числа Фибоначчи

Задача. Напечатать первые 6 чисел Фибоначчи: 1 1 2 3 5 8. Каждое следующее — сумма двух предыдущих. Такие числа встречаются в природе: в спиралях подсолнуха и раковин.

  1. Вход/выход: 6 чисел → 1 1 2 3 5 8.
  2. Руками: держу в голове два последних числа. Складываю их — получаю новое. Потом «сдвигаюсь»: старое второе становится первым, новое — вторым.
  3. Роли: prev — последнее значение (предыдущее число), cur — текущее, next — временная: объявлена в теле цикла и живёт одну итерацию, чтобы ничего не потерять при сдвиге.
  4. Псевдокод: prev = 0, cur = 1; 6 раз: напечатать cur; next = prev + cur; prev = cur; cur = next.
int prev = 0;
int cur = 1;
for (int i = 1; i <= 6; i++) {
    System.out.print(cur + " ");
    int next = prev + cur;
    prev = cur;
    cur = next;
}
Зачем временная next? Что выведется, если написать без неё: prev = cur; cur = prev + cur;?

1 2 4 8 16 32 — числа просто удваиваются. После присваивания prev = cur старое значение prev потеряно, и выражение prev + cur превращается в cur + cur. Временная переменная сохраняет результат, пока мы «переставляем» остальные. Как при обмене двух стаканов с соком нужен третий, пустой.

Проверь себя

Поговори с наставником

Напиши: «Дай мне задачу на цикл. Я не буду писать код — назову роли переменных и напишу псевдокод, а ты проверь». Это лучший тренажёр перед задачами модуля.

Коротко

  • Переменные в цикле играют роли: шагающая, счётчик, накопитель, рекордсмен, флаг, последнее значение (+ временная).
  • Роль подсказывает, каким значением инициализировать переменную и как она меняется на каждой итерации.
  • Инициализируем: сумму — нулём, произведение — единицей, рекордсмена — первым значением, флаг — false.
  • Решаем по шаблону: вход/выход → руками → роли → псевдокод → код → трассировка.
