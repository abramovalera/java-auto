Модуль 5 · Головоломки

Сколько раз? Что выведется? Зависнет ли?

Циклы — любимая тема вопросов «что будет?» на собеседованиях. Здесь нельзя запускать код — только трассировать в голове или на листке.

Как решать

Не угадывай. Нарисуй на листке табличку «шаг | переменные | вывод» и пройди цикл по итерациям, как в трассировщике. Сначала ответ и объяснение «почему» — вслух или письменно, потом клик. Проверить себя в IDEA после ответа — тоже честно.

Что выведется на экран?

1. Инкремент прямо в условии. Что напечатает?

int i = 0;
while (i++ < 3) {
    System.out.print(i);
}
  • 012
  • 123
  • 1234

2. Вложенные циклы. Что напечатает?

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 2; j++) {
        System.out.print(i * j);
    }
}
  • 011223
  • 000102
  • 012

3. break во вложенном цикле. Что напечатает?

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == i) {
            break;
        }
        System.out.print(j);
    }
}
  • Ничего: при i = 1 сразу break
  • 112
  • 123123123

4. Что напечатает?

int x = 10;
do {
    x -= 3;
} while (x > 0);
System.out.println(x);
  • 1
  • -2
  • 0

5. continue и break вместе. Что напечатает?

for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    if (i == 5) break;
    System.out.print(i);
}
  • 1245
  • 124
  • 12

6. Сколько итераций? Что напечатает?

int n = 1000;
int c = 0;
while (n > 1) {
    n /= 10;
    c++;
}
System.out.println(c);
  • 4
  • 3
  • 1000

Скомпилируется, но что будет при запуске?

8. Цикл без единой части в заголовке. Что будет?

for (;;) {

  • Не скомпилируется

  • Не напечатает ничего

9. Сколько раз напечатается «Hi»?

  • 3 раза
  • 1 раз

10. Что произойдёт при запуске?

int i = 0;
while (i < 5) {
    if (i == 2) {

    }

}
System.out.println("Готово");
  • Напечатает «Готово»
  • Программа зависнет
  • Не скомпилируется

11. ★★★ Модуль 2: вспомни диапазон byte (от −128 до 127). Сколько итераций?

for (byte b = 0; b < 200; b++) {
    System.out.println(b);
}
  • 200
  • 128
  • Бесконечно

Скомпилируется ли?

12. Скомпилируется?

for (int i = 0; i < 3; i++) {
    System.out.print(i);
}
System.out.println(i);
  • Да, напечатает 0123
  • Нет: i не видна после цикла

13. ★★★ Классика собеседований. Скомпилируется?

while (true) {
    System.out.println("A");
}
System.out.println("B");
  • Да: напечатает A бесконечно, B никогда
  • Нет: строка с B недостижима (unreachable statement)
  • Да: напечатает A, потом B

14. Скомпилируется?

int i = 0;
do {
    int k = i * 2;
    i++;
} while (k < 6);
  • Да, сделает 4 итерации
  • Нет: k не видна в условии while

Найди ошибку

15. Нужна сумма нечётных чисел от 1 до 10 (это 25), а программа печатает 9. В чём ошибка?

int sum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 1) {
        sum = i;
    }
}
System.out.println(sum);
  • Условие i % 2 == 1 неверное
  • sum = i вместо sum += i
  • Условие цикла должно быть i < 10

Читаем код

Головоломки проверяли, что делает код. Теперь — как о нём сказать: прочитай каждую строку правильными терминами модуля, как на собеседовании или код-ревью. В одних заданиях выбери описание из пяти, в других собери его из квадратиков — лишние оставь на месте.

Джавик-курьер: что будет?

Задачки по части 2 игры: здесь код не пишем, а предсказываем, что сделает Джавик или компилятор.

Что тренирует такой формат

  • Выполнять цикл в голове по итерациям — с табличкой переменных.
  • Видеть мелочи: i++ в условии, ; после заголовка, continue перед шагом, границы < и <=.
  • Помнить область видимости переменной и что компилятор знает о недостижимом коде.
