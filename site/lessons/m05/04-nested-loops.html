Вложенные циклы

Цикл внутри цикла: так рисуют прямоугольники и треугольники из звёздочек, печатают таблицу умножения и обходят любые «строки и столбцы». И да — ёлочка любой высоты.

Повторение

Цикл в цикле

Тело цикла может содержать любые инструкции: вызов println, if… и другой цикл. Такой цикл называют вложенным. Он нужен, когда у данных есть строки и столбцы: таблица, шахматная доска, картинка из звёздочек, места в кинозале (ряды и кресла).

Аналогия: почтальон в многоэтажке

Почтальон поднимается на этаж (внешний цикл) и обходит на нём все квартиры (внутренний цикл). Только обойдя все квартиры этажа, он идёт на следующий этаж — и снова обходит все квартиры с первой.

for (int row = 1; row <= 3; row++) {        // этажи: строки
    for (int col = 1; col <= 5; col++) {    // квартиры: столбцы
        System.out.print("*");
    }
    System.out.println();                   // строка готова — на новую строку
}
*****
*****
*****
for (int row …)

Внешний цикл: строки. Одна итерация внешнего цикла = одна строка картинки.

for (int col …)

Внутренний цикл: его тело — вызов print, звёздочки одной строки печатаются без перевода строки. На каждой итерации внешнего цикла счётчик col заново объявляется и инициализируется значением 1.

System.out.println();

Вызов стоит после внутреннего цикла, но в теле внешнего. Выполняется один раз на итерацию внешнего цикла — «нажимает Enter».

По шагам: внутренний цикл каждый раз заново

Самое важное, что нужно увидеть: когда внешний цикл переходит к следующей итерации, внутренний начинается с самого начала — с инициализации col = 1.

Таблица умножения

В заголовке и теле внутреннего цикла можно использовать счётчик внешнего. Строка i, столбец j, в клетке — i * j. Для ровных столбцов после каждого числа печатаем табуляцию \t из модуля 1.

for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        System.out.print(i * j + "\t");
    }
    System.out.println();
}

Здесь выражение i * j + "\t" вычисляется правильно: оператор * выполняется раньше склейки. Сколько всего умножений сделала программа? 9 × 9 = 81.

Что изменится, если во внутреннем цикле написать j <= i вместо j <= 9?

Получится треугольник: в первой строке одно число, во второй два, в девятой девять. Условие внутреннего цикла теперь зависит от счётчика внешнего — это главный приём для любых треугольников и ёлочек.

Лесенка, прижатая вправо

В уроке 5.1 лесенка была прижата к левому краю. Прижмём её вправо — для этого перед звёздочками нужны пробелы. Прежде чем писать код, заполним табличку для высоты 4 — так делают программисты, а не гадают:

Строка rowКак выглядитПробеловЗвёздочек
1␣␣␣*31
2␣␣**22
3␣***13
4****04

Звёздочек — столько же, сколько номер строки: row. Пробелов — сколько не хватает до 4: n - row. Значит, в каждой строке два внутренних цикла подряд: сначала пробелы, потом звёздочки.

int n = 4;
for (int row = 1; row <= n; row++) {
    for (int s = 1; s <= n - row; s++) {
        System.out.print(" ");
    }
    for (int k = 1; k <= row; k++) {
        System.out.print("*");
    }
    System.out.println();
}
   *
  **
 ***
****

Пройди по шагам для n = 3. Отдельные итерации внутренних циклов мы «свернули» — ты уже знаешь, как они крутятся. Твоя задача — посчитать, сколько пробелов напечатать в каждой строке.

Ёлочка: план, а код — за тобой

Ёлочка из модуля 1 — это та же лесенка, только звёздочек в строке больше. Сделаем то же, что с лесенкой: табличка для высоты 4.

Пробелы — уже знакомое n - row. А звёздочки: 1, 3, 5, 7 — нечётные числа, каждый раз +2. Как связать их с номером строки? Попробуй сам, прежде чем открыть:

Формула для количества звёздочек в строке row

2 · row − 1. Проверь: row = 1 → 1, row = 2 → 3, row = 3 → 5, row = 4 → 7. Подход «удвой номер и подправь» помогает почти всегда, когда число растёт на 2.

План на русском — псевдокод, то есть «почти код» обычными словами:

для row от 1 до N:
    напечатать (N − row) пробелов
    напечатать (2·row − 1) звёздочек
    перевести строку
ствол: (N − 1) пробелов и «|»
Твой ход

Переводить план в код ты будешь сам — это задача m05-t05 «Ёлочка любой высоты» на странице практики. Подсказка: код почти как у лесенки выше, меняется условие одного цикла и добавляется ствол. Проверь себя трассировкой на N = 1 и N = 2.

Сколько раз и куда выходит break

Если внешний цикл делает A итераций, а внутренний — B итераций, тело внутреннего выполнится A × B раз. 100 × 100 — уже 10 000, а три вложенных цикла по 1000 — миллиард. Поэтому с вложенностью осторожнее: программа может стать очень медленной.

Если условие внутреннего цикла зависит от счётчика внешнего (треугольник, j <= i), считаем по строкам: 1 + 2 + 3 + … + N.

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            break;
        }
        System.out.print(i + "" + j + " ");
    }
}
Что напечатает этот код?

11 21 31. break выходит только из ближайшего цикла — внутреннего. Внешний продолжает работать: i = 2, i = 3, и внутренний каждый раз начинается заново и снова доходит до j = 2. А выражение i + "" + j — приём из модуля 1: пустой строковый литерал в середине склеивает числа как текст, иначе получилось бы сложение.

А как выйти сразу из обоих циклов?

Задача: найти первую пару чисел от 1 до 9, произведение которых равно 12, и остановиться. Одного break мало — он выйдет только из внутреннего цикла, а внешний продолжит искать. Обычный способ — флаг: переменная boolean «нашли?» (подробно про такую роль — в уроке 5.5).

boolean found = false;
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        if (i * j == 12) {
            System.out.println("Нашёл: " + i + " * " + j);
            found = true;
            break;              // выход из внутреннего цикла
        }
    }
    if (found) {
        break;                  // выход из внешнего цикла
    }
}
Нашёл: 2 * 6
Что напечатает программа, если убрать if (found) { break; }?

Четыре строки: 2 * 6, 3 * 4, 4 * 3, 6 * 2. Внутренний break обрывает только текущий внутренний цикл, а внешний переходит к следующему i — и поиск продолжается.

Второй способ — метка: имя с двоеточием перед внешним циклом. break с этим именем выходит сразу из помеченного цикла:

outer:
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        if (i * j == 12) {
            System.out.println("Нашёл: " + i + " * " + j);
            break outer;        // выход сразу из цикла с меткой outer
        }
    }
}

Метки встречаются редко: их достаточно узнавать в чужом коде. Сам пользуйся флагом, а когда в модуле 7 научишься выносить код в методы — ещё проще будет выйти из метода через return.

Собери программу

Прямоугольник 3 × 4 из решёток. Собери строки в правильном порядке — отступы подскажут вложенность.

Проверь себя

Поговори с наставником

Напиши: «Нарисуй мне фигуру из звёздочек (треугольник или рамку), а я составлю для неё табличку "строка → пробелы → звёздочки" и псевдокод. Код не показывай».

Коротко

  • Вложенный цикл — цикл в теле другого цикла. Внешний обычно — строки, внутренний — столбцы.
  • На каждой итерации внешнего цикла внутренний проходит полностью, с инициализации счётчика.
  • Вызов println() после внутреннего цикла завершает строку.
  • Тело внутреннего выполняется A × B раз. Условие внутреннего цикла может зависеть от счётчика внешнего — так получаются треугольники.
  • Картинку сначала раскладываем в табличку «строка → пробелы → символы», ищем формулу, пишем псевдокод — и только потом код.
  • break выходит только из ближайшего цикла. Выйти сразу из двух — флаг found и второй break во внешнем цикле (или метка: break outer;).
