Цикл for

Самый популярный цикл Java. Инициализация счётчика, условие и шаг собраны в одну строку — в заголовок цикла, — и забыть шаг становится почти невозможно.

⏱ 20 минут🔁 for🔍 трассировка

Повторение

while, собранный в одну строку

В прошлом уроке три части цикла были разбросаны по коду: подготовка — над циклом, условие — в скобках, шаг — где-то в конце тела. В длинной программе шаг легко потерять. Цикл for [фор] («для») собирает все три части в заголовок цикла — строку for (…):

int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Эти две программы делают одно и то же — печатают числа от 1 до 5. Но во второй всё управление циклом видно в одной строке — в заголовке.

Аналогия: тренер на стадионе

Тренер говорит: «Начинаешь с первого круга; бегаешь, пока номер круга не больше пяти; после каждого круга номер на табло +1». Вся тренировка описана одной фразой ещё до старта — это и есть заголовок for.

Три части и порядок выполнения

В скобках после for — три части через точку с запятой (не через запятую!): инициализация счётчика (объявляем i и сразу присваиваем начальное значение), условие продолжения и шаг:

Главная ловушка для новичка: шаг i++ стоит в заголовке, до тела, а выполняется после тела. Проверь это в трассировщике — он покажет каждый прыжок. Напоминание из модуля 3: i -= 2 — то же самое, что i = i - 2.

Вперёд, назад, через одно

Меняя три части, можно заставить i пройти почти любой путь:

Нужно получитьЗаголовок
1 2 3 … 10for (int i = 1; i <= 10; i++)
10 9 8 … 1 (обратный отсчёт)for (int i = 10; i >= 1; i--)
2 4 6 … 20 (чётные)for (int i = 2; i <= 20; i += 2)
0 5 10 … 100for (int i = 0; i <= 100; i += 5)
1 2 4 8 … 1024 (удвоение)for (int i = 1; i <= 1024; i *= 2)
Что напечатает for (int i = 1; i < 100; i *= 3) System.out.print(i + " ");?

1 3 9 27 81. Следующее значение было бы 243, но 243 < 100 — ложь. Кстати, фигурные скобки здесь опущены: если тело цикла — одна инструкция, так можно. Но лучше ставь скобки всегда — так меньше ошибок.

Обратный отсчёт: for (int i = 10; i >= 1; i++). Что не так?

Начали с 10, условие «пока ≥ 1», а шаг увеличивает i: 10, 11, 12… Условие верно всегда — цикл (почти) бесконечный. Для отсчёта назад шаг должен быть i--. Проверяй: шаг двигает i к границе условия или от неё?

Сколько раз выполнится?

Этот вопрос задают на собеседованиях и в головоломках постоянно. Самые частые варианты:

ЗаголовокЗначения iСколько раз
for (int i = 0; i < 5; i++)0 1 2 3 45
for (int i = 1; i <= 5; i++)1 2 3 4 55
for (int i = 0; i <= 5; i++)0 1 2 3 4 56 ⚠️
for (int i = 1; i < 5; i++)1 2 3 44 ⚠️
Привычка программистов

«Повторить N раз» почти всегда пишут как for (int i = 0; i < n; i++): старт с 0 и строгое <. Почему с нуля — станет ясно в модуле 6 про массивы: там нумерация начинается с 0. А если нужны сами числа 1…N — пиши i = 1; i <= n. Главное — не смешивать: 0 и <= дают лишнюю итерацию.

Проверяй по крайним значениям: какое i будет на первой итерации и какое на последней? Тогда «плюс-минус один» не застанет тебя врасплох. Подробно про эту ошибку — в уроке 5.7.

for + Scanner: таблица квадратов

Пользователь вводит N — программа печатает квадраты чисел от 1 до N. Сколько будет итераций, зависит от ввода:

import java.util.Scanner;

public class Squares {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("До какого числа? ");
        int n = scanner.nextInt();
        for (int i = 1; i <= n; i++) {
            System.out.println(i + " в квадрате = " + i * i);
        }
    }
}
Ловушка из модуля 1: что выведется, если написать "… = " + i + i вместо i * i? Возьми i = 3.

«3 в квадрате = 33». Выражение вычисляется слева направо: строка + 3 = строка, потом к ней приклеивается ещё 3. А вот i * i работает правильно: умножение выполняется раньше сложения, и к строке приклеивается уже готовое 9.

Когда брать for, а когда while? Простое правило: если число итераций известно или его можно посчитать до старта (от 1 до N) — for. Если крутим, пока что-то не случится (пока пользователь не введёт 0, пока страница не загрузится) — while. Подробнее — в следующем уроке.

Коротко

  • for (инициализация; условие; шаг) { тело } — все три части в заголовке цикла, через ;.
  • Порядок: инициализация счётчика один раз → условие → тело → шаг → условие → …
  • Шаг может быть любым: i--, i += 2, i *= 2. Он должен вести к границе условия.
  • i = 0; i < n и i = 1; i <= n — по N итераций. 0 и <= — на одну больше.
  • Счётчик, объявленный в заголовке for, живёт только внутри цикла.
