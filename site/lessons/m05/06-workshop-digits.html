Мастерская: цифры числа

Два простых выражения с операторами % и / — n % 10 и n / 10 — и цикл, который разбирает число по цифрам. Решим классику собеседований — число задом наперёд — медленно, по шаблону, от «не знаю, с чего начать» до работающего кода.

⏱ 30 минут🛠 мастерская🔍 2 трассировки

Повторение

Два инструмента: % 10 и / 10

Вспомни модуль 3: оператор % — остаток от деления, а оператор / для целых операндов отбрасывает дробную часть. Если делить на 10, получаются два волшебных действия:

👀

n % 10

Посмотреть на последнюю цифру. 1234 % 10 = 4

✂️

n / 10

Отрезать последнюю цифру. 1234 / 10 = 123

Аналогия: поезд из вагонов-цифр

Число 1234 — поезд из четырёх вагонов. % 10 — заглянуть в последний вагон: там 4. / 10 — отцепить последний вагон: остался поезд 123. Отцеплять можно, пока поезд не кончится — то есть пока число не станет 0.

Чему равны 7 % 10 и 7 / 10?

7 и 0. У однозначного числа последняя цифра — оно само, а после отрезания не остаётся ничего: 0. Вот почему «число стало 0» значит «цифры кончились».

Скелет «пока есть цифры» и сумма цифр

Соединим два инструмента с циклом. Сколько цифр в числе, заранее неизвестно, — значит, while:

while (n > 0) {
    int digit = n % 10;   // посмотреть на последнюю цифру
    // … что-то сделать с digit …
    n = n / 10;           // отрезать её
}

Этот скелет — основа всех задач про цифры. Меняется только тело цикла — строка «что-то сделать». Пример: сумма цифр. 507 → 5 + 0 + 7 = 12.

  • n — шагающая: идёт к нулю, теряя по цифре;
  • digit — временная: объявлена в теле цикла и живёт одну итерацию;
  • sum — накопитель.
int n = 507;
int sum = 0;
while (n > 0) {
    int digit = n % 10;
    sum += digit;
    n = n / 10;
}
System.out.println(sum);
Количество цифр — твоя задача

Тем же скелетом можно посчитать, сколько цифр в числе: вместо накопителя нужен счётчик. Это задача m05-t07. Перед кодом протрассируй руками число 0: сколько раз выполнится while (n > 0), и сколько цифр у нуля на самом деле? Вспомни, какой цикл из урока 5.3 выполняет тело хотя бы один раз.

Большая задача: число задом наперёд

История от автора курса. Когда-то он открыл на сайте задачек LeetCode простую задачу «разверни строку» — и просидел над ней, не понимая, с чего вообще начать. Синтаксис знал, а как из задачи получить код — нет. Этот урок — ровно о том, как начинать. Возьмём родственницу той задачи — развернём число — и пройдём все шесть шагов шаблона медленно.

Шаг 1. Пойми задачу

На входе — целое число. На выходе — число из тех же цифр в обратном порядке. Не строка, а именно число: с ним потом можно считать. Примеры — обязательно с граничными:

ВходВыходЧто проверяет пример
12344321обычный случай
120021нули в конце: у числа не бывает «0021»
77одна цифра
00ноль — самое коварное число

Отрицательные числа сегодня не трогаем — это бонус в задаче m05-t10.

Шаг 2. Реши руками и запиши, что делал

Возьми листок и разверни 1234 руками, наблюдая за собой. Получится примерно так: «Беру последнюю цифру — 4, записываю. Беру следующую с конца — 3, пишу справа: 43. Потом 2 — 432. Потом 1 — 4321». Запишем это табличкой:

—1234—0 (ничего)

Что повторялось? «Взять последнюю цифру, отрезать её, приписать справа к ответу». Первые два действия мы уже умеем: % 10 и / 10. А вот третье…

Ключевой вопрос: как приписать цифру справа?

На бумаге — просто дописал. А в числе? Из 43 нужно сделать 432. Посмотри: 432 = 430 + 2, а 430 = 43 · 10. Умножение на 10 сдвигает все цифры влево и освобождает справа место (там появляется 0). Потом прибавляем цифру — она встаёт на это место.

Аналогия: полка с книгами

На полке стоят книги «4» и «3», прижатые вправо. Чтобы поставить новую книгу справа, сдвигаешь все на одно место влево (×10) и ставишь новую в освободившуюся ячейку (+ digit).

Проверь формулу на первой итерации: result = 0, digit = 4. Что получится?

4: 0 · 10 + 4 = 4. Формула работает с самого начала, если накопитель инициализирован нулём. Никакой особой обработки первой цифры не нужно.

Шаг 3. Роли переменных

  • n — шагающая: теряет по цифре и идёт к нулю, как в сумме цифр;
  • digit — временная: последняя цифра на этой итерации;
  • result — накопитель. Он копит не сумму, а «приписывание»: result · 10 + digit.

Заметь: скелет тот же, что у суммы цифр! Отличается одна строка — присваивание накопителю. В этом и сила шаблона: новые задачи часто оказываются старыми с другой «начинкой».

Шаг 4. Псевдокод

result = 0
пока n больше 0:
    digit = последняя цифра n
    приписать digit справа к result
    отрезать последнюю цифру у n
вывести result

Шаг 5. Код — перевод строка в строку

int n = 1200;
int result = 0;
while (n > 0) {
    int digit = n % 10;
    result = result * 10 + digit;
    n = n / 10;
}
System.out.println(result);

Сравни с псевдокодом: каждая строка плана стала одной строкой кода. Если бы ты сразу начал с кода, пришлось бы думать обо всём одновременно. А так думал по очереди: что делать → как это сказать на Java.

Шаг 6. Трассировка

Самый коварный пример из нашей таблицы — 1200, с нулями. Проверим на нём.

И остальные граничные случаи — устно, по коду:

  • 7: одна итерация, result = 0 · 10 + 7 = 7 ✓.
  • 0: условие 0 > 0 ложно сразу, тело цикла не выполнится ни разу, result останется 0 ✓. Повезло: здесь «ни разу» даёт правильный ответ. В задаче про количество цифр так не повезёт.
  • −123: -123 > 0 ложно — тело цикла не выполнится, ответ 0 ✗. Как это починить, разберёшься в задаче m05-t10. Подсказка — вспомни, чему равно -123 % 10 в Java.

А как же строка с LeetCode?

Строки по-настоящему будут в модуле 8. Но план «разверни строку» ты можешь составить уже сейчас — по тому же шаблону:

  1. Вход/выход: «кот» → «ток»; «а» → «а»; пустая строка → пустая строка.
  2. Руками: беру буквы с конца: т, о, к — и приписываю каждую справа к ответу.
  3. Роли: i — шагающая, идёт от последней буквы к первой; result — накопитель, собирает буквы.
  4. Псевдокод: result = "" (инициализируем пустой строкой); для i от последней позиции до первой: result = result + буква номер i.

Видишь? Это та же самая задача, что и с числом: идём с конца, приписываем справа. Изменились только инструменты: вместо % 10 будет «взять букву номер i», вместо · 10 + — склейка строк +. Когда в модуле 8 узнаешь, как достать букву из строки, код напишется за минуту. Задача, которая когда-то казалась непонятной, решается за один урок, если начинать не с кода, а с рук и ролей.

🔎 Для любопытных: переполнение и палиндромы

Переполнение. Разверни 1 999 999 999 — получится 9 999 999 991, а это больше максимального int (2 147 483 647, модуль 2). Результат «перевалит» через край и станет мусором. Если числа большие, накопитель объявляют с типом long. На собеседованиях про это любят спросить.

Палиндром — число, которое читается одинаково с обеих сторон: 12321, 4554. Проверка в одну строку после цикла: сохрани исходное число до цикла и сравни его с перевёрнутым через ==.

Проверь себя

Поговори с наставником

Напиши: «Дай мне задачу про цифры числа (например, самая большая цифра или есть ли в числе семёрка). Я пройду все шесть шагов шаблона письменно, а ты проверь каждый шаг до кода».

Коротко

  • Выражение n % 10 — последняя цифра, n / 10 — число без последней цифры.
  • Скелет: while (n > 0) { digit = n % 10; …; n = n / 10; }. Итераций столько, сколько цифр.
  • Приписать цифру справа: result = result * 10 + digit.
  • Шаблон: вход/выход с граничными → руками с табличкой → роли → псевдокод → код → трассировка. Так решается и «разверни строку».
  • Всегда проверяй 0 и отрицательные: while (n > 0) их не обрабатывает.
