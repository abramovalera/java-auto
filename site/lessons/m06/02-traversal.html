Главный цикл модуля

Обойти массив — значит обратиться к каждому элементу по очереди. Для этого берут обычный for, а счётчик цикла используют как индекс:

int[] grades = {5, 4, 3, 5, 4};
for (int i = 0; i < grades.length; i++) {
    System.out.println("Ученик " + i + ": " + grades[i]);
}
int i = 0

Инициализация счётчика: начинаем с индекса 0 — с первого элемента.

i < grades.length

Условие: идём, пока индекс строго меньше длины. Длина 5 — значит последняя итерация будет с i = 4. Не пиши здесь число 5: если массив станет длиннее, цикл сам подстроится.

i++

Шаг: переходим к следующему индексу.

grades[i]

Обращение к элементу по индексу i. На каждой итерации — новый элемент.

Запомни как скороговорку

for (int i = 0; i < a.length; i++) — «от нуля, пока меньше длины». В IDEA есть шаблон: набери fori и нажми Tab, или itar + Tab — сразу цикл по массиву.

Сумма элементов — тот же накопитель из модуля 5, только прибавляем не счётчик i, а элемент a[i]. Пройди программу по шагам и предскажи значения:

Заполняем массив с клавиатуры

Самый частый сценарий в задачах этого модуля: сначала вводят N — сколько будет чисел, потом сами N чисел. Шаблон: объявляем n и инициализируем результатом вызова nextInt(), создаём массив на n элементов, а в цикле присваиваем каждому элементу numbers[i] результат очередного вызова nextInt():

import java.util.Scanner;

public class ReadNumbers {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();          // 1. узнали размер
        int[] numbers = new int[n];         // 2. создали массив на n ячеек
        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextInt(); // 3. по очереди заполнили ячейки
        }
        // 4. дальше работаем с массивом: считаем, ищем, печатаем…
        System.out.println("Первое: " + numbers[0]
                + ", последнее: " + numbers[n - 1]);
    }
}

В консоли Run набери числа через пробел или каждое с новой строки — nextInt() всё равно прочитает их по одному:

Подсказки «Введите число» не нужны

В задачах на сайте вывод сравнивается с ожидаемым символ в символ. Строка «Введите N:» попадёт в вывод — и проверка не пройдёт. Читай молча, печатай только ответ.

Почему в цикле чтения можно писать и i < n, и i < numbers.length?

Массив создан как new int[n], поэтому numbers.length равно n. Оба варианта верны. Но numbers.length надёжнее: условие цикла всегда привязано к длине самого массива.

for-each: «для каждого элемента»

Часто индекс вообще не нужен: просто пройти по всем элементам и с каждым что-то сделать. Для этого есть короткая форма — for-each (по-русски «для каждого»):

int[] grades = {5, 4, 3, 5, 4};
int sum = 0;
for (int g : grades) {     // читается: «для каждого g из grades»
    sum += g;
}
System.out.println(sum);   // 21

Двоеточие читай как «из». В заголовке объявлена переменная g; на каждой итерации ей присваивается копия очередного элемента: сначала 5, потом 4, потом 3… Ни индекса, ни length, ни риска ошибиться на единицу.

Аналогия: кассир в магазине

Кассир берёт товары с ленты по одному и пробивает. Номер товара на ленте ему не нужен — «для каждого товара на ленте: пробить». Это for-each. А вот кладовщик, который раскладывает коробки «на полку 3 — сюда, на полку 4 — туда», работает с номерами — это for по индексам.

Что выведет? int[] a = {1, 2, 3}; for (int x : a) { x = x * 10; } System.out.println(a[0]);

1. x — копия элемента, отдельная переменная. Присвоили копии новое значение — массив не изменился. Чтобы изменить элементы, нужен for по индексам — присваивание через обращение по индексу: a[i] = a[i] * 10;. Это любимый вопрос на собеседованиях.

Вылет за край: ArrayIndexOutOfBoundsException

Самая частая ошибка с массивами — одна лишняя единица. Посмотри на условие цикла:

public class Oops {
    public static void main(String[] args) {
        int[] grades = {5, 4, 3, 5, 4};
        for (int i = 0; i <= grades.length; i++) {   // <= вместо <
            System.out.println(grades[i]);
        }
    }
}

Компилятор молчит: синтаксически всё правильно. Программа печатает 5, 4, 3, 5, 4 — и на шестой итерации, когда i = 5, падает при обращении grades[5]:

Читаем сообщение по кусочкам — оно говорит почти всё:

ArrayIndexOutOfBoundsException

Что случилось: «индекс массива вне границ». Это исключение — ошибка во время работы программы (не компиляции).

Index 5

Какой индекс ты попросил.

for length 5

Какая длина у массива. Индексы допустимы от 0 до 4 — пятёрка не влезла.

at Oops.main(Oops.java:5)

Где: файл Oops.java, строка 5. В IDEA это ссылка — кликни, и курсор встанет на нужную строку.

Хорошая новость: Java не даёт тихо прочитать мусор за краем массива (в языке C это возможно — и это источник страшных уязвимостей). Программа падает громко и сразу говорит, где. Увидел Index … out of bounds — первым делом проверь <= в условии цикла и i + 1 внутри.

Коротко

  • Обход по индексам: for (int i = 0; i < a.length; i++) — «от нуля, пока меньше длины».
  • Ввод массива: прочитать n → создать массив new int[n] → в цикле присвоить каждому элементу результат вызова nextInt().
  • for-each for (int x : a) — когда нужны только значения. x — копия элемента, изменить массив через неё нельзя.
  • Индекс, позиция, соседи, обратный порядок, присваивание элементам — for по индексам.
  • ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5 — вылет за край; ищи <= или i + 1.
