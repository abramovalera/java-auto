Массивы: что выведется? Скомпилируется ли?

Массивы — любимая тема собеседований: индексы с нуля, длина, ссылки, ==. Запускать нельзя — только думать и объяснять.

Как решать

Сначала скажи ответ вслух и объясни почему, потом кликай. Для задачек про ссылки помогает нарисовать на бумаге стек и кучу со стрелками — как в уроке 6.3.

Что выведется на экран?

1. Что напечатает программа?

int[] a = new int[3];
System.out.println(a[1] + a.length);
  • Ошибка: a[1] не задан
  • 3
  • 03
  • 2

2. Изменение через вторую ссылку. Что напечатает?

int[] a = {1, 2, 3};
int[] b = a;
b[0] = 10;
System.out.println(a[0] + b[0]);
  • 11
  • 20
  • 1010

3. Одинаковые массивы. Что напечатают две строки?

int[] a = {1, 2, 3};
int[] b = {1, 2, 3};
System.out.println(a == b);
System.out.println(Arrays.equals(a, b));
  • true и true
  • false и true
  • false и false

4. for-each и примитивы. Что напечатает?

int[] a = {1, 2, 3};
for (int x : a) {
    x = x * 2;
}
System.out.println(Arrays.toString(a));
  • [2, 4, 6]
  • [1, 2, 3]
  • Ошибка компиляции

5. Значения по умолчанию у строк. Что напечатает?

String[] names = new String[2];
System.out.println(names[0] + "!");
  • !
  • null!
  • NullPointerException

6. Перевесили стрелку. Что напечатает?

int[] a = {3, 1, 2};
int[] b = a;
a = new int[]{9, 9};
System.out.println(b[0] + " " + a.length);
  • 9 2
  • 3 2
  • 3 3

7. Клон. Что напечатает?

int[] a = {1, 2, 3};
int[] b = a.clone();
b[0] = 100;
System.out.println(a[0]);
  • 1
  • 100
  • Ошибка компиляции

8. Массив символов. Что напечатают две строки?

char[] c = {'h', 'i'};
System.out.println(c);
System.out.println("" + c);
  • hi и hi
  • hi и что-то вроде [C@1b6d3586
  • [h, i] и [h, i]

9. ★ Сравнение через equals. Что напечатает?

int[] a = {1};
int[] b = {1};
System.out.println(a.equals(b));
  • true
  • false
  • Ошибка компиляции

Скомпилируется ли?

10. Скомпилируется?

int[] a = new int[];
  • Да, создастся пустой массив
  • Нет: не указан ни размер, ни значения

11. Скомпилируется?

int[] a = new int[3]{1, 2, 3};
  • Да, массив из трёх чисел
  • Нет: нельзя одновременно размер и значения

12. Скомпилируется? Если да — что напечатает?

int n = 0;
int[] a = new int[n];
System.out.println(a.length);
  • Да, напечатает 0
  • Нет, размер не может быть 0
  • Скомпилируется, но упадёт при запуске

Скомпилируется, но что будет при запуске?

13. Что будет при запуске?

int[] a = {5};
System.out.println(a[a.length]);
  • Напечатает 5
  • ArrayIndexOutOfBoundsException
  • Ошибка компиляции

14. ★★★ На опережение. Что будет при запуске?

int size = -1;
int[] a = new int[size];
  • Создастся пустой массив
  • Ошибка компиляции
  • Исключение NegativeArraySizeException

Найди ошибки

15. Код должен посчитать сумму всех элементов. Сколько в нём ошибок?

int[] a = {4, 8, 15, 16, 23, 42};
int sum = 0;
for (int i = 1; i <= a.length; i++) {
    sum += a[i];
}
System.out.println(sum);
  • Одна
  • Две
  • Три

Читаем код

Головоломки проверяли, что делает код. Теперь — как о нём сказать: прочитай каждую строку правильными терминами модуля, как на собеседовании или код-ревью. В одних заданиях выбери описание из пяти, в других собери его из квадратиков — лишние оставь на месте.

Джавик-курьер: что будет?

Задачки по части 3 игры: здесь код не пишем, а предсказываем, что сделает Джавик или компилятор.

Что тренирует этот набор

  • Индексы с нуля и границы: последний — length - 1, всё за ним — исключение при запуске.
  • Ссылки: b = a не копирует массив, == и equals у массивов сравнивают ссылки.
  • Значения по умолчанию и правила создания массивов, которые проверяет компилятор.
  • В for-each переменной цикла присваиваются копии элементов.
