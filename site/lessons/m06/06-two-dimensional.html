Двумерные массивы: таблицы и игровые поля

Журнал оценок, кинозал, поле для крестиков-ноликов — данные, у которых есть строки и столбцы. Для них в Java есть массив массивов.

⏱ 20 минут▦ int[][]🔁 вложенные циклы

Повторение

Данные бывают таблицей

Обычный массив — это ряд. Но многие данные — таблица: оценки трёх учеников по четырём предметам, места в кинозале (ряд и место), клетки игрового поля. Можно завести три отдельных массива — по одному на ученика. Но тогда «пройти по всем ученикам» циклом снова не выйдет. Нужен массив, элементы которого — массивы.

Аналогия: билет в кино

На билете два числа: ряд и место. Сначала находишь ряд, потом место в этом ряду. Двумерный массив устроен так же: обращение hall[ряд][место] — по двум индексам. Только нумерация, как всегда в Java, с нуля: индекс — не «номер по-человечески», а сдвиг от начала. Первый ряд — индекс 0, третье место — индекс 2.

int[][] grades = new int[3][4];   // 3 строки (ученика) по 4 столбца (предмета)
grades[1][2] = 5;                 // строка 1, столбец 2: второй ученик, третий предмет

int[][] field = {                 // сразу со значениями: строки в { }
    {1, 0, 2},
    {0, 1, 0},
    {2, 2, 1}
};
System.out.println(field[2][0]);  // 2 — строка 2, столбец 0

Как это лежит в памяти: массив массивов

Таблицы в памяти на самом деле нет. Выражение new int[3][4] создаёт в куче внешний массив из трёх ссылок, и каждая ссылка ведёт на свой обычный int[] из четырёх чисел — на строку.

🔎 Для любопытных: строки разной длины

Раз каждая строка — отдельный массив, строки могут быть разной длины («рваный» массив, jagged array):

int[][] triangle = new int[3][];   // строки пока не созданы: там null
triangle[0] = new int[1];
triangle[1] = new int[2];
triangle[2] = new int[3];

Поэтому в условии внутреннего цикла пишут grades[r].length, а не grades[0].length: так код работает с любой формой таблицы.

Обход: цикл в цикле

Внешний цикл идёт по строкам, внутренний — по столбцам текущей строки. Печать таблицей — вызов print в теле внутреннего цикла и вызов println() после него, в теле внешнего:

int[][] field = {
    {1, 0, 2},
    {0, 1, 0},
    {2, 2, 1}
};
for (int r = 0; r < field.length; r++) {           // по строкам
    for (int c = 0; c < field[r].length; c++) {    // по столбцам строки r
        System.out.print(field[r][c] + " ");
    }
    System.out.println();                           // перевод строки
}
1 0 2
0 1 0
2 2 1

С for-each тоже можно: в заголовке внешнего объявлена переменная row типа int[] — на каждой итерации ей присваивается ссылка на очередную строку, внутренний перебирает числа в строке: for (int[] row : field) { for (int x : row) { … } }.

Что будет, если перепутать и написать в условии внутреннего цикла field.length вместо field[r].length?

Для квадратной таблицы 3×3 — ничего, числа совпадают, и ошибка спрячется. А для таблицы 2×5 внутренний цикл сделает только 2 итерации — 2 столбца из 5. Для 5×2 — вылетит ArrayIndexOutOfBoundsException. Тестируй на неквадратных таблицах!

Сумма по строкам

Типичная задача: оценки учеников по предметам, найти сумму баллов каждого ученика. Роли: шагающие r и c (счётчики двух циклов), накопитель rowSum. Главный вопрос — где объявить и инициализировать накопитель? Пройди по шагам:

Правило накопителя

Накопитель инициализируют нулём перед тем циклом, по которому он копит. Сумма строки копится по столбцам — значит, int rowSum = 0; стоит в теле цикла по строкам, перед циклом по столбцам. Сумма всей таблицы — до обоих циклов.

Печать и поле для игры

Если вызвать Arrays.toString и передать двумерный массив, он покажет только ссылки на строки: [[I@1b6d3586, [I@4554617c]. Для массивов массивов есть Arrays.deepToString («глубокий»):

int[][] m = {{1, 2}, {3, 4}};
System.out.println(Arrays.deepToString(m));   // [[1, 2], [3, 4]]

А вот поле для крестиков-ноликов — массив символов. Пустым клеткам присвоим точку — символьный литерал '.':

char[][] board = new char[3][3];
for (char[] row : board) {
    Arrays.fill(row, '.');      // строка — обычный массив, fill работает
}
board[1][1] = 'X';
board[0][2] = 'O';
for (char[] row : board) {
    for (char cell : row) {
        System.out.print(cell + " ");
    }
    System.out.println();
}
. . O
. X .
. . .

Игровое поле, морской бой, лабиринт, карта уровня в игре — всё это двумерные массивы. Ход игрока — присваивание элементу board[r][c], проверка победы — обход строк, столбцов и диагоналей.

Коротко

  • int[][] m = new int[строки][столбцы]; — обращение m[r][c]: сначала строка, потом столбец.
  • Это массив массивов: m.length — строки, m[r] — строка, m[r].length — столбцы.
  • Обход — вложенные циклы: внешний по строкам, внутренний по столбцам; println() после внутреннего.
  • Накопитель строки объявляют и инициализируют нулём в теле цикла по строкам.
  • Печать целиком — Arrays.deepToString(m).
