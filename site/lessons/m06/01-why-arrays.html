Зачем нужны массивы

Сто оценок — это не сто переменных. Знакомимся с массивом: одна переменная, много ячеек, у каждой свой номер.

⏱ 20 минут📦 int[], new, length🔢 индексы с нуля

Повторение

Массивы почти всегда обходят циклом, поэтому сначала разомнём циклы и роли переменных из модуля 5.

Проблема: сто оценок

Учитель хочет посчитать средний балл класса. Пока учеников пятеро, можно завести пять переменных:

int grade1 = 5;
int grade2 = 4;
int grade3 = 3;
int grade4 = 5;
int grade5 = 4;
int sum = grade1 + grade2 + grade3 + grade4 + grade5;
System.out.println("Среднее: " + sum / 5.0);

Работает: объявили пять переменных и инициализировали каждую литералом. А теперь в школе 100 учеников. Или 1000. Или число учеников вводится с клавиатуры, и заранее ты его не знаешь. Сто строк int gradeN никто писать не будет, а цикл тут не поможет: цикл не умеет «перебирать» переменные с разными именами — grade1, grade2… для Java это просто разные слова.

Хочется написать что-то вроде «grade номер i» и крутить i в цикле. Хорошая новость: именно это и умеет массив.

В магазине та же история: в чеке 20 цен товаров, и программа проверяет, что все они больше нуля. Двадцать переменных — безумие. Один массив цен и один цикл — норма.

Идея: ряд пронумерованных ячеек

Массив (array) — это набор ячеек одного типа, стоящих подряд, под одним именем. Каждая ячейка называется элементом, а её номер — индексом. Чтобы достать элемент, пишешь имя массива и индекс в квадратных скобках: grades[2] — это обращение к элементу по индексу 2.

Аналогия: камера хранения на вокзале

Длинный ряд одинаковых ячеек. У ряда есть название — «Ряд Б», а у каждой ячейки номер на дверце. Ты не придумываешь каждой ячейке своё имя: говоришь «ряд Б, ячейка 3» — и знаешь, куда идти. Количество ячеек в ряду фиксировано: его определили, когда ставили шкаф.

Только у Java есть причуда: нумерация начинается с нуля. Первая ячейка — нулевая.

Массив
Набор ячеек одного типа под одним именем. Размер задаётся при создании и потом не меняется.
Элемент
Одна ячейка массива и значение в ней.
Индекс
Номер ячейки: целое число от 0 до «размер − 1».

Объявляем и создаём массив

int[] grades = new int[5];
int[]

Тип переменной: «массив int». Сама переменная хранит не ячейки, а ссылку на массив — адрес, где он лежит. Квадратные скобки после типа и означают «массив». Бывает double[], boolean[], String[] — любой тип плюс [].

grades

Имя массива. Обычно во множественном числе: grades, prices, names — сразу видно, что значений много.

new

Оператор new — «создай новый объект». Это создание массива: массив в Java — объект, он появляется в куче. Подробно, со стрелками, — в уроке 3.

int[5]

Сколько ячеек и какого типа. Тип справа должен совпадать с типом слева.

Вся строка читается так: «объявляем переменную grades типа int[] и инициализируем её новым массивом из 5 элементов типа int».

Размер не обязан быть числом в коде — подойдёт любая переменная типа int. Это и решает проблему «сколько учеников — заранее не знаю»:

Scanner scanner = new Scanner(System.in);
int n = scanner.nextInt();       // сколько учеников — узнаём у пользователя
int[] grades = new int[n];       // ровно n ячеек
Размер нельзя поменять

Создал массив на 5 ячеек — их будет 5 до конца жизни массива. Нужно больше — создают новый массив побольше и копируют туда значения элементов. (Списки, которые растут сами, — в модуле 13 «Коллекции».)

🔎 Для любопытных: можно ли написать int grades[]?

Можно: int grades[] = new int[5]; — так пишут в языке C, и Java это разрешает. Но в Java принято ставить скобки у типа: int[] grades. Тогда читается честно: «объявляем переменную grades типа int[]». На собеседовании иногда спрашивают, скомпилируется ли второй вариант. Ответ: да.

Что лежит в новом массиве

Ты создал массив new int[5] и ни одному элементу ничего не присвоил. Что внутри? Если прочитать локальную переменную, которую объявили, но не инициализировали, Java бы ругалась («variable might not have been initialized»). А вот ячейки массива всегда заполняются значениями по умолчанию:

Тип массиваЗначение в каждой ячейке
int[], long[], byte[], short[]0
double[], float[]0.0
boolean[]false
char[]символ с кодом 0 ('\u0000') — невидимый
String[] и другие объектыnull — «ссылки нет, коробка пустая»
Что напечатает: boolean[] flags = new boolean[3]; System.out.println(flags[1]);

false. Обращаемся к элементу с индексом 1 — элементы boolean-массива по умолчанию равны false. Ошибки нет: значение по умолчанию есть всегда.

А это? String[] names = new String[2]; System.out.println(names[0]);

null. Строк ещё нет — ячейки пустые. Печать null не падает, а вот вызов метода у такого элемента (например, names[0].length()) уронит программу с NullPointerException.

Сразу со значениями: литерал { }

Если значения известны заранее, массив можно создать и заполнить одной строкой. Фигурные скобки со значениями через запятую — это литерал массива (инициализатор). Размер Java посчитает сама. int[] daysInMonth = {31, 28, 31, 30}; читается так: «объявляем переменную daysInMonth типа int[] и инициализируем её литералом массива из четырёх элементов».

int[] daysInMonth = {31, 28, 31, 30};            // 4 ячейки
String[] colors = {"красный", "жёлтый", "зелёный"}; // 3 ячейки
double[] prices = {99.9, 150.0};                  // 2 ячейки
Ловушка: короткая форма — только при объявлении

int[] a = {1, 2, 3}; — объявление с инициализацией, можно. А вот присваивать литерал отдельно от объявления нельзя:

int[] a;
a = {1, 2, 3};             // ошибка компиляции: illegal start of expression
a = new int[]{1, 2, 3};    // так можно: полная форма работает везде

Индексы с нуля и length

Элемент массива ведёт себя как обычная переменная: через обращение по индексу его можно прочитать, присвоить ему новое значение, увеличить инкрементом.

int[] grades = {5, 4, 3, 5, 4};
grades[2] = 4;                     // исправили третью оценку
grades[0]++;                       // была 5, стала 6 (ну, бывает)
System.out.println(grades[0]);     // 6
System.out.println(grades.length); // 5 — сколько ячеек

grades.length — длина массива, то есть число элементов. Пишется без скобок: это не вызов метода, а поле массива, как надпись «5 ячеек» на шкафу. Последний элемент всегда grades[grades.length - 1].

Почему с нуля? Индекс — это не «номер по счёту», а сколько шагов отступить от начала. Первая ячейка стоит в самом начале — до неё 0 шагов. Третья — в двух шагах. Поэтому grades[2] — третья.

В таблице каждая ячейка массива показана отдельной строкой: a[0], a[1]… — так удобнее следить, что где меняется.

Коротко

  • Массив — много элементов одного типа под одним именем. Размер фиксирован при создании массива.
  • Объявление с инициализацией новым массивом: int[] a = new int[5]; или литералом массива int[] a = {1, 2, 3};.
  • Новый массив заполнен значениями по умолчанию: 0, 0.0, false, null.
  • Обращение к элементу по индексу; индексы с нуля: первый a[0], последний a[a.length - 1].
  • a.length — длина массива, поле без скобок.
