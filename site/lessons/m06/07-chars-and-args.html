Повторение

Массив символов

Тип char — один символ в одинарных кавычках: 'J', 'я', '7'. Массив таких символов — char[], с ним всё как с int[]:

char[] letters = {'J', 'a', 'v', 'a'};
letters[0] = 'j';                         // ячейку можно поменять
System.out.println(letters.length);       // 4
System.out.println(letters);              // java — печатается как текст!

Заметь последнюю строку: если передать аргументом int[], println напечатал бы «паспорт» [I@…, а char[] он умеет печатать как текст. Это единственное такое исключение — println специально обучен массивам символов.

Что выведет: char[] w = {'о', 'к'}; System.out.println("Ответ: " + w);

Что-то вроде Ответ: [C@7a81197d. Ловушка! Особый режим у println(char[]) работает, только когда массив передан единственным аргументом. Здесь же сначала вычисляется выражение "Ответ: " + w, а при склейке массив превращается в «паспорт» ([C — массив char). Чинится так: "Ответ: " + new String(w) или Arrays.toString(w) → [о, к].

Строка ↔ массив символов

Внутри строки String символы тоже лежат рядом и пронумерованы с нуля. Поэтому строку легко превратить в массив символов и обратно: вызываем у строки метод toCharArray() — он возвращает новый массив; а выражение new String(chars) создаёт новую строку из массива:

String word = "кот";
char[] chars = word.toCharArray();     // ['к', 'о', 'т'] — НОВЫЙ массив-копия
chars[0] = 'р';
String changed = new String(chars);    // "рот" — новая строка из массива
System.out.println(word + " → " + changed);   // кот → рот

length или length()?

Вечная путаница, на которой спотыкаются даже опытные: у массива — поле a.length, у строки — метод s.length(), его вызывают со скобками. IDEA подчеркнёт красным, если перепутаешь. А на собеседовании могут спросить именно это.

String[] args — что это наконец такое

С первой программы ты писал public static void main(String[] args), не зная, что такое String[] args. Теперь знаешь: это параметр метода main — массив строк с именем args (от arguments — аргументы). Подробно про параметры — в модуле 7, а пока главное: в этот массив Java кладёт слова, которые передали программе при запуске.

public class Greeter {
    public static void main(String[] args) {
        System.out.println("Аргументов: " + args.length);
        for (int i = 0; i < args.length; i++) {
            System.out.println("args[" + i + "] = " + args[i]);
        }
    }
}

Запусти кнопкой ▶ — увидишь Аргументов: 0. Массив есть, но пустой: длина 0, а ссылка не null. Чтобы передать аргументы в IntelliJ IDEA:

  1. Вверху, рядом с кнопкой ▶, открой список с именем класса → Edit Configurations…
  2. В поле Program arguments впиши через пробел: Петя 25 Москва
  3. OK и снова ▶.
Без аргументов — не трогай args[0]

Если запустить без аргументов и обратиться к args[0], получишь знакомое ArrayIndexOutOfBoundsException: Index 0 out of bounds for length 0. Сначала проверяй args.length.

Где это используют: консольные утилиты (копировать откуда куда), серверы (--port 8080), игры (--fullscreen — запуск сразу на весь экран). Сейчас тебе args почти не нужен, но больше main не будет выглядеть заклинанием.

🔎 Для любопытных: как превратить "25" в число?

int age = Integer.parseInt(args[1]); — вызываем метод parseInt и передаём аргумент args[1]; метод возвращает число, им инициализируется age. Если строка не число ("двадцать"), программа упадёт с NumberFormatException. Подробнее — в модулях про строки и исключения.

Коротко

  • char[] — массив символов; println(chars) печатает его как текст, но при склейке со строкой — «паспорт» [C@….
  • Вызов s.toCharArray() возвращает новый массив символов, new String(chars) создаёт строку из массива.
  • Массив: a.length, a[i], можно менять. Строка: s.length(), s.charAt(i), менять нельзя.
  • String[] args — параметр метода main, аргументы запуска программы; без аргументов это пустой массив длины 0.
