Ввод с клавиатуры: Scanner

До сих пор программа только говорила. Теперь она научится слушать: спросит имя, возраст, число — и ответит по-разному в зависимости от того, что ты ввёл.

⏱ 25 минут⌨️ ввод в консоли IDEA🪤 главная ловушка

Повторение

Программа, которая слушает

Ты уже знаешь System.out — это выход программы, экран. У него есть пара: System.in — вход, клавиатура. Но System.in умеет отдавать только «сырые» символы, один за другим. Разбирать их вручную — мучение. Поэтому в Java есть готовый помощник — класс Scanner.

Аналогия: официант

Ты говоришь официанту длинную фразу: «Мне, пожалуйста, два капучино и чизкейк». Официант записывает в блокнот уже разобранный заказ: «капучино — 2, чизкейк — 1». Scanner — такой официант: слушает поток символов с клавиатуры и выдаёт программе готовые числа, слова и строки.

Первая программа с вводом

import java.util.Scanner;

public class AskName {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Как тебя зовут?");
        String name = scanner.nextLine();
        System.out.println("Привет, " + name + "!");
    }
}
import java.util.Scanner;

«Возьми класс Scanner с полки java.util». Помнишь, Java — огромная библиотека готовых классов, разложенных по пакетам? import говорит, где взять нужный. Пишется в самом верху файла, над классом. String и System лежат в пакете java.lang — его Java подключает сама, поэтому для них import не нужен.

Scanner scanner = new Scanner(System.in);

Объявляем переменную scanner типа Scanner и инициализируем её: new создаёт новый объект в куче — прямо как в уроке 2.4. Переменная scanner хранит ссылку на него. В скобках — аргумент, значение, которое мы передаём: откуда читать — System.in, с клавиатуры. Сканер создаём один раз в начале программы.

scanner.nextLine()

Вызов метода nextLine() у объекта scanner. Программа останавливается и ждёт, пока ты что-нибудь напечатаешь и нажмёшь Enter. Потом метод возвращает введённую строку — ею инициализируется переменная name.

IDEA допишет import сама

Начни набирать Scanner и выбери подсказку — import появится наверху автоматически. Если слово уже подчёркнуто красным, встань на него и нажми Alt+Enter → Import class. Но первый раз напиши import руками, чтобы запомнить.

Как вводить в консоли IDEA

  1. Запусти программу зелёным треугольником ▶, как обычно.
  2. Внизу откроется панель Run, в ней появится вопрос «Как тебя зовут?». Программа ждёт: кнопка ■ (стоп) красная, процесс не закончился.
  3. Щёлкни мышкой в панель Run, чтобы курсор оказался там, а не в редакторе кода.
  4. Напечатай ответ и нажми Enter. Твой ввод IDEA показывает зелёным цветом.

Дробные числа — через запятую!

Scanner читает числа по правилам языка твоей системы. В русской Windows дробную часть он ждёт через запятую: 3,5. Если ввести 3.5, программа упадёт с ошибкой InputMismatchException. В коде Java дробные числа по-прежнему пишутся через точку — это разные вещи.

Проверка задач на сайте

Когда ты жмёшь «Проверить» на странице задач, ввод подставляется автоматически, а в выводе он не виден: видно только то, что напечатала программа. Поэтому в задачах важно, print или println ты используешь для вопроса, — в условии всегда показан точный вывод.

Метода nextChar() нет. Чтобы прочитать один символ, берут слово и первый символ из него: у строки, которую вернул next(), вызывают метод charAt(0) — scanner.next().charAt(0).

System.out.println("Сколько тебе лет?");
int age = scanner.nextInt();
System.out.println("Через 10 лет тебе будет " + (age + 10));

Через 10 лет тебе будет 29

А если на вопрос о возрасте ввести «девятнадцать»? nextInt() не сможет превратить слово в число, и программа упадёт с ошибкой InputMismatchException («ввод не подходит по типу»). Обрабатывать такие ошибки научимся в модуле 12.

Программа читает имя через scanner.next() и печатает "Привет, " + name + "!". Пользователь ввёл «Анна Мария». Что выведется?

Привет, Анна! next() читает только до пробела. «Мария» осталась непрочитанной и ждёт следующего вызова. Для имени с пробелами нужен nextLine().

Ловушка: nextInt, а за ним nextLine

Классика, на которой спотыкаются все новички (и это популярный вопрос на Stack Overflow). Программа спрашивает возраст, потом город:

System.out.println("Возраст:");
int age = scanner.nextInt();
System.out.println("Город:");
String city = scanner.nextLine();
System.out.println(age + " лет, город " + city);

Город спросили — и не дали ввести! Программа сразу закончилась. Почему?

Всё, что ты печатаешь, попадает на «ленту ввода», включая нажатие Enter — это тоже символ (обозначим его ⏎). Scanner читает ленту слева направо:

Починка: после nextInt() вызови лишний scanner.nextLine(); — он «доест» оставшийся Enter. Посмотри по шагам — переменная (ввод) показывает, что осталось на ленте:

Второй способ — читать всё через nextLine(), а число получать из строки методом Integer.parseInt. Его разберём в следующем уроке.

Собери программу

🔎 Для любопытных: а сканер не надо закрывать?

У Scanner есть метод close(), и IDEA иногда подсвечивает сканер жёлтым с советом закрыть его. Для сканера клавиатуры в маленькой программе это не обязательно: программа закончится — и всё освободится. Правильную работу с ресурсами (try-with-resources) разберём в модуле 15 про файлы. А вот чего делать не стоит — создавать несколько сканеров для System.in в одной программе: один сканер на всю программу.

Проверь себя

Поговори с наставником

Напиши: «Объясни ещё раз ловушку nextInt + nextLine на другом примере, а потом я сам расскажу, почему так происходит».

Коротко

  • import java.util.Scanner; наверху, потом Scanner scanner = new Scanner(System.in); — один на программу.
  • Что возвращают методы: nextLine() — строку целиком, next() — слово, nextInt()/nextDouble()/nextLong() — числа. Символ — next().charAt(0).
  • Программа ждёт ввода; в IDEA щёлкни в панель Run, введи ответ и нажми Enter.
  • Дробные числа в консоли русской Windows вводят через запятую.
  • Ловушка: nextInt() оставляет Enter, и следующий nextLine() вернёт пустую строку. Лечится лишним nextLine().
