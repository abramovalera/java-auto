Стек и куча — тоже

Картинка со стрелками вернётся в модулях про массивы, методы и классы. Чем лучше ты её понял сейчас, тем легче будет дальше.

Коротко

  • Переменная — коробка с типом, именем и значением. Её объявляют, инициализируют, ей присваивают новые значения; = — оператор присваивания («положи»).
  • Пять главных примитивов: int, long, double, boolean, char. String — класс, строки — объекты.
  • Примитив — значение прямо на стеке, объект — в куче, в переменной ссылка.
  • Scanner читает с клавиатуры; помни про ловушку nextInt + nextLine.
  • Расширение — автоматически, сужение — явно (тип); (double) a / b — дробное деление, (double) (a / b) — уже поздно; строки в числа — Integer.parseInt/Double.parseDouble (Integer, Double — классы-обёртки); дробь с «хвостом» — Math.round(x * 10) / 10.0.
Совет: спрашивай ИИ, пока не станет понятно

Перечитай «Коротко» выше. Если хоть один пункт ты не можешь объяснить своими словами — спроси наставника в Claude Code или любой бесплатный ИИ (например, DeepSeek). Проси разжевать, привести пример из жизни, объяснить ещё раз другими словами — столько раз, сколько нужно. Решение задач за тебя не проси: спрашивай «почему» и «как это работает».
