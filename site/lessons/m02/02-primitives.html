Примитивные типы: числа, «да/нет» и символы

Целое число, дробное, «да или нет», одна буква — для каждого вида данных в Java своя коробка. Разберёмся, какие они бывают, сколько вмещают и что случается, когда коробка переполняется.

Разные данные — разные коробки

На кухне соль хранят в солонке, молоко — в бутылке, а яйца — в лотке. Можно было бы всё сложить в одно ведро, но тогда неудобно и легко всё испортить. В Java так же: для каждого вида данных — своя «тара», свой тип.

Память компьютера состоит из битов — крошечных ячеек, в каждой 0 или 1. Восемь битов — это байт. Чем больше байтов у типа, тем больше разных значений в нём помещается. Например, int занимает 4 байта (32 бита), и в нём помещаются числа от −2 147 483 648 до 2 147 483 647 — примерно ±2 миллиарда.

В Java есть восемь встроенных типов. Их называют примитивными (простыми): они хранят одно простое значение, и пишутся они с маленькой буквы.

Каждый день тебе понадобятся пять типов со звёздочкой ⭐. byte, short и float встречаются редко: знай, что они есть, и не пугайся, если увидишь в чужом коде.

Целые числа: int и long

int — главный тип для целых чисел: количество, возраст, номер, очки. Если число может вырасти больше двух миллиардов — бери long.

int players = 12;
int temperature = -5;
long population = 8_100_000_000L;     // население Земли
long millis = 1_700_000_000_000L;     // миллисекунды — их всегда много

Значение, написанное прямо в коде (12, -5, 8_100_000_000L), называется литерал. У литералов тоже есть тип, и Java определяет его по внешнему виду:

  • целое число без хвостика — это int;
  • с буквой L в конце — long. Пиши большую L: маленькую l легко спутать с единицей;
  • подчёркивания _ внутри числа Java пропускает. Они нужны только людям, чтобы видеть разряды: 1_000_000 читается легче, чем 1000000.
Скомпилируется ли строка long big = 3000000000;?

Нет! Ошибка integer number too large. Коробка long большая, но сам литерал 3000000000 без L считается int, а для int он слишком велик. Починка: 3000000000L.

Дробные числа: double

double price = 99.90;
double pi = 3.14159;
double half = 0.5;
double whole = 5;          // можно и целое: станет 5.0
float weight = 72.5f;      // float — с буквой f

Дробная часть отделяется точкой, а не запятой, как в английском. 3,14 Java поймёт как два разных числа через запятую — и выдаст ошибку. Число с точкой без хвостика — это double. Чтобы получился float, нужна буква f на конце.

Что напечатает System.out.println(0.1 + 0.2);?

0.30000000000000004 — не опечатка! Компьютер хранит дробные числа в двоичном виде, а 0.1 в двоичной системе — бесконечная дробь, как 1/3 = 0.3333… в десятичной. Хранится чуть-чуть неточное число, и при сложении погрешность вылезает наружу. Так работает почти любой язык программирования, не только Java.

Деньги в double не хранят

Из-за таких погрешностей в банках и магазинах деньги в double не держат. Их считают в копейках (целым числом в long) или используют специальный класс BigDecimal — его разберём позже. Для учебных задач double подходит.

«Да/нет» и символы: boolean и char

boolean хранит только одно из двух значений: true (истина, «да») или false (ложь, «нет»). Это ответ на вопрос: залогинен ли пользователь? Оплачен ли заказ? Включён ли свет?

boolean isLoggedIn = true;
boolean testPassed = false;

Литералы true и false пишутся без кавычек: "true" в кавычках — уже строковый литерал, текст, а не boolean. И нет, вместо них нельзя писать 1 и 0, как в некоторых языках. Такие переменные часто называют с is или has: isVisible, hasError. Настоящая сила boolean откроется в модуле 4, когда программа начнёт принимать решения.

char (от англ. character — символ) хранит ровно один символ в одинарных кавычках:

char grade = 'A';
char letter = 'я';
char digit = '7';      // символ «7», а не число 7
char space = ' ';      // пробел — тоже символ

'AB' — ошибка: два символа в char не влезут. А "A" в двойных кавычках — это уже строка (String), не char. Помнишь головоломку из модуля 1 про println('Hello')? Вот откуда она.

Секрет char

На самом деле внутри char лежит число — номер символа в огромной таблице всех символов мира (Unicode). 'A' — это 65, 'a' — 97, 'Я' — 1071. Поэтому 'A' + 'B' даёт 131, а не «AB». Подробно — в уроке 2.6.

Какой тип выбрать?

Новичков на собеседовании часто просят выбрать тип для данных из жизни. Потренируйся: для каждой карточки нажми подходящий тип.

Переполнение: когда коробка мала

Самое большое число, которое влезает в int, хранится в готовой константе Integer.MAX_VALUE (Integer — класс-помощник для типа int, о нём в уроке 2.3). Что будет, если прибавить к нему единицу?

int max = Integer.MAX_VALUE;
System.out.println(max);
System.out.println(max + 1);

Никакой ошибки, никакого предупреждения — просто самое большое число превратилось в самое маленькое. Это переполнение (англ. overflow).

Аналогия: счётчик пробега

У старой машины счётчик пробега на шесть цифр. Проехал 999 999 км, ещё километр — и на счётчике 000 000. Цифр больше нет, счёт пошёл по кругу. У int то же самое, только круг замыкается не на нуле, а на самом маленьком отрицательном числе.

История: Gangnam Style сломал YouTube

В 2014 году клип «Gangnam Style» приблизился к 2 147 483 647 просмотрам — пределу 32-битного счётчика. Разработчикам YouTube пришлось срочно перевести счётчик на 64-битное число — то есть на аналог long. Переполнение — не учебная выдумка.

Что выведет программа?
int a = 2_000_000_000;
int b = a + a;
System.out.println(b);

−294967296. 4 миллиарда в int не влезает, счёт ушёл по кругу в минус. Если ждёшь больших чисел — бери long. Но осторожно: long b = a + a; не спасёт! Выражение справа a + a вычисляется в int (обе переменные — int) и переполняется до того, как результат присвоится переменной long. Как это обойти — в уроке 2.6.

🔎 Для любопытных: почему после плюса получается минус

Один из 32 битов int хранит знак: 0 — плюс, 1 — минус. Самое большое int — это 0 и дальше 31 единица. Прибавляем 1: единицы «переносятся», как 0999 + 1 = 1000 в десятичной системе, и в знаковом бите оказывается 1. Получается самое маленькое отрицательное число. Такая запись называется «дополнительный код». Учить её не нужно, главное — помнить, что int идёт по кругу.

Для long то же самое, только круг гораздо больше: Long.MAX_VALUE = 9 223 372 036 854 775 807.

Коротко

  • Восемь примитивных типов; каждый день нужны пять: int, long, double, boolean, char.
  • Литералы: 42 — int, 42L — long, 4.2 — double, 4.2f — float, 'A' — char, true — boolean.
  • Дробная часть — через точку. 0.1 + 0.2 ≠ 0.3 ровно: дробные числа хранятся с погрешностью.
  • char — один символ в одинарных кавычках, внутри — числовой код.
  • int вмещает примерно ±2,1 миллиарда. Integer.MAX_VALUE + 1 молча уходит в минус — это переполнение. Для больших чисел — long.
