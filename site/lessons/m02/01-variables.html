Переменные: коробки с ярлыками

Пока что твои программы умеют только повторять заученный текст. Научим их запоминать: числа, слова, «да» и «нет» — и менять запомненное по ходу работы.

Зачем программе память

В модуле 1 программа печатала только то, что ты заранее вписал в кавычки. Но настоящим программам нужно помнить:

  • игра помнит очки, жизни и имя игрока;
  • интернет-магазин — сколько товаров в корзине и на какую сумму;
  • банковское приложение — номер счёта, баланс и сколько раз подряд ввели неверный ПИН-код.

Для этого в любом языке программирования есть переменные. Переменная — это место в памяти компьютера, у которого есть имя и в котором лежит значение.

Аналогия: коробки на складе

Представь склад с коробками. На каждой наклеен ярлык с именем: age, score, lives. Внутри коробки лежит одно значение. Хочешь узнать, сколько очков, — находишь коробку по ярлыку и заглядываешь внутрь. Хочешь поменять — вынимаешь старое и кладёшь новое.

Ярлык у коробки не меняется, а содержимое можно менять сколько угодно. Отсюда и слово «переменная»: значение в ней может меняться, пока работает программа.

Объявление: заводим коробку

Прежде чем класть что-то в коробку, её нужно завести. Это называется объявление переменной: мы сообщаем Java её тип и имя. Строку ниже читают так: «объявляем переменную age типа int»:

int age;
int

Тип переменной: какие значения в неё можно класть. int (от англ. integer — целое число) — коробка для целых чисел: 25, 0, −7.

age

Имя — ярлык на коробке. Придумываешь сам. Хорошее имя объясняет, что лежит внутри: age — возраст.

;

Конец инструкции, как и в модуле 1.

Тип — это форма коробки. В коробку для целых чисел не получится положить текст или 3.5: компилятор заметит это ещё до запуска и покажет ошибку. Тип выбирается один раз и навсегда — поменять его у переменной нельзя. Про другие типы (дробные числа, текст, «да/нет») — в следующих уроках.

Переменные пока пишем внутри метода main, между его фигурными скобками:

public class Variables {
    public static void main(String[] args) {
        int age;
        age = 25;
        System.out.println(age);
    }
}

Присваивание: = значит «положи»

Строка age = 25; похожа на математику: «age равно 25». Но в Java знак = означает совсем другое. Это оператор присваивания: «вычисли то, что справа, и положи в коробку слева». А вся строка — присваивание: переменной age присваивается значение 25.

Читай такие строки справа налево: «переменной age присваиваем 25» — то есть кладём 25 в коробку age.

= — это не «равно»

В Java = — это команда, а не утверждение. Слева от неё всегда стоит переменная (коробка), справа — значение. Поэтому 25 = age; — ошибка: числу 25 ничего присвоить нельзя, это не переменная. А сравнение «равны ли два значения» пишется двумя знаками ==. Его разберём в модулях 3 и 4.

Объявить переменную и сразу присвоить ей значение можно одной строкой. Так пишут чаще всего:

int age = 25;      // объявление + первое значение
int lives = 3;

Первое значение переменной называют инициализацией (от англ. initial — начальный). Строку int age = 25; читают так: «объявляем переменную age типа int и инициализируем её значением 25». А само число 25, записанное прямо в коде, называют литералом.

Что выведет программа?
int x = 5;
x = 7;
System.out.println(x);

7. В коробке помещается только одно значение. Когда переменной присваиваем 7, пятёрка выбрасывается навсегда — никакого «5 и 7» не будет.

Новое значение из старого

Самая важная строка этого урока:

int score = 120;
score = score + 10;
System.out.println(score);
130

Для математика score = score + 10 — бессмыслица: число не может быть равно самому себе плюс десять. Но для Java это присваивание: справа стоит выражение score + 10 — кусочек кода, который вычисляется в одно значение. Всё делается в три простых действия:

Ловушка. Что выведет программа?
int a = 2;
int b = a * 10;
a = 5;
System.out.println(b);

20. В строке 2 Java вычислила выражение 2 * 10 и инициализировала b результатом — числом 20. В коробке лежит готовое число, а не формула «a умножить на 10». Поэтому, когда a поменялась, b осталась прежней. Это не Excel, где ячейки пересчитываются сами.

Чтобы напечатать значение, передай методу println имя переменной без кавычек:

int age = 25;
System.out.println(age);        // 25 — значение из коробки
System.out.println("age");      // age — просто текст из трёх букв
System.out.println("Мне " + age + " лет");

В кавычках — строковый литерал: текст, который печатается как есть. Без кавычек — имя переменной, и Java подставит её значение — то, что лежит в коробке. Склейка через + работает так же, как в модуле 1: строка + число = строка.

Помнишь ловушку «2 + 2 = 22»? Что выведет программа?
int age = 25;
System.out.println("Через год: " + age + 1);

Через год: 251. Вычисление идёт слева направо: "Через год: " + age — уже строка «Через год: 25», к ней приклеивается «1». Починка — скобки: "Через год: " + (age + 1) → «Через год: 26».

Переменные работают вместе

В настоящей программе переменных много, и они передают значения друг другу, как эстафету. Одну заполнили, из неё посчитали вторую, из двух собрали третью. Поначалу именно это кажется самым запутанным, поэтому разберём медленно.

Задача: поздравить Артёма и сказать, сколько ему будет через год.

String name = "Артём";        // 1. кладём имя
int age = 20;                 // 2. узнали у Артёма возраст
int nextAge = age + 1;        // 3. из age считаем новое число
String message = name + ", через год тебе " + nextAge;  // 4. собираем строку
System.out.println(message);
Артём, через год тебе 21
  1. Положили имя. Объявили переменную name типа String и инициализировали её текстом «Артём».
  2. Узнали возраст. Объявили age и инициализировали числом 20. В модуле 2.5 его спросят с клавиатуры, а позже (модуль 7) — получат из другого метода. Для коробки это неважно: главное, что в ней теперь лежит число.
  3. Посчитали новое значение. Java вычислила выражение age + 1 (достала 20 из age, прибавила 1) и результатом 21 инициализировала новую переменную nextAge. Сама age не изменилась — в ней по-прежнему 20.
  4. Собрали строку. Java достала «Артём» из name, приклеила текст «, через год тебе », потом приклеила 21 из nextAge. Получилась одна новая строка — ею и инициализировали переменную message.
В коробке — готовый результат, а не связь

В message лежит готовый текст «Артём, через год тебе 21». Если потом присвоить name новое значение (name = "Вика";), message не поменяется — его уже собрали. Чтобы получить новую строку, её надо собрать заново. Это как фотография: снял — и картинка больше не меняется, что бы ни происходило с людьми на ней.

Правила и частые ошибки

Компилятор строго следит за переменными. Вот что он скажет, если нарушить правила:

КодСообщение javacЧто не так
System.out.println(cost);cannot find symbolПеременной cost нет: её не объявили или опечатались в имени.
int x;
System.out.println(x);		variable x might not have been initializedПеременная объявлена, но не инициализирована — коробка пустая. Читать из неё нельзя, сначала присвой ей значение.

Правила для имён:

  • буквы, цифры, _ и $; начинаться с цифры нельзя: 2players — ошибка, player2 — можно;
  • без пробелов и дефисов: my age и my-age — ошибки;
  • регистр важен: age и Age — две разные переменные;
  • нельзя брать служебные слова Java: int, class, public…

Коротко

  • Переменная — коробка с ярлыком: у неё есть тип, имя и значение.
  • int age; — объявление; int age = 25; — объявление с инициализацией (первым значением); 25 — литерал.
  • = — оператор присваивания («положи»), а не «равно». Сначала вычисляется выражение справа, потом результат присваивается переменной слева.
  • score = score + 10 — вычислить выражение из старого значения и присвоить результат той же переменной.
  • В переменной лежит готовое значение, а не формула. Новое значение вытесняет старое.
  • Нельзя: читать пустую переменную, объявлять её дважды, присваивать значение не того типа.
