Что выведется? Скомпилируется ли?

Переменные, типы, ссылки, преобразования — на этом строится добрая половина вопросов «что будет?» на собеседованиях. Запускать нельзя, только думать.

Как решать

Сначала ответ — потом клик

Не кликай сразу. Скажи ответ вслух или запиши и объясни себе, почему так. Для задач с несколькими переменными нарисуй табличку трассировки, а для строк — стрелки на кучу. Не уверен — набери код в IDEA и проверь: так тоже честно.

На собеседовании ценят не угаданный ответ, а объяснение. «Будет 131, потому что char + char — это сложение кодов» звучит куда сильнее, чем просто «131».

Что выведется на экран?

1. Разминка. Что напечатает программа?

int a = 5;
int b = a;
a = 10;
System.out.println(b);
  • 10
  • 5
  • 15

2. Классика. Что напечатает?

System.out.println('A' + 'B' + "C");
  • ABC
  • 131C
  • A B C
  • Ошибка компиляции

3. А так?

System.out.println("" + 'A' + 'B' + 1);
  • 131
  • AB + 1
  • AB1

4. Что окажется в d?

double d = 10 / 4;
System.out.println(d);
  • 2.5
  • 2.0
  • 2

5. ★★ Ловушка переполнения. Что напечатает?

long big = Integer.MAX_VALUE + 1;
System.out.println(big);
  • 2147483648
  • -2147483648
  • Ошибка компиляции

6. Строки и стрелки. Что напечатает?

String s1 = "Кот";
String s2 = s1;
s1 = s1 + "ик";
System.out.println(s2);
  • Котик
  • Кот
  • null

7. Что напечатает?

char c = 'a';
System.out.println(c + 1);
  • b
  • a1
  • 98

Скомпилируется ли?

8. Скомпилируется?

long stars = 3000000000;
  • Да, в long помещается
  • Нет: литерал без L считается int и слишком велик

9. Скомпилируется?

float price = 9.99;
  • Да
  • Нет: 9.99 — это double, нужно 9.99f

10. ★★ Вопрос с подвохом. Скомпилируется? Если да, что напечатает?

char c = 65;
System.out.println(c);
  • Не скомпилируется: int в char нельзя
  • Скомпилируется, напечатает 65
  • Скомпилируется, напечатает A

11. Скомпилируется?

var data = null;
  • Да, data будет пустой
  • Нет: по null нельзя угадать тип

12. Найди строку с ошибкой.

final int LIMIT;          // строка 1
LIMIT = 10;               // строка 2
LIMIT = 20;               // строка 3
  • Строка 1: final без значения нельзя
  • Строка 2
  • Строка 3: значение уже было присвоено

Скомпилируется, но что будет при запуске?

13. Что будет при запуске?

String title = null;
System.out.println(title.length());
  • Напечатается 0
  • Ошибка компиляции
  • NullPointerException

14. Пользователь ввёл 20, нажал Enter, потом ввёл Анна. Что напечатает программа?

int age = scanner.nextInt();
String name = scanner.nextLine();
System.out.println(name + ": " + age);
  • Анна: 20
  • : 20
  • InputMismatchException

15. ★★★ На опережение (модуль 3). Что будет при запуске?

System.out.println(1 / 0.0);
System.out.println(1 / 0);
  • Обе строки упадут с ошибкой
  • Напечатается Infinity, потом ArithmeticException
  • 0.0 и 0

Найди ошибки

16. Сколько ошибок компиляции в этом коде?

int age = "25";
String name = 'Аня';
boolean ok = True;
double price = 9.99;
  • Одна
  • Две
  • Три
  • Четыре
Хочешь ещё?

Напиши наставнику: «Дай мне 3 головоломки по модулю 2 про типы и преобразования, по одной, ответ не говори, пока я не объясню». На экзамене модуля они тоже будут.

Что тренируем

  • Тип литерала решает всё: 3000000000 без L — int, 9.99 без f — double.
  • Выражение справа вычисляется первым и в «своём» типе: 10 / 4 — это 2 даже в double-переменной.
  • char — это число: 'A' + 'B' = 131, пока в выражении не появилась строка.
  • Ссылки: копируем стрелку, а не объект; null — нет стрелки, у него нельзя вызвать метод.
