Как читать код: правильные слова

Программисты не говорят «тут переменная, кладём в неё число». Они говорят «объявляем переменную и инициализируем её». Учимся читать каждую строку кода вслух так, как скажут на собеседовании и на код-ревью.

⏱ 25 минут🗣 читаем вслух🧩 тренажёр «что происходит»

Зачем правильные слова

Код читают гораздо чаще, чем пишут: коллеги на код-ревью, ты сам через месяц, собеседующий на интервью. И везде нужен общий язык. Когда ты говоришь «инициализируем переменную результатом вызова метода», любой программист сразу понимает, что происходит, — а «тут мы кладём штуку из сканера» понятно только тебе.

🎤

Собеседование

«Прочитай этот код и объясни, что он делает» — один из самых частых вопросов.

👀

Код-ревью

Замечания пишут терминами: «здесь переменная объявлена, но не инициализирована».

🤖

Вопросы ИИ

Точные слова — точный ответ. ИИ лучше понимает «почему не компилируется присваивание», чем «почему не работает».

Аналогии вроде «коробки с ярлыком» никуда не денутся — они помогают понять. Но рядом с аналогией всегда будет правильное слово. Его и запоминаем.

Объявление, инициализация, присваивание

Три слова, которые путают чаще всего. Смотри на одну переменную в трёх строках:

int count;      // 1
count = 3;      // 2
count = 5;      // 3
СтрокаКак называетсяЧто происходит (аналогия)
int count;Объявление переменной count типа intЗавели коробку с ярлыком count, в которую помещаются целые числа. Она пока пустая — читать из неё нельзя.
count = 3;Инициализация — первое присваивание значенияВпервые положили в коробку число 3.
count = 5;Присваивание нового значенияВынули 3, положили 5. Старое значение потеряно.

Чаще всего объявление и инициализацию пишут одной строкой:

int count = 3;  // объявляем count и сразу инициализируем значением 3

Читается так: «объявляем переменную count типа int и инициализируем её значением 3». А знак = называется оператор присваивания: он вычисляет то, что справа, и кладёт результат в переменную слева.

Главная ошибка новичка

Объявил, но не инициализировал — и прочитал: int count; System.out.println(count);. Компилятор ответит variable count might not have been initialized — «переменная, возможно, не инициализирована». Теперь ты понимаешь каждое слово в этой ошибке.

Литерал, выражение, оператор, инструкция

Разберём одну строку на детали:

int total = price * count + 50;
ЧастьТерминЧто это
intтипкакие значения можно хранить — целые числа
totalимя переменнойярлык на коробке
=оператор присваивания«вычисли правую часть и положи результат в total»
price * count + 50выражениевсё, что вычисляется в одно значение
* и +операторыдействия над значениями
price, count, 50операндыто, над чем действуют операторы
50литералзначение, записанное прямо в коде. Литералы бывают разные: 50, 4.5, "Аня", 'A', true
вся строка с ;инструкциязаконченное действие программы. Здесь — объявление с инициализацией

Целиком строка читается так: «объявляем переменную total типа int и инициализируем её результатом выражения price * count + 50».

Читаем программу по строкам

Набери программу в training (новый класс Shop) и запусти. А потом прочитай каждую строку вслух — полным предложением, как в таблице.

public class Shop {
    public static void main(String[] args) {
        final int DISCOUNT = 10;
        int price = 250;
        int count;
        count = 3;
        int total = price * count;
        total = total - DISCOUNT;
        String text = "Итого: " + total;
        System.out.println(text);
    }
}
СтрокаКак читать вслух
final int DISCOUNT = 10;Объявляем константу DISCOUNT типа int и инициализируем её литералом 10. Присвоить ей другое значение уже нельзя.
int price = 250;Объявляем переменную price типа int и инициализируем литералом 250.
int count;Объявляем переменную count типа int без значения.
count = 3;Присваиваем переменной count значение 3. Это её инициализация — первое значение.
int total = price * count;Объявляем total и инициализируем результатом выражения price * count — это 750.
total = total - DISCOUNT;Вычисляется выражение total - DISCOUNT (740), результат присваивается переменной total. Старое значение 750 заменяется.
String text = "Итого: " + total;Объявляем text типа String и инициализируем результатом выражения: строковый литерал "Итого: " склеивается со значением total.
System.out.println(text);Вызываем метод println у объекта System.out и передаём ему аргумент text. Метод печатает строку и ничего не возвращает.
Итого: 740
Привычка на весь курс

Встречаешь новый код — прочитай его вслух по строкам этими словами. Дальше в курсе будут новые слова: условие и тело if, итерация цикла, параметры и возвращаемое значение метода, создание объекта. Каждое — в своём модуле, а все вместе — в шпаргалке.

Тренажёр: что происходит в строке?

Два вида заданий. В одних выбираешь правильное описание из пяти. В других собираешь описание из квадратиков — лишние оставь на месте.

Потренируйся с ИИ

Напиши: «Дай мне 5 строк кода на Java по одной: переменные, выражения, вызовы методов. Я прочитаю каждую вслух правильными терминами (объявление, инициализация, присваивание, выражение, вызов метода), а ты поправь, если я ошибся».

Коротко

  • Объявление — заводим переменную: тип и имя. Инициализация — первое значение. Присваивание — запись значения через =.
  • int a = 5; — «объявляем a типа int и инициализируем значением 5».
  • Выражение вычисляется в значение; в нём операторы и операнды; литерал — значение прямо в коде; инструкция — законченное действие с ;.
  • obj.method(x) — «вызываем метод method у объекта obj и передаём аргумент x».
  • Новый код читаем вслух по строкам этими словами — с этого начинается понимание.
