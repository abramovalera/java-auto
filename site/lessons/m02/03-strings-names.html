Строки, var, константы и хорошие имена

Текст — самые частые данные в программах: имена, адреса, сообщения об ошибках. Знакомимся с типом String, учимся не повторять тип дважды и называть переменные так, чтобы код читался как книга.

Повторение

String — тип для текста

Ты пользовался строками с первого урока: всё, что в двойных кавычках, — это строка (строковый литерал). Теперь строкой можно инициализировать переменную — положить текст в коробку. Тип для текста называется String (англ. «нить», «цепочка» — цепочка символов):

String name = "Аня";
String city = "Казань";
String empty = "";              // пустая строка: ноль символов
System.out.println("Привет, " + name + " из города " + city + "!");
Привет, Аня из города Казань!

Заметь: String пишется с большой буквы, а int и double — с маленькой. Это не случайность. String — не примитивный тип, а класс. Помнишь «чертёж» из урока 1.1? Каждая строка — это объект, сделанный по чертежу String. А у объектов есть методы — то, что объект умеет делать.

Чем строка-объект отличается от числа-примитива в памяти компьютера, разберём в следующем уроке. Там будет красиво: стрелки, стек и куча!

Что выведет программа?
String a = "10";
String b = "5";
System.out.println(a + b);

105. Это строки, а не числа: + их склеивает. Кавычки решают всё: "10" — текст из двух символов, 10 — число.

Главное правило: всё, что в кавычках, — строка

Внутри кавычек может быть что угодно — цифры, имя переменной, даже кусок кода. Для Java это просто текст, набор символов. Она не смотрит внутрь и ничего там не считает.

Как превратить число в строку — и обратно

Постоянная задача: из числа сделать текст (чтобы напечатать или склеить с другим текстом) или наоборот — из текста, который ввёл человек, достать число, чтобы считать.

int age = 21;

// число → строка: три способа, результат одинаковый — "21"
String a = String.valueOf(age);
String b = Integer.toString(age);
String c = "" + age;            // склейка с пустой строкой

// строка → число: только если внутри правда число
int back = Integer.parseInt("21");
double price = Double.parseDouble("99.5");
  • String.valueOf(...) — самый понятный способ: метод возвращает строку из значения любого типа: числа, boolean, символа.
  • "" + age — короткий трюк: строка в начале склейки превращает в строку всё, что дальше.
  • Integer.parseInt("abc") упадёт с ошибкой NumberFormatException — подробно про это в уроке 2.6.
Что выведет программа?
int age = 20;
String text = "" + age;
System.out.println(text + 1);
System.out.println(age + 1);

201 и 21. Переменная text инициализирована строкой «20», к ней приклеилась «1». А в age — число, к нему прибавилась единица. Одни и те же цифры, но разные типы — и совсем разный результат.

Строка умеет кое-что сама

Чтобы попросить объект что-то сделать, после имени переменной ставят точку и пишут имя метода со скобками. Это называется вызов метода у объекта. Метод выполняет работу и возвращает результат — например, число или новую строку. Три метода для начала:

String word = "Java";
System.out.println(word.length());       // 4 — сколько символов
System.out.println(word.charAt(0));      // J — символ под номером 0
System.out.println(word.toUpperCase());  // JAVA — большими буквами
word.length()

Метод возвращает длину строки — сколько в ней символов. Пробелы и знаки препинания тоже считаются: у "Привет, мир" длина 11. У пустой строки "" длина 0.

word.charAt(0)

Метод возвращает символ (char) по номеру. Нумерация с нуля! В "Java": 0 — J, 1 — a, 2 — v, 3 — a. Последний символ — под номером length() - 1.

word.toUpperCase()

Метод возвращает новую строку большими буквами. Сама word не меняется — строки в Java неизменяемы (подробнее в модуле 8).

Что выведет System.out.println("Кот".charAt(3));?

Программа упадёт с ошибкой StringIndexOutOfBoundsException: в слове «Кот» символы с номерами 0, 1, 2. Номера 3 нет. Эта ошибка случится не при компиляции, а во время работы программы.

var: пусть Java сама догадается о типе

В строке String city = "Казань"; тип указан дважды: словом String и самими кавычками. С Java 10 можно писать короче:

var city = "Казань";     // String — из-за кавычек
var age = 25;            // int
var price = 9.99;        // double
var big = 5_000_000_000L; // long

var — не «тип на любой вкус». Компилятор смотрит на значение справа (инициализатор) и навсегда ставит переменной подходящий тип — это называется вывод типа. Дальше это обычная переменная с обычным строгим типом.

  • var x; — ошибка: без инициализации не по чему угадывать тип.
  • var age = 25; age = "двадцать"; — ошибка: строку присвоить нельзя, age уже навсегда int.
  • var работает только для переменных внутри методов (как наши — внутри main).
Как писать в этом курсе

Пока учишься, пиши типы явно: int, String, double. Так ты лучше чувствуешь, что где лежит. var пригодится позже, когда типы станут длинными, вроде Map<String, List<Integer>>. Но читать код с var ты уже умеешь.

Константы: final

Иногда значение не должно меняться никогда: число дней в неделе, максимум попыток входа, адрес сайта магазина. Для таких значений перед типом пишут слово final (англ. «окончательный»):

final int MAX_LIVES = 3;
final double VAT_RATE = 0.2;
final String BASE_URL = "https://shop.example.com";

MAX_LIVES = 5;   // ошибка компиляции!

IDEA подчеркнёт такую строку сразу, а при запуске ▶ сборка остановится:

Так объявляют константу: после инициализации присвоить ей другое значение нельзя. Это коробка, которую заклеили скотчем: положить значение можно один раз, поменять — нельзя. Зачем это нужно:

  • Защита от случайностей. Компилятор не даст поменять то, что менять нельзя.
  • Нет «магических чисел». Что значит price * 0.2? Непонятно. А price * VAT_RATE — ясно: налог.
  • Одно место для правки. Если сайт магазина переедет, адрес меняют в одной строке, а не в двадцати.

В реальных проектах константы на каждом шагу: адрес сервера, ставка налога, максимум попыток входа. Увидишь MAX_LOGIN_ATTEMPTS большими буквами — знай, это final.

Как называть: стили и «говорящие» имена

Компилятору всё равно, как ты назовёшь переменную. А людям — нет. Код читают в десять раз чаще, чем пишут, поэтому у Java-программистов есть общие договорённости:

«Говорящее» имя объясняет, что лежит в коробке, без комментариев. Сравни:

ПлохоХорошоПочему
int d = 7;int daysUntilRelease = 7;d — что угодно: день, дистанция, долг…
String s;String userEmail;Видно, какой текст ждём.
boolean flag;boolean isLoggedIn;Имя-вопрос для boolean: ответ да/нет.
String имяИгрока;String playerName;Кириллица в именах технически работает, но так не пишут.

Имена пишут по-английски — так принято во всём мире. Не знаешь слово — переводчик в помощь, это нормально.

Проверь себя

Поговори с наставником

Напиши: «Дай мне 5 плохих имён переменных из чужого кода, а я предложу хорошие».

Коротко

  • String — тип для текста в двойных кавычках. Это класс, а не примитив, поэтому с большой буквы.
  • Вызовы методов строки: s.length() возвращает длину, s.charAt(i) — символ по номеру (с нуля), s.toUpperCase() — большими буквами.
  • var — вывод типа: компилятор определяет тип по инициализатору справа; без инициализации нельзя, сменить тип потом нельзя.
  • final — константа: значение присваивается один раз, при инициализации. Имена констант — UPPER_SNAKE_CASE.
  • Переменные — camelCase, классы — PascalCase. Имена по-английски и «говорящие».
