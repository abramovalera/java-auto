Решения — только в проекте workspace

Задачи решаются в IntelliJ IDEA, в проекте workspace из папки курса: сайт проверяет файлы только там. IDEA ещё не настроена — начни с урока 0.3 «Подготовка», первая программа — в уроке 1.4.

Как работать с задачей
  1. Прочитай условие задачи.
  2. В IntelliJ IDEA, в синей папке module-01 проекта workspace, создай класс с именем из условия: правый клик по папке → New → Java Class.
  3. Напиши код и запусти ▶ — убедись, что выводится то, что нужно.
  4. Вернись сюда и нажми «Проверить». Сайт сам возьмёт твой файл и проверит вывод.
  5. Всё зелёное — покажи решение наставнику: в чате Claude Code напиши /check и номер задачи (он указан под кнопкой). Застрял — напиши /hint и номер. Что такое наставник?
  6. Всё зелёное — разбери решение с DeepSeek: попроси объяснить, что можно улучшить, и задать тебе вопрос по твоему коду. Свой код не стесняйся показывать — решение уже твоё.
